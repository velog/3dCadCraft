# 2.10 Work features (Work Plane / Work Axis / Work Point / UCS)

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ waiting for another feature.

## 1. Purpose

Work features are helper geometry that is not part of the body: **planes, axes, points** and **user coordinate systems (UCS)**.
- They serve as:
  - a sketch plane when there is no suitable face;
  - an Extrude limit (To / From);
  - the axis of a Revolve, of a circular pattern and of a mirror;
  - reference points for 3D paths and measurements;
  - centre lines in drawings.
- They are **features in the history**. They regenerate together with the part and follow their inputs, because they are associative.
- In Inventor a work plane is **infinite**: the rectangle is only how it is drawn. A work axis is an infinite line as well.

## 2. Inputs (general rules)

- Inputs: faces and planes (of the Origin, work planes, the planes of a UCS), straight edges and axes, points (vertices, the middle of an edge, work points, sketch points), curved edges and sketch curves.
- **One command** (Plane / Axis / Point): the method is recognised from the kind and number of the picks. The drop-down menu gives the method explicitly (Inventor 2011+; the old command is the "legacy method").
- The pick order matters for the orientation (see the tables).
- **In-line**: while a work feature command runs, a right-click where a point, axis or plane is expected creates a nested feature. It becomes a child of the main one in the browser, and then the main command continues.

**In-line input from a sketch:** a point or line of a visible sketch used in a method with further inputs (e.g. plane + sketch point) becomes a hidden work point/axis right before the new feature (Inventor nests them under it). 🟡 (they are not nested in the browser; Redefine does not allow them — pick a work point/axis).

## 8. Edge cases and errors

- Midplane of non-parallel planes → `Work Plane: the planes are not parallel`.
- Three Points on one line → `Work Plane: the points are collinear`.
- Angle with an edge not parallel to the plane → `Work Plane: the edge is not parallel to the plane`.
- Axis from parallel planes → `Work Axis: the planes are parallel`.
- Point from lines that do not intersect → `Work Point: the lines do not intersect`.
- Missing input at regeneration: the feature becomes sick; sketches and work features on it keep their last position (rule 5).

## 9. Implementation

- `part/work.rs`: `WorkFeature` (`flip`, `build`), `WorkDef` (Plane / Axis / Point / Ucs), `WorkPlaneDef`, `WorkAxisDef`, `WorkPointDef`, `UcsDef`, `CurveRef`, `LineRef`, `ucs_parts`. They are computed in the regeneration loop into `PartDocument::work` (runtime only); `Ctx` provides the body, the work features built so far, the Revolve axes and the sketches.
- `part/work/surf.rs`: the analytic surface of a face (`facet_of` for faceted ones), axis/centre/midplane of a torus, tangent planes (through a line, through a point, parallel), intersection of a line with a cylinder/sphere/cone/torus, centre of a circle/ellipse from points (conic fit), tangent of a curve at a point.
- Inputs are by persistent names only (faces, edges, vertices), sketch id + point/line id in it, work feature ids; a missing input → feature health (rules 5, 8).
- Cones from the exact kernel are now converted into `Surface::Cone` (they used to become the XY plane).
- `PlaneRef::Work(id)`, `SketchPlacement::resolve_with`; the UCS elements are `PlaneRef::Work("UCS1:XY")` etc.
- GUI: `gui/work.rs` (draft, method recognition, in-line inputs, EN/BG prompts, picking, drawing, angle arc), `gui/work_panel.rs` (dialog and Properties), `gui/manip.rs::plane_angle_handle`.
