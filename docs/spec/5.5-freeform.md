# 5.5 Freeform — control-cage surfaces and direct shaping

## 1. Purpose

Organic shapes made by pulling the points of a control cage instead of drawing profiles: Inventor's
Freeform environment (Box, Plane, Cylinder, Sphere, Torus, Quadball, Face; Edit Form, Align Form,
Delete, …) and, for the editing itself, the way Alias works on a NURBS surface — its control vertices
(CVs) are moved directly in the view, alone or several at once, with a falloff to the neighbours.

The cage is ours to keep: a feature stores the cage's rest positions and every moved point, and the
shape is rebuilt from them on each regeneration (a parametric feature, unlike Alias's history-free CVs).
The surface is a **cubic B-spline tensor surface** whose control net is the cage — the same smooth
limit a regular T-spline / subdivision cage gives away from its extraordinary points. Shapes that need
points of other valence (Box, Sphere, Quadball, Face with many sides) wait for an n-sided patch (§6).

## 2. Inputs

- **Plane / Center:** a work plane, an origin plane or a planar face; the centre point on it (default:
  the plane's origin; a click on the plane sets it).
- **Sizes and Faces:** length, width (height, diameter… per primitive) and the number of cage faces in
  each direction (each face of the cage is one span of the surface).
- **Edit Form:** the cage points of one Freeform feature, picked in the view.

### 3.3 Other Freeform commands

Align Form, Delete, Insert Edge / Point, Subdivide, Bridge, Merge Edges, Unweld / Weld, Crease /
Uncrease, Flatten, Match Edge, Thicken, Mirror, Make Uniform, Convert to Freeform: ⬜ (interface first,
rule 15).

## 4. Browser and editing

A Freeform feature is one browser node (`Freeform1`), its body a surface body `Freeform1` with one face
`Freeform1:Face`. Edit Feature opens the creation panel (sizes, faces) with Edit Form on the view: changing
the face count rebuilds the cage at rest (moved points are kept where the count is unchanged).

## 5. Edge cases and errors

- Faces < 1, a size ≤ 0, more than 64 faces a side: refused (`Freeform: …`).
- A plane reference that no longer exists: the feature's health.

## 6. Implementation

- `part::freeform` (`FreeformOp`: kind, plane, centre, sizes, face counts, symmetry, `moved`: cage index
  → offset); `cage()` gives the cage points (rest + offset); `BodyOp::Freeform` builds through
  `kernel::exact::freeform_sheet` (vendor `bspline_sheet`: clamped cubic knots, the net as given, its four
  border curves as the edges).
- GUI `gui/freeform.rs`: the Freeform Plane panel's logic (planned panel with logic), the Edit Form mode
  (cage overlay, picking, view-plane drag, falloff, numbers), drawn last in the viewport.
- An n-sided patch (Catmull–Clark limit near extraordinary points, or Gregory patches) is the next kernel
  step for Box / Sphere / Quadball.
