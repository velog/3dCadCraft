# 5.6 Sheet Metal

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ blocked by another feature.

> **Research document first** (the owner's rule for this module, 2026-10-24): this file gathers how Inventor
> 2027 behaves, what SolidCraft (MIT OR Apache-2.0) already implements that we can adapt, and a staged plan.
> Every row starts ⬜. Rows marked *(to confirm)* were written from general Inventor knowledge and must be
> checked against the 2027 help page before that row is implemented.

## 1. Purpose

Parts made from sheet stock of one thickness: plates, flanges and bends that a press brake can make, and
the **flat pattern** (the part unfolded) that a laser / punch cuts. Every bend is developed from the sheet
metal **rule** (thickness, bend radius, K-factor or bend table, reliefs), so the flat pattern is right for
the shop. Exports the flat pattern to DXF for the cutter and feeds drawings (bend lines, bend table) and
the BOM (flat size, `Sheet Metal Length/Width/Area` properties).

## 2. Inputs

- A **sheet metal part** (Inventor: a part document of subtype *Sheet Metal*; a normal part can be
  converted). Sketches as in parts; edges and faces of the sheet body.
- The active **Sheet Metal Rule** (a style) and the per-feature overrides.

### 3.1a Rules as styles (owner, 2026-10-26: "defaults are too few; they must come from a table, so I can
make many styles for different materials")

Inventor keeps sheet metal settings as two kinds of named styles in the Style and Standard Editor
(Manage › Styles Editor), stored in the document or in the shared style library: **Sheet Metal Rule**
(tabs Sheet, Bend, Corner) and **Sheet Metal Unfold** (the unfold rule a Sheet Metal Rule names). A part
uses one rule (Sheet Metal Defaults); features may override relief, corner and unfold settings.

### 3.3a The flat pattern as an object (owner, 2026-10-26: "make it once, for further work that does
not show in 3D, and use it for the drawing")

In Inventor, **Create Flat Pattern** adds a *Flat Pattern* node to the browser. The flat state has its own
features and parameters: what is added there is not in the folded model's history and does not show in
3D; the folded model's edits update the flat. Drawings make their flat views from it (deleting it deletes
those views); its extents are the sheet stock. Convert to Standard Part deletes it.

| Option | Inventor behaviour | Restrictions | Our status |
|---|---|---|---|

| Flat features | in the flat state: Cut / Hole / Corner Round / Corner Chamfer / Punch / Cosmetic Centerline / Bend Order Annotation and the common model commands; they belong to the flat only (own history under the node, not in 3D) | applied after the whole fold history | ⬜ `PartDocument::flat` = `Option<FlatPatternDef>` with its own `features` (`Feature` values, same ids space) built on the flat solid after regeneration; a separate build cache step |

### 3.5 Command panels (interface), from Inventor 2025–2027 Help

Inventor's sheet metal commands moved from dialogs to **property panels** (2025): a header with the
feature's name (editable breadcrumb) and presets; sections **Input Geometry** (selector rows: a coloured dot,
the count, `x` to clear; the first selector is active when the command opens and a single profile is taken
by itself), **Behavior**, **Bend Properties**, **Corner** sections; **OK / Apply (+) / Cancel**; the result
previewed in the view while values change. Our panels follow that layout on our shared command parts
(`command_ui` selector rows and right-click menu, `field_row` expression fields, breadcrumb, OK / Apply /
Cancel, Enter / Esc, Edit Feature reopening the same panel). Owner, 2026-10-26: "no previews, the controls are
terrible" — this section is the requirement for every command.

## 4. Browser and editing behaviour

- Sheet metal features are history features like the part's (Edit, Suppress, reorder, EOP).
- The Flat Pattern is a node after the folded model; editing a folded feature updates it. Its own flat
  features are listed under it and never appear in the folded history or the 3D model (3.3a).
- Rule and Defaults changes regenerate every feature that uses the rule's parameters.

## 5. Edge cases and errors

- A flange or fold that would intersect the sheet itself: an error naming the feature (`Flange: …`).
- Bend radius 0 or K outside 0..1: refused by the rule editor.
- A body that is not of constant thickness cannot be converted (the face found is reported).
- A closed shape without a rip cannot be unfolded: the flat pattern reports it.

## 6. Implementation (research)

### 6.1 What SolidCraft has (`crates/doc/src/sheet.rs`, 6 800 lines; `sheet_convert.rs`; `crates/engine/src/cmd/sheet.rs`; `crates/io/src/dxf.rs`)

- **Model:** a sheet body is kept **as its flat pattern**: the base panel, flanges hanging off panel edges
  (each a bend zone of width BA = θ·(R + K·T) followed by a flat panel), cut-outs, all in the flat frame;
  folding maps flat coordinates through the parents' bends. The folded solid is built from extruded
  pieces (panels; bend zones as annular sectors) joined together; the flat solid is the outline extruded.
- **Rules** (`SheetRule`): thickness, K-factor, bend radius, relief width / depth, corner relief and its
  shape (notch, round, rectangular, tear), hem gap, gap — as **expressions** (`Thickness` usable).
- **Features:** `SheetBase` (Face), `SheetContour` (Contour Flange), `SheetFlange` (several edges, height,
  angle, radius, position inside/outside/middle, flip, per-edge values), `SheetHem` (flat hem), `SheetFold`
  (sketch line, fold location, fixed side), `SheetUnfold` (unfold all / refold), `SheetConvert` (from a
  plate or a shelled body with chosen bend edges).
- **Flat pattern:** `flat_solid`, `outline`, `bends()` (bend lines), `flat_size`, DXF writer.
- Bounded work budgets everywhere (no runaway geometry).

### 6.1a S1 as built (2026-10-25)

- `kernel::exact::sheet_metal` wraps `solidcraft_doc::sheet` (Face, flanges, flat solid / size / bends,
  edge names); `part::sheet_metal`: the rule, `Feature::SheetFace` / `SheetFlange` (format revision 19),
  `PartDocument::sheet_models` (runtime, one model per sheet body, kept in the build cache), the step key
  includes the rule. Faces of the sheet are named by the sheet (`Face1:<panel>:top`, bends

- Revision 21 (2026-10-26): `Feature::SheetOp` (Hem, Fold, Contour Flange, Unfold, Refold, Cut — one
  feature type, `kind` in the JSON); the Cut is our `cut_through` in `vendor/solidcraft-doc` (regions

### 6.1b Laser-ready corners (2026-10-26, owner's Box 1 / Box 2)

The owner's flat patterns had stepped notches (a round relief about the base's vertex that stopped the
bends while the closed panels ran on), bends ending in caps and bare stretches of a wall's edge beside a
lip's bend. Now (`vendor/solidcraft-doc`, rows in `vendor/README.md`):

- **2-bend reliefs** are flat cut-outs about the crossing of the bends' centre lines (Inventor's
  placement): one line → arc → line in the outline.
- **Rim corners** (lips, returns on returns): as in Inventor (owner's picture), the seam is one even gap
  through panels *and bends*: a lip's bend end is mitred — in the flat a curve (cubic pieces) on which both
  faces keep the half gap from the mitre plane, from its wall's end to where its panel starts. A bend that
  must start in from its wall's end has the wall's end lean back to it. The flat outline is one smooth line
  from level to level.
- **Bend relief on lips** held back by Width Extents (Offset): the rule's straight relief in the parent.
- Tests: `tests/sheet_metal.rs` `laser_ready` / `flat_steps` count the jogs left in an outline (a short edge
  turning sharply one way then the other); the owner's boxes are fixtures (`tests/data/sheet_box*.3dcadcraft`).
- `examples/flat_dxf.rs` writes a project's flat patterns as DXF from the command line.
- Old files stay as they were (rule 6, `tests/compat`): `SheetFlangeFeature::relief_placement` (serde default
  Base Vertex) and `laser_corners` (default off: SolidCraft's return corners, no bend relief on flanges) are
  set by `SheetFlangeFeature::new`; choosing Bend Centerlines in the Corner section turns `laser_corners` on
  too, so an old part is brought up to date flange by flange with Edit Feature.
