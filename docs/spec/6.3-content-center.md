## 1. Purpose

Standard parts placed from a library instead of being modelled: bolts, screws, nuts, washers, pins,
rivets, bearings, keys, circlips, structural profiles (for frames, 6.1), fittings. Each **family** is one
parametric shape and a table of sizes; placing a size makes (or reuses) its part file. The parts carry
their designation, standard and material in iProperties, so the BOM and drawings name them correctly.

## 2. Inputs

- The library: categories → families → members (table rows).
- In an assembly: the place to put the part; for fasteners, optionally a hole to fit (AutoDrop).

## 4. Browser and editing behaviour

- A library part is an ordinary occurrence of its (read-only) part file; Open shows it read-only.
- The part files are generated on demand into a cache folder and reused for every assembly.

## 5. Edge cases and errors

- A size missing from the table after a library update: placed parts keep their file (copied data).
- A custom part file renamed or moved: resolved like any linked part (3.1).

## 6. Implementation (research)

- **Data, our own**: family tables as CSV files (as `data/standards/*.csv` for holes: built in, plus a user
  folder overriding by name), with the standard's dimension names as columns. The numbers are typed from
  the **standards themselves** (ISO 4017, ISO 4032, ISO 7089, ISO 4762, EN 10056 / 10279 / 10365 profiles…)
  or published open tables — never copied from Autodesk's (or any commercial CAD's) libraries.
- **Templates**: a family's template is a part of ours whose sketch dimensions and feature values are
  parameters named after the table's columns (our parameters, 0.5); a member is the template with the row
  applied, regenerated, saved as `<cache>/<standard>/<family>/<designation>.3dcadcraft`, then linked into
  the assembly like any part (3.1). Thread: cosmetic (2.9) by default.
- **AutoDrop**: hole / cylinder detection exists (`PartDocument::holes`, `hole::cylinder_face`); the
  bolt's diameter is the nearest table size, its Insert constraint (3.2) put on the hole's rim.
- **Window**: like Place's file browser (`gui/place.rs`) with a category tree, member table and preview.
