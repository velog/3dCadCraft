# 0.6 Файлове: New, Open, Save, Save As, Export, последни файлове

## 1. Предназначение

Работа с файла на проекта (`.3dcadcraft`) и износ на детайла. В Inventor това са командите
от менюто File (New, Open, Save, Save As, Export) и списъкът с последни документи; при
затваряне с незаписани промени програмата пита дали да запише. Inventor ползва стандартния
прозорец на операционната система; ние имаме собствен прозорец в egui (еднакъв на Linux и
Windows, без зависимост от GTK/COM).

## 2. Входни данни

- път до файл (избран в прозореца, написан на ръка, от Open Recent или пуснат с мишката
  върху прозореца);
- за Export: формат (STL, STEP, GLB) и име на файла.

## 3. Настройки и поведение

| Опция | Поведение в Inventor | Ограничения | Статус при нас |
|---|---|---|---|
| New (Ctrl+N) | нов документ от шаблон | при незаписани промени пита първо | 🟡 празен детайл, без шаблони |
| Open (Ctrl+O) | прозорец за избор на файл | показва само файлове от правилния вид | 🟡 работи на Linux, Windows чака визуална проверка |
| Open Recent | списък с последните документи | само съществуващи файлове, най-новият отгоре | 🟡 до 10 файла; Windows чака проверка |
| Save (Ctrl+S) | записва в текущия файл; без файл — Save As | атомарен запис с `.bak` | 🟡 Windows чака проверка |
| Save As (Ctrl+Shift+S) | нов файл; предупреждение при съществуващ | разширението се добавя, ако липсва | 🟡 второ натискане на Save заменя файла |
| Save as Folder | — (наше: разпакувана папка за git) | | 🟡 |
| Export STL / STEP / GLB | File → Export → CAD Format | вж. [7.7-export.md](7.7-export.md) | 🟡 Windows чака проверка |
| Незаписани промени при затваряне | Save / Don't Save / Cancel | `*` в заглавието | 🟡 Windows чака проверка |
| Пуснат файл върху прозореца | отваря документа | разширението без значение от главни/малки букви | 🟡 |
| Up | родителска папка | — | 🟡 |
| Up от корена на диск (Windows) | „This PC“ със списък на дисковете | | 🟡 списък `C:\`, `D:\`…; чака визуална проверка |
| Писане на `C:` в полето за папка | корена на диска | `C:` без `\` в Windows значи „текущата папка на C:“ | 🟡 превръща се в `C:\` |
| Скрити и системни папки | не се показват (по подразбиране) | | 🟡 `.име` навсякъде; атрибут Hidden/System в Windows |
| Папка без права за четене | съобщение за грешка | | 🟡 „Cannot read …“ под списъка |
| Начална папка | последната папка / Documents | | 🟡 папката на текущия файл, иначе `Documents` (в Windows и OneDrive\Documents), иначе домашната |
| Настройки и последни файлове | в профила на потребителя | | 🟡 `%APPDATA%\3dcadcraft\settings.json` (Windows), `~/.config/3dcadcraft/settings.json` (Linux) |

## 4. Поведение в дървото и при редакция

Отварянето заменя целия проект и изчиства историята Undo. Записът не променя Undo.

## 5. Крайни случаи и грешки

- Име `.`, `..` или празно — „Type a file name“.
- Име, написано в списъка с дискове, без пълен път — „Pick a drive or type a full path“.
- Липсваща папка — „No folder …“; липсващ файл при Open — „No file …“.
- Последните файлове се пазят с обикновен път (`C:\…`), не с `\\?\C:\…`, който връща
  `canonicalize` в Windows; същото важи за пътищата до библиотеки (Link), за да работят
  и между различни дискове.
- Домашната папка в Windows е `USERPROFILE`: Git Bash задава `HOME=/c/Users/…`, който
  Windows не може да отвори.

## 6. Реализация

- `src/gui/files.rs`: `FileDialog` (`up`, `go`, `at_drives`, `target`), `list_dir`
  (`is_hidden`), `drives`, `drive_root`, `home_dir`, `settings_path`, `recent_files`,
  `remember_recent`, `start_dir`, прозорецът „Unsaved changes“.
- `src/document/library.rs`: `without_verbatim` за каноничните пътища.
- Тестове: `gui::files::tests` (някои само под `cfg(windows)`), `document::library::tests`.
