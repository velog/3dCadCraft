# 0.6 Files: New, Open, Save, Save As, Export, recent files

## 1. Purpose

Working with the project file (`.3dcadcraft`) and exporting the part. In Inventor these are
the commands of the File menu (New, Open, Save, Save As, Export) and the list of recent
documents; when closing with unsaved changes the program asks whether to save. Inventor uses
the operating system's standard dialog; we have our own dialog in egui (the same on Linux and
Windows, with no dependency on GTK/COM).

## 2. Inputs

- a file path (picked in the dialog, typed by hand, from Open Recent or dropped with the mouse
  onto the window);
- for Export: the format (STL, STEP, GLB) and the file name.

## 3. Options and behaviour

| Option | Inventor behaviour | Restrictions | Our status |
|---|---|---|---|
| New (Ctrl+N) | new document from a template | asks first if there are unsaved changes | 🟡 empty part in a new tab (§3.1), no templates |
| Open (Ctrl+O) | file picker dialog | shows only files of the right kind | 🟡 works on Linux, Windows waiting for a visual check |
| Open Recent | list of the recent documents | only existing files, newest on top | 🟡 up to 10 files; Windows waiting for a check |
| Save (Ctrl+S) | writes to the current file; without a file — Save As | atomic write with `.bak` | 🟡 Windows waiting for a check |
| Save As (Ctrl+Shift+S) | new file; warning if it exists | the extension is added if missing | 🟡 pressing Save a second time replaces the file |
| Save as Folder | — (ours: an unpacked folder for git) | | 🟡 |
| Export STL / STEP / GLB | File → Export → CAD Format | see [7.7-export.md](7.7-export.md) | 🟡 Windows waiting for a check |
| Unsaved changes on close | Save / Don't Save / Cancel | `*` in the title | 🟡 Windows waiting for a check |
| File dropped onto the window | opens the document | extension case-insensitive | 🟡 |
| Up | parent folder | — | 🟡 |
| Up from a drive root (Windows) | "This PC" with the list of drives | | 🟡 list `C:\`, `D:\`…; waiting for a visual check |
| Typing `C:` in the folder field | the drive root | in Windows, `C:` without `\` means "the current folder on C:" | 🟡 turned into `C:\` |
| Hidden and system folders | not shown (by default) | | 🟡 `.name` everywhere; Hidden/System attribute in Windows |
| Folder without read permission | error message | | 🟡 "Cannot read …" below the list |
| Start folder | the last folder / Documents | | 🟡 the current file's folder, otherwise `Documents` (in Windows also OneDrive\Documents), otherwise the home folder |
| Settings and recent files | in the user profile | | 🟡 `%APPDATA%\3dcadcraft\settings.json` (Windows), `~/.config/3dcadcraft/settings.json` (Linux) |

### 3.0 The file dialog (Open, Save As, Export, Import)

Inventor shows the system's Open / Save dialog: a navigation pane with places on the left, the
folder's files in columns, the file name and the file type at the bottom, a preview. Ours follows
that layout in egui (one dialog for every purpose in `DialogPurpose`).

| Row | Behaviour | Our status |
|---|---|---|
| Window | resizable; opens centred on the first use, afterwards where and as large as it was left (`file_window` in the layout); the list takes the height the window gets | 🟡 waiting for the owner's check |
| Toolbar | Back, Forward, Up, Refresh and the folder path (editable; Enter goes there, `C:` means `C:\`) | 🟡 |
| Places pane | Recent, Desktop, Documents, Downloads, Home, This PC (Windows: the drives), and the folder of the current file; the place of the shown folder is highlighted | 🟡 |
| Recent place | the recent files with their folders, newest first; only files that still exist | 🟡 |
| Columns | Name (folder / project icon), Date modified (local time), Size (KB / MB; folders none); a click on a header sorts by it, a second click reverses; folders stay above files | 🟡 |
| Click / double-click | a click selects (a file also fills the name); a double-click opens the folder or the file (like Windows; a single click used to enter folders) | 🟡 |
| Keyboard | Up / Down move the selection, Enter opens it (or the typed name), Alt+Left / Alt+Right back / forward, Alt+Up or Backspace (outside the name field) the parent folder, Esc cancels | 🟡 |
| Typed name | a folder name or path typed with Enter goes into that folder; a full path is used as it is; the extension is added when missing | 🟡 |
| Files of type | the filter is shown below the name (e.g. `3DCadCraft project (*.3dcadcraft)`); only matching files are listed | 🟡 one type per purpose, no type choice |
| Speed | entries are read once per folder (type and metadata from the directory listing); only the visible rows are drawn, so folders with thousands of files scroll smoothly | 🟡 |
| Preview / thumbnails | Inventor shows a preview of the picked file | ⬜ needs thumbnails stored in the project file |

### 3.1 Document tabs (several open files)

Inventor keeps every open document in its own **document tab** along the bottom of the graphics
window: a click switches to it, the tab menu has Close / Close All / Close Other; each document has
its own view, selection and Undo; closing a changed document asks to save it.

| Row | Behaviour | Our status |
|---|---|---|
| Open / New in a tab | Open and New add a tab (no "save changes?" question, the other document stays open); opening a file that is already open switches to its tab; an untouched empty "Untitled" tab is replaced | 🟡 also a dropped file; a failed open removes its tab again (`gui/doc_tabs.rs`) |
| Tab bar | above the view: one tab per document — title (`*` when changed), `x` to close; a click switches | 🟡 plus `+` for New (deviation: Inventor has them along the bottom of the view) |
| Switching | the open command / sketch edit of the tab being left is finished (Finish Sketch) or cancelled (commands); each tab keeps its project, Undo history, file path, saved state, camera and selection | 🟡 the autosave / recovery file follows the active tab only |
| Close tab | `x` or the tab's right-click Close; a changed document asks Save / Don't Save / Cancel; closing the last tab leaves an empty Untitled one | 🟡 |
| Close Other / Close All | in the tab's right-click menu (each changed one asks) | 🟡 Close / Close Other (unchanged tabs close, changed ones stay); Close All ⬜ |
| Quit | every changed tab asks in turn (the first changed tab comes forward) | 🟡 Don't Save goes on to the next changed tab, Cancel stops the quit |
| Ctrl+Tab / Ctrl+Shift+Tab | next / previous tab | 🟡 taken in `raw_input_hook` before egui moves the focus |

## 4. Browser and editing behaviour

Opening adds a tab (§3.1); the tab's Undo history starts empty. Saving does not change Undo.

## 5. Edge cases and errors

- Name `.`, `..` or empty — "Type a file name".
- A name typed in the list of drives, without a full path — "Pick a drive or type a full path".
- Missing folder — "No folder …"; missing file on Open — "No file …".
- Recent files are stored with a plain path (`C:\…`), not with the `\\?\C:\…` that
  `canonicalize` returns in Windows; the same applies to paths to libraries (Link), so they
  also work across different drives.
- The home folder in Windows is `USERPROFILE`: Git Bash sets `HOME=/c/Users/…`, which
  Windows cannot open.
