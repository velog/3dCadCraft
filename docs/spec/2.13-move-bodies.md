# 2.13 Move Bodies

## 1. Purpose

Moves and turns bodies of a multi-body part, for example to place parts of a design before they are
combined. One feature holds one or more moves applied in order. Inventor: 3D Model › Modify › Move Bodies.

## 2. Inputs

- **Bodies**: solid or surface bodies of the part (picked in the view or in the browser). A pre-selected
  body, or a face of one, fills the selector (rule 17).
- Per move, depending on its type: offsets, or a line (a straight edge, a work axis or an origin axis) with an
  offset or an angle.

## 3. Options

| Option | Inventor behaviour | Restrictions | Our status |
|---|---|---|---|
| Bodies selector | the bodies to move; a second pick removes one | | 🟡 waiting for a visual check |
| Move Type **Free Drag** | X, Y, Z offsets, or drag the preview freely | | 🟡 X, Y, Z expression fields; dragging the preview ⬜ |
| Move Type **Move Along Ray** | an edge or axis gives the direction; Flip; Offset (or drag) | straight edge or axis | 🟡 edges, work axes, origin X / Y / Z; drag ⬜ |
| Move Type **Rotate About Line** | an edge or axis to turn about; Flip; Angle (or drag) | straight edge or axis | 🟡 right-handed about the line's direction, Flip the other way; drag ⬜ |
| *Click to add* | another move in the same feature (moves are grouped to keep the file small) | | 🟡 up to 9 moves; each can be removed |
| Values | expressions and parameters | | 🟡 fields `x1`, `y1`, `z1`, `offset2`, `angle3`… (`BodyOpFeature::fields`) |
| Preview | the moved bodies while the panel is open | | 🟡 their edges (orange) |
| OK / Apply / Cancel | | | 🟡 |

## 4. Browser and editing behaviour

- The feature is `MoveBodies<N>` (format revision 35, `BodyOp::MoveBodies`) with the Move Bodies icon; its
  tooltip lists the moves.
- Edit Feature reopens the panel with the feature rolled back.
- Faces, edges and bodies keep their names, so later features and sketches on a moved body follow it.

## 5. Edge cases and errors

- No body or no move: OK stays disabled (*select the bodies to move*, *add a move*).
- A body or a line that no longer exists after an upstream edit: the feature's health.
- A curved edge as a line: refused (*edge … is not straight*).
- Every refusal leaves the part unchanged.
- Known gap: hole data for drawings (hole tables, notes) and cosmetic thread bands of a moved body stay
  where the hole was made.

## 6. Implementation

- Data: `part::body_op::{MoveBodiesOp, MoveStep}`.
- Geometry: `part/exact.rs::move_matrix` (the steps composed; lines resolved on the body before the feature)
  and `move_bodies` (`exact::moved`, a rigid motion keeping the face names and the surface flag).
- GUI: `gui/move_bodies.rs`.
- Tests: `tests/move_bodies.rs`, `tests/compat/r35`.
