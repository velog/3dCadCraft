# 5.4 Surfaces — Stitch, Boundary Patch, Trim, Extend, Ruled Surface, Replace Face, Sculpt

## 1. Purpose

The commands of Inventor's 3D Model › Surface panel that make, join, cut and use surface bodies:
**Stitch** sews surfaces into a quilt (a solid when they close a volume), **Boundary Patch** fills a
closed loop, **Trim** cuts a surface with a tool, **Extend** lengthens a surface at its edges,
**Ruled Surface** makes a strip from model edges, **Replace Face** swaps faces of a solid for a
surface or a plane, **Sculpt** adds or removes material bounded by surfaces. Surface bodies come from
Extrude / Revolve / Sweep / Loft with Output Surface (2.1, 2.2, 5.1, 5.2), Thicken/Offset (2.14) and
these commands.

## 2. Inputs

Surface bodies (by name), faces (name + a point), edges (the name of a face along the edge + a point on
it), planes (origin / work planes, planar faces), sketch regions, work axes and straight edges as
directions. The command panels and selectors are the planned panels of spec 2.0 §3.

## 4. Browser and editing

Each command is a `Feature::BodyOp` with its own `BodyOp` variant (format revision 37), named
`Stitch1`, `BoundaryPatch1`, `TrimSurface1`, `ExtendSurface1`, `RuledSurface1`, `ReplaceFace1`,
`Sculpt1`; Edit Feature opens the command's panel. A Boundary Patch of a sketch region consumes the
sketch (cache key, history dependencies).

## 5. Edge cases and errors

- A failure is the feature's health (`Fail::User`), never a faceted rebuild.
- Trim: a pick on the tool itself, or a tool that does not cut, is refused.
- Stitch of surfaces that do not meet within the tolerance is refused.
- A flat sheet "closed" by a copy of itself encloses nothing: Sculpt treats it as open.

## 6. Implementation

- Kernel: `kernel::exact::surface_ops` (stitch, patch_edges, patch_region, trim, extend, reversed),
  `kernel::exact::sweep_sheet_along`.
- Part: `part::surface_op` (data + regeneration), dispatched from `part/exact.rs::body_op`.
- GUI: `gui/surface_cmd.rs` (the planned panels' picks with the clicked point → the `BodyOp`;
  Edit Feature), `PartDialog::items` / `pick_item` in `gui/part_planned.rs`.
- Tests: `tests/surface_tools.rs` (areas and volumes against hand values, Pappus for revolved
  surfaces).
