# 1.2b Ellipse

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ waiting for another feature. A new spec: everything ⬜.

## 1. Purpose

Elliptical outlines in a sketch (oval holes and bosses, handles, cams, the section of a tilted
cylinder) as an exact curve: dimensioned by its two axes, constrained like a circle, extruded and
revolved into exact elliptical faces — today the only way is a spline, which cannot be dimensioned by
its axes and is not exact.

## 2. Inputs

Sketch → Create → Ellipse (in the Circle drop-down in Inventor; ours: its own small button in the
Create panel, alias `EL`). Three clicks: **centre**, **end of the first axis** (direction and half
length), **a point on the ellipse** (fixes the other half axis). Dynamic Input fields for the two half
axes and the angle of the first one.

## 4. Browser and editing

No browser node (sketch geometry). Selecting the ellipse shows in Properties: centre, the two half
axes, the angle of the first axis, construction flag. Double-click a half-axis dimension edits it in
place.

## 5. Edge cases and errors

- Third point on the first axis' line or at the centre: the click is refused with
  `Ellipse: pick a point off the first axis`.
- Equal half axes are allowed (the ellipse is then a circle; it stays an ellipse entity).
- Over-constrained: the usual solver report; a failing solve reverts (rule 5).
- Old builds cannot read a file with an ellipse (a new `Entity` variant): format revision + fixtures.

## 6. Implementation (plan)

- `sketch`: `Entity::Ellipse { center, axis_end, minor }` — the first axis is `axis_end − center`, the
  other half axis `minor` is a solver unknown (like a circle's radius); `Entity::EllipseArc { center,
  axis_end, minor, start, end }` with implicit "on the ellipse" residuals for `start` / `end` (as arcs
  carry "end on the circle"; copies of elliptical arcs must tie only one end, see the arc pitfall).
  Residuals through the `Geo` trait (point on ellipse: the implicit equation in the ellipse's frame,
  normalised by the half axes so the gradient never vanishes at the axis ends); tangency to a line =
  the line's distance from the centre along its normal equals the support function
  `√((a·cosφ)² + (b·sinφ)²)`.
- `sketch::profile`: `ProfileCurve::Ellipse` (centre, axes, start angle, sweep); regions need its
  intersections with lines / circles / ellipses (a quartic — solve numerically on the sampled curve,
  then Newton on the exact one).
- `kernel`: no new `Curve` variant — an ellipse is an exact rational quadratic NURBS (four quarter
  arcs, weights √2/2), which `BSplineCurve` and the exact boundary already carry; `exact.rs` must keep
  the profile's segments in quarters like circles (`map_loop`).
- Format revision (next free after 41) with fixtures under `tests/compat/r<N>/`.
- GUI: `sketch_tools.rs` tool `Ellipse` (3 clicks, preview, Dynamic Input), `commands.rs` entry with
  alias `EL` and its own icon, General Dimension placement for the two half axes, overlay drawing.
- Tests: DOF of a free ellipse = 5 (centre 2, axis end 2, minor 1), `redundant == 0` for an ellipse
  with both axes dimensioned and the axis horizontal; tangency to a line and a circle; Trim to an arc;
  region area = πab; extruded volume = πab·h (exact kernel) and face names; save / load round trip.
