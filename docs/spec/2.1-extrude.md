# 2.1 Extrude

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ waiting for another feature (which one in brackets).

Compared row by row with Inventor Help 2027 (*To Create Extruded Features*) on 2026-10-19. The new rows from this comparison are marked "(2027)"; all of them are waiting for a visual check (the machine is Windows, without screenshot tools), so they are 🟡 even when the tests pass.

## 1. Purpose

Pulls closed areas (regions) or contours of a sketch perpendicular to its plane, creating or modifying a body. This is the basic feature for prismatic parts: plates, bosses, pockets, holes of any shape. Inventor offers three ways: from a sketch profile, from a face (Press/Pull) and from a primitive (Box, Cylinder).

## 5. Editing and browser

- ✅ **Edit Feature** (double click in the browser, context menu): the model rolls back to the feature, the dialog opens with all the inputs, OK replaces it in place; on failure nothing changes.
- If the region disappears, the feature is **"sick"**: orange in the browser, with the reason in the tooltip.
- 🟡 (2027) Context menu in the view while the command is open: OK (Ctrl+Enter), Cancel (Esc); for Revolve also Continue.

## 6. Edge cases

- Distance 0 or negative → refused.
- A "To" extent in the sketch plane (zero depth) → refused.
- A Taper at which the section vanishes → refused with a clear message.
- To a plane parallel to the direction (perpendicular to the sketch) → "never meets it".
- To an inclined plane that crosses the profile → "the plane crosses the profile".
- To a cylinder that the profile does not meet entirely in either direction → refused.
- A From / To face that does not cover the profile, with Extend face off → refused with a hint to turn it on.
- An open profile without a body → "an open profile needs a solid body".
- Every refusal leaves the part unchanged (tests).

## 7. Our implementation

- `part/extrude.rs`: `ExtrudeFeature` (new fields: `alternate`, `extend_face`, `terminator`, `open: Option<OpenProfile>`), `TargetRef` (+ `Plane`, `Point` — format revision 11), `Termination` (Offset / Plane / Cylinder), `ExtrudeFeature::pieces` → `Piece` (profile + `Span` with levels and `Clip`), `predict_operation`, `needs_extended_face`, `open_loop` (Match Shape).
- `part/exact.rs`: `extrude` applies `Clip` and `bounds`; `clip_tool`, `slab`, `cylinder_solid`. The faceted kernel refuses clipping ("needs the exact geometry kernel").
- `part/primitive.rs`: primitives (see §9).
- GUI: `gui/feature_cmd.rs` (breadcrumb, the menu, "+", Ctrl+Enter, primitives, open curves, prompts), `gui/breadcrumb.rs` (shared module), `panels.rs` (`extrude_options`, `output_options`, `DraftCtx`).
- Face names: `<id>:Start`, `<id>:End` (also when clipped), `<id>:Side:<curve>:<k>`; open profile — `…:Side:Frame:<k>` for the sides along the frame.
