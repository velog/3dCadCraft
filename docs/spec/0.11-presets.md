# 0.11 Presets (готови набори настройки в панелите на командите)

## 1. Предназначение

Preset е именуван запис на настройките на една команда за операция (Extrude, Fillet,
Shell…). Потребителят си подготвя стойностите веднъж („Fillet 3 mm“, „Shell 1.5 Outside“),
дава им име и после ги избира с едно щракване: панелът се попълва наведнъж. Входовете на
командата (профили, ръбове, стени, оси) **не** са част от набора — те се избират всеки път
наново.

Наборите са **настройка на потребителя**, а не данни на документа. Пазят се в папката с
настройките на програмата и важат за всички проекти. В самия детайл се записва само
**името** на набора, с който е направена операцията (за Edit Feature).

## 2. Входни данни

- текущите стойности в панела на отворената команда;
- файлът с набори на командата в папката с настройки;
- при Edit Feature: името на набора, записано в операцията.

## 3. Настройки

### 3.1 Редът Preset

| Опция | Поведение в Inventor | Ограничения | При нас |
|---|---|---|---|
| Ред **Preset** най-горе в панела | падащ списък + бутон (+) „Create new preset“ + меню с настройки | в панела на всяка команда с набори | 🟡 `gui/presets.rs::preset_row`, под заглавието; чака визуална проверка |
| Падащ списък | No Preset, Last Used, наборите на потребителя, вградените | | 🟡 тези четири групи, вградените след разделител; чака визуална проверка |
| Избор от списъка | панелът се попълва със стойностите на набора; входовете остават | | 🟡 `PresetData::apply` (тест `applying_changes_exactly_the_stored_settings`); чака визуална проверка |
| Звездичка | `*Име` — стойност е сменена след избора / последния запис | | 🟡 `modified()`; чака визуална проверка |
| (+) Create new preset | записва текущите стойности под ново име; предлага име по подразбиране | името е уникално | 🟡 поле за име (`<Команда> 1`, `2`…), Enter/OK записва, Esc отказва; чака визуална проверка |
| Hide Presets (меню на панела) | скрива целия ред | | ⬜ |

### 3.2 Менюто с настройки (бутон `...`)

| Опция | Поведение в Inventor | Ограничения | При нас |
|---|---|---|---|
| **Save Current** | презаписва избрания набор с текущите стойности | не за вградени | 🟡 сива при вграден / No Preset / Last Used; чака визуална проверка |
| **Rename Current** | ново име на избрания набор; Esc връща старото | не за вградени | 🟡 поле за име, Esc отказва; чака визуална проверка |
| **Delete Current** | изтрива избрания набор | не за вградени | 🟡 след изтриване: No Preset; чака визуална проверка |
| **New <Command> Default → Last Used** | нова команда започва с последно ползваните стойности | по подразбиране | 🟡 тест `start_follows_the_new_default`; чака визуална проверка |
| **New <Command> Default → Use Current Preset** | нова команда започва с избрания набор | | 🟡 „избраният“ е последният избран именуван набор; ако го няма — No Preset |
| **New <Command> Default → No Preset** | нова команда започва с фабричните стойности | | 🟡 фабричните = стойностите на командата без набор |
| Sort → **Recently Used** | по последно ползване (най-новият горе) | | 🟡 тест `sort_orders`; чака визуална проверка |
| Sort → **Date created** | от най-стария към най-новия | | 🟡 |
| Sort → **Alpha-Numeric** | числата първи, после по азбучен ред | | 🟡 сравнение без главни/малки, числата в името по стойност |
| Sort → **Last modified** | по последна промяна (най-новият горе) | | 🟡 |
| Show built-in presets | вградените могат да се скрият | | 🟡 отметка в менюто; чака визуална проверка |

### 3.3 Поведение при стартиране и редакция

| Опция | Поведение в Inventor | Ограничения | При нас |
|---|---|---|---|
| Нова команда | списъкът показва **Last Used**, ако командата е ползвана преди, иначе **No Preset** | | 🟡 `CommandPresets::start`; Last Used се пази между сесиите |
| Last Used | временен набор: последните стойности, с които е натиснат OK / Apply | | 🟡 записва се при успешен OK / Apply на нова операция (не при Edit Feature) |
| No Preset | фабричните стойности; за Extrude/Revolve булевата операция е последната ползвана | | 🟡 при нас операцията остава предложената (Join при тяло, New Solid без тяло) |
| Edit Feature | показва набора, с който е направена операцията; ако е от Last Used / стара — No Preset | | 🟡 името от `preset` на операцията (тест `edit_feature_shows_the_preset_it_was_made_with`); ако наборът вече го няма — No Preset |
| Стара операция със сменени стойности → Custom | | | ⬜ показваме No Preset |
| Predict Boolean | предложената операция бие тази от набора | Extrude/Revolve | 🟡 без тяло (нищо за Join/Cut) остава New Solid |
| Вградени набори | метрични и инчови според единиците на документа; само за четене; могат да станат основа за свой | | 🟡 само метрични (документите ни са в mm); основа за свой — избери вградения, смени, (+) |
| Допуски в набора | допускът на стойност се пази с набора | | ⬜ полетата на операциите още нямат допуски |
| Surface mode | наборите на операции, правещи тела, пазят и Solid/Surface | | 🟡 `output` за Extrude / Revolve |
| Конфликт със стил | набор, несъвместим със стила, е сив | | ⛔ няма стилове |

### 3.4 Какво пази наборът на всяка команда

Пази се JSON обектът на операцията, **само** с ключовете от списъка. Всичко останало
(id, име, скица, профили, ос, ръбове, стени, тела, имената на параметрите) не влиза.
За полета с израз се пази **текстът на израза** (`params: {"distance": "wall*2"}`), а
стойността — като число. При прилагане изразът се изчислява наново в текущия документ; ако
там няма такъв параметър, остава записаното число и излиза предупреждение.

| Команда | Пази | Не пази (входове) | При нас |
|---|---|---|---|
| Extrude | `extent` (Distance / To Next / Through All), `distance`, `distance_b`, `direction`, `taper`, `taper_b`, `operation`, `output`, изразите | профили, скица, `To` лице/връх, `from`, `solids` | 🟡 тест `strip_inputs_leaves_out_the_inputs` |
| Revolve | `extent`, `angle`, `angle_b`, `direction`, `operation`, `output`, изразите | профили, скица, ос, `solids` | 🟡 |
| Fillet | `kind` (радиус), `fillet_type`, `smooth`, `cone_corners`, израза на `radius` | ръбове, допълнителните набори ръбове (`sets`), променливите радиуси, средната стена на Full Round | 🟡 радиусите на допълнителните набори не се пазят |
| Chamfer | `kind` (метод, разстояния, ъгъл, flip), `cone_corners`, изразите | ръбове, частичната фаска | 🟡 |
| Shell | `thickness`, `direction`, `chain`, изразите | Remove Faces, `solids` | 🟡 |
| Face Draft | `draft_type`, `angle`, `flip`, `chain`, изразите | посоката на изваждане, равнината, стените | 🟡 наше разширение: в Inventor Draft е диалог без набори |
| Work Plane (Offset) | в Inventor работните равнини нямат набори | | ⛔ не е команда с набори в Inventor |
| Hole, Pattern | в Inventor имат набори | | ⬜ една реализация на `PresetData` за всяка (вж. §6) |

### 3.5 Вградени набори (метрични, само за четене)

| Команда | Набори |
|---|---|
| Extrude | `Extrude 10 mm`, `Cut Through All`, `Symmetric 20 mm` |
| Revolve | `Revolve 360°`, `Revolve 180° Symmetric` |
| Fillet | `Fillet 1 mm`, `Fillet 2 mm`, `Fillet 5 mm` |
| Chamfer | `Chamfer 0.5 x 45°`, `Chamfer 1 mm` |
| Shell | `Shell 2 mm Inside`, `Shell 1 mm Outside` |
| Face Draft | `Draft 1°`, `Draft 3°` |

## 4. Поведение в дървото и при редакция

- Операцията пази само името на набора (`preset`), нищо друго. Ако наборът бъде
  преименуван или изтрит, операцията не се променя; Edit Feature показва No Preset.
- Стойностите на операцията са нейни: Edit Feature **не** прилага набора наново, само го
  показва в списъка (със звездичка, ако стойностите вече се различават).
- Ако при Edit Feature се избере друг набор и се натисне OK, операцията запомня новото име.

## 5. Крайни случаи и грешки

- Повредена папка или файл (невалиден JSON): предупреждение `Presets: <файл> is damaged
  (…); it is kept as <файл>.bak at the next save`. Командата работи със списък без
  потребителски набори; при първия запис старият файл се мести в `.bak`, не се губи.
- Файл само за четене: предупреждение `Presets: <файл> is read-only; changes are not saved`.
  Наборите от него се ползват, промените остават до края на сесията.
- Запис, който не успее (няма права, пълен диск): предупреждение, програмата продължава.
- Записът е атомарен: временен файл до целевия, после преименуване.
- Име: празно, вече заето (и от вграден), `No Preset` или `Last Used` → `Presets: …` грешка,
  нищо не се променя.
- Вграден набор: Save / Rename / Delete са сиви; извикани отвън — грешка, нищо не се
  променя.
- Набор от по-нова версия с непознат ключ: ключът се пропуска, останалото се прилага.
- Стойност от грешен вид (напр. текст вместо число): прилагането се отказва с грешка
  `<Command>: the preset does not fit this command (…)`, панелът остава какъвто е бил.
- Ако папка с настройки няма (няма `APPDATA` / `HOME`), наборите живеят само в паметта.

## 6. Как е реализирано при нас

- `src/presets.rs` (без GUI, тества се с временна папка):
  - `PresetData` — трейт за дефиницията на операция: `KEYS` (ключовете на настройките),
    `strip_inputs` (входове, скрити в настройка, напр. `extent: To(лице)`), `capture`,
    `apply`, `preset_name` / `set_preset_name`, `to_feature` / `from_feature`;
  - `apply_in(part, def, settings)` прилага и преизчислява изразите в документа;
  - `CommandPresets` — наборите на една команда, Last Used, New Default, Sort, броячи за
    „създаден / сменен / ползван“;
  - `PresetStore` — един JSON файл на команда (`<Command>.json` без интервали) в
    `%APPDATA%\3dcadcraft\presets` (Windows) или `~/.config/3dcadcraft/presets`;
    `CADCRAFT3D_PRESETS_DIR` го пренасочва (тестове, скриптове);
  - `builtins(command)` и `factory(command)`.
- `gui/presets.rs`: `PresetUi` (състоянието на реда за всяка команда) и куките
  `preset_row`, `preset_start`, `preset_edit`, `preset_stamp`, `preset_used`.
- Операциите имат поле `preset: Option<String>` (`#[serde(default, skip_serializing_if =
  "Option::is_none")]`): стари версии го пропускат, файлът без набор е байт по байт същият —
  затова не се вдига `FORMAT_REVISION`.
- **Нова команда с набори** (Hole, Pattern…): `impl PresetData for HoleFeature` в
  `presets.rs` (ключове + `strip_inputs`), `builtins`/`factory` за името на командата, и
  четирите куки в GUI: `preset_start` при старт, `preset_edit` при Edit Feature,
  `preset_row` под заглавието на панела, `preset_stamp` + `preset_used` при OK.
