# 6.2 Bolted Connection

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ blocked by another feature.

## 1. Purpose

A bolted joint is placed as one object: the user picks where it goes and through what, picks the
fasteners, and the command drills matching holes through every component between the start and the
termination, places the bolt, the washers and the nut from the Component Library with relationships, and
keeps all of it together so it can be edited or deleted as a whole. It is the first generator of the
Design tab (Inventor's Design Accelerator, FEATURES 6.2). The strength check (Calculation tab) is a separate
row group (§3.7) and comes later.

Ribbon: assembly **Design › Fasten › Bolted Connection**, alias `BC`, command id `design.bolted`.

## 2. Inputs

- a **start plane**: a planar face (or work plane) of a component; the bolt's head side, and the
  direction of the connection (into the material, against the face's outward normal);
- the **position** of the bolt axis on that plane, by one of four placements (§3.2);
- a **termination**: the planar face where the connection ends — the far side of the stack for Through All
  (the nut side), the face where the threaded hole starts for Blind;
- the **thread** (standard, diameter);
- the **fasteners**: a stack of rows (head-side washers, the bolt, nut-side washers, nuts).

Everything between the start plane and the termination along the axis is the **plate stack**: its total
thickness is the grip, its components are the participants of the holes.

## 3. Settings

### 3.1 Type

| Option | Inventor behaviour | Restrictions | Our status |
|---|---|---|---|
| **Through All** | clearance holes through every component between start and termination; the bolt passes through and a nut (with washers) holds it on the far side | at least one component | ⬜ |
| **Blind** | clearance holes through the components from the start plane down to a *blind start plane*; the last component gets a tapped hole starting at that plane; no nut | needs two or more components (one component: only Through All) | ⬜ |
| Countersunk screws | a countersunk bolt gets a countersunk seat in the first component | the bolt row decides | ⬜ |

### 3.2 Placement

| Option | Inventor behaviour | Selectors (in order) | Our status |
|---|---|---|---|
| **Linear** | the axis on the start plane at distances from two straight edges; a 3D grip per distance in the view | Start Plane, Linear Edge 1, Linear Edge 2, Termination | ⬜ |
| **Concentric** | the axis through the centre of a circular edge | Start Plane, Circular Reference, Termination | ⬜ |
| **On Point** | one connection per selected point (sketch points of a part sketch, work points); all points of a sketch at once, Ctrl+click adds / removes one | Start Plane, Point, Termination | ⬜ |
| **By Hole** | the axis of an existing hole; the hole also fixes the direction and the largest diameter that fits | Start Plane, Existing Hole, Termination | ⬜ |
| **Follow Pattern** | By Hole only, when the hole is one of a pattern (a Hole feature with several centres, or a patterned hole): a connection in every hole of it; inserting again replaces the earlier connections of that pattern | check box, enabled for By Hole on a patterned hole | ⬜ |
| Distances (Linear) | two values, the grips in the view edit them | expression fields (rule 13) | ⬜ |

The fastener list stays disabled until the placement is complete (start, reference, termination).

## 4. Browser and editing

| Item | Inventor behaviour | Our behaviour | Our status |
|---|---|---|---|
| Browser node | one node per connection (`Bolted Connection:1`) holding its fasteners | a node *Bolted Connection N* with its fasteners below it; the fasteners are ordinary occurrences (picking, BOM) | ⬜ |
| **Edit** | right click › Edit Using Design Accelerator: the dialog with the stored inputs; add / remove fasteners, length, points | *Edit Bolted Connection* on the node or a fastener: the panel opens on the connection; OK replaces it as one Undo step | ⬜ |
| **Delete** | deleting the bolt removes all of the connection's fasteners | Delete on the node or any of its fasteners removes the fasteners, their relationships and the holes | ⬜ |
| Moved points | a moved sketch point moves its connection | the relationships follow the point / hole | ⬜ |
| BOM | each fastener is a BOM row of its own (the library's part number) | ordinary occurrences: rows by part number, quantities summed | ⬜ |
| Holes | Inventor writes the holes into the components' own parts | **ours: assembly features** (spec 3.10 §3.8): one tool body per connection in the tools part, the components between start and termination its participants; the part documents are never changed (owner's choice: a library part or a part used elsewhere stays whole) | ⬜ |

### What is stored

`AssemblyDocument::bolts: Vec<BoltedConnection>` (format revision 65), each:

- `id` (never reused), `name`;
- `kind` (Through All / Blind), `placement` (Linear with two edges and two distances, Concentric with a
  circular edge, On Point with points, By Hole with the hole and `follow_pattern`) as `GeomRef`s;
- `start`, `end` (`GeomRef` planes); `thread` (standard, diameter);
- the stack: each row the library family by standard + designation and the member, its role
  (washer under the head, bolt, washer under the nut, nut);
- the fasteners' occurrence ids and the relationships they got (per axis);
- the tool body's name in the tools part.

The fasteners themselves are ordinary occurrences linked to library member files, so the BOM, drawings
and old builds' BOM see them; the connection only groups them.

## 5. Edge cases and errors

| Case | Behaviour |
|---|---|
| Termination not parallel to the start plane | `Bolted Connection: the termination must be parallel to the start plane` |
| Termination on the wrong side | `Bolted Connection: the termination lies behind the start plane` |
| Nothing between start and termination | `Bolted Connection: no component between the start plane and the termination` |
| Blind with one component | Blind disabled; `Bolted Connection: a blind connection needs two components` |
| No fastener fits the diameter / grip | the row lists nothing; OK refuses `Bolted Connection: no <family> of length ≥ <l> mm` |
| By Hole: the hole smaller than the diameter's clearance | the diameter list stops at what fits; a larger one: `Bolted Connection: Ø<d> does not fit the Ø<h> hole` |
| A referenced face / edge / hole lost later | the connection's node gets health (rule 8), its fasteners stay where they were |
| A library member file cannot be written | nothing changes (rule 5), the error is reported |
| Solve fails after placing | the whole OK is undone (`asm_try`) |

## 6. Implementation

- Data: `assembly::bolted` (`BoltedConnection`, `BoltKind`, `BoltPlacement`, `StackRow`), GUI-free:
  the axis from the placement, the plate stack by casting the axis through the components
  (`PickMesh`), hole diameters from `data/standards/clearance_holes.csv` (Normal fit) and the tap drill
  from the thread tables, the bolt length from `fit::Stack::length_for`.
- Holes: assembly features (`assembly::features`): a body per connection in the tools part, named
  `Bolt<id>`; Follow Pattern: one body per hole of the pattern (one Boolean through `union_apart`).
- Fasteners: placed like Smart Drop's Bolted Connection (`gui/smart_drop.rs`: `seat_transform`,
  Mate of the axis, Flush / Mate of the seat with an offset), committed through `asm_try`.
- GUI: the planned panel (`gui/asm_planned.rs` `AsmPlanned::BoltedConnection`) gets its logic
  (`Planned::has_logic`, rule 18); right-click menu of a planar face and of a hole (rule 17);
  Next / Back through the panel's `Flow` (rule 21).
