# 4.15 Section participation (which components a section view cuts)

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ blocked by another feature.

## 1. Purpose

A section view through an assembly cuts most components, but drawing practice (ISO 128-50 / ISO 128-44)
leaves solid round and standard parts uncut when the cutting plane runs along them: bolts, screws, nuts,
washers, pins, keys, rivets, shafts. Inventor shows such components whole in the section and lets the
designer change it per component and per view. This spec describes where that choice lives and in what
order the settings win.

## 2. Inputs

- An assembly section view (spec 4, Section View; offset and aligned sections included).
- The components of the view's model at any depth (subassemblies are walked; a setting on a
  subassembly occurrence reaches the parts inside).

## 3. Settings

**Precedence** (first that is set wins): the view's override of that component (or of a subassembly above
it) › the view's Section Standard Parts when Never / Always and the part is a standard part › the
assembly occurrence (the part's own, then each subassembly above it) › the part's Properties › the
category default.

## 4. Browser and editing

- A component not cut in a section view is tagged *(not cut)* in that view's component list; a view
  override is tagged *(view)*.
- Changing participation is one Undo step and recomputes the view's lines (the cache key includes the
  list of components left whole).
- Other views of the same model are untouched: a bolt can be cut in one section and whole in another.

## 5. Edge cases

- An uncut component is drawn whole, also the part of it on the removed side of the cutting plane, and
  its outline hides what lies behind it like any body.
- Hatching: each cut component is hatched on its own (loops of one component are never joined with a
  touching neighbour's); neighbouring components alternate the hatch direction (45° / 135°) so their
  boundary reads. ✅ visually checked (plate 45°, pin 135°).
- Where the plane meets a component left whole (a pin Ø8 in a tapped M8 hole drilled Ø6.8) its section
  covers the cut face: no hatching there (`ViewLines::section_cover`). ✅ visually checked.
- Files written before this feature have no settings: their sections look as before except that library
  parts and generated shafts are now drawn whole (the category default).

## 6. Implementation

- `document::iprops::SectionParticipation` (Default / Section / None), on `IProperties` (part) and on
  `Occurrence` (assembly), both `serde(default)`, skipped when Default (no format revision: old builds
  ignore the field).
- `drawing::participation`: `StandardSection` (view option), `ParticipationOverride` (per view, by
  occurrence path), `Leaf` + `cut` (the precedence), `prefix` (the instance prefix of edge names).
- `hlr::Aligned::uncut` (instance prefixes) and `ViewModel::mesh_owner`: uncut meshes and their edges /
  silhouettes are not clipped and give no cut faces; crossings are chained per component;
  `ViewLines::section_owner` gives each hatched loop its component for alternating hatch angles.
- GUI: `gui/drawing_participation.rs` (leaves → `Leaf`s, the menus, the Properties list).
