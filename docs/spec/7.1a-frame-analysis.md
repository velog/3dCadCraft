# 7.1a Frame Analysis

Status: FA1-FA4 done, FA5 partly (2026-11-09). Level 7.1. Reference: Autodesk Inventor 2027, Environments › Frame
Analysis (functional reference only).

## 1. Purpose

A linear analysis of the frames of an assembly as **beams**: the members become straight beams on their
centroid axes joined at nodes, the user adds constraints and loads, and the solver gives displacements,
section forces, stresses and natural frequencies, with diagrams along each beam. It answers "will this
frame carry that load" in seconds, without a solid mesh; solid stress analysis stays 7.1.

## 2. Inputs

- An assembly with frames of Frame Generator (6.1). Its members' sections and materials come from the
  frame; a simulation can override them per beam.
- Constraints and loads are placed on beams or nodes.

## 5. Edge cases and errors

- A model that can still move: `Simulate: the frame can move freely: add constraints.` Nothing is changed.
- No straight member: `Frame Analysis: the frame has no straight members.`
- A beam released about the same axis at both ends with no stiffness left: refused.
- A load beyond the beam's end is clamped to its end.

## 6. Implementation

- `analysis::beam`: GUI-free solver. Straight prismatic Euler-Bernoulli beams, six unknowns per node,
  static condensation of releases, rigid links by eliminating the child's unknowns, skyline L·D·Lᵀ with
  reverse Cuthill-McKee ordering; modes by subspace iteration on the consistent mass matrix. Loads inside a
  beam cut it at their stations; between stations the curve is exact (cubic + the uniform load's own curve).
- Shear deformation is left out (Euler-Bernoulli): deviation until Inventor's choice is confirmed.
- Results recover the section forces by statics of the piece from the beam's start to the cut.
- Simulate solves on a worker thread from a copy of the converted model (a large modal run takes seconds); the run
  is dropped when the simulation changes meanwhile.
- Every panel has Next and Back in the right-click menu (rule 21): its location or beam, then its values at the cursor.

Stages: FA1 solver · FA2 conversion and data model · FA3 environment and panels · FA4 results in the view
and Beam Detail · FA5 modal, report.
