# 1.11 Sketch text

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ blocked by another feature.

## 1. Purpose

Text in a sketch, in any installed font, whose letters are closed profiles: extrude it, emboss it,
cut it. Inventor: Sketch › Create › Text (and Geometry Text along a curve).

## 2. Inputs

A click for the place (its top left), then the panel. A double click on a text (or Edit Text in the
view's menu) opens it again.

## 4. Browser and editing

- A text stands on a **construction line** of the sketch: its start is the top left, its direction the
  writing direction. Constraints and dimensions on that line place and turn the text. (Inventor: the
  corner point of the text box.) ✅
- Deleting that line deletes the text. ✅
- A later edit of the text changes its profiles; a feature's profile follows by the point inside it. 🟡
  a much changed text can lose a profile: select the profiles again.

## 5. Edge cases and errors

- A missing font: the part still builds (the outlines are stored, rule 8); Edit Text keeps the name in
  the list and refuses OK until another font is chosen.
- A letter with overlapping contours (some variable fonts): the extrusion overlaps as the font does. ⬜

## 6. Implementation

- `sketch/text.rs`: `SketchText` (spec, stored outlines, line), `layout`, regions (`Sketch::regions` adds
  them after the curves' regions), `GlyphSource`. `sketch/fonts.rs`: finding faces in the system's font
  folders, `ttf-parser`. A quadratic curve of TrueType is raised to the same cubic.
- A font's curves become **arcs** within 0.0002 x size of the curve for the profile (B-spline walls: one
  word on a plate 9.6 s and refused over the plate's edge; arcs 3.4 s and exact; lines 106 s for one letter
  over the edge). The volumes agree with the exact outlines within 0.01 mm3 per word.
- **Deviation:** Inventor's outlines come through the system's hinting; ours are the font file's own
  curves. Areas differ per letter: within 0.2 % for most (T, e, H, O), 2 % for an Arial x. The sizes and
  positions agree.
- Line pitch at single spacing is 1.5737 x size (Inventor's value for Arial; it is the same factor for
  every font here, a small deviation).
- All side faces of a text carry the line's key in their names (`<feature>:Side:<line>:<k>`), repeated
  from letter to letter: a reference to one letter's wall is found through its point.
- GUI: `gui/sketch_text.rs`. Format revision 63.
