# 2.13 Combine и Split (тела и стени)

Статус: ✅ готово · 🟡 частично · ⬜ предстои · ⛔ чака друга функция.

## 1. Предназначение

**Combine** събира тела на един детайл с много тела: едно тяло е основа, другите са
инструменти. Резултатът е Join (сбор), Cut (основата без инструментите) или Intersect
(само общият обем).

**Split** реже с инструмент (скица, работна или основна равнина, повърхнина):
- **Split Face** дели само стените. Тялото не се променя, но една стена става две и всяка може
  да се наклони отделно (Face Draft), да се изтрие и т.н.;
- **Trim Solid** маха едната страна на тялото;
- **Split Solid** оставя и двете страни като две отделни тела.

## 2. Входни данни

- **Combine:** Base (едно твърдо тяло), Toolbodies (едно или повече други твърди тела),
  операция, Keep Toolbody.
- **Split:** метод (Split Face / Trim Solid / Split Solid), инструмент (Split Tool), стени
  или тяло, страна (за Trim Solid).

## 3. Настройки

### 3.1 Combine

| Опция | Поведение в Inventor | Ограничения | При нас |
|---|---|---|---|
| Команда | 3D Model → Modify → Combine | само в детайл с много тела | ⬜ |
| **Base** | селекторът е активен при отваряне; щракнато тяло става основа. Ако телата имат различен външен вид, резултатът носи вида на основата | едно тяло | ⬜ |
| **Toolbodies** | селекторът се активира сам след основата; едно или повече тела; броят се показва в селектора; изборът с рамка ускорява много тела | не основата | ⬜ |
| Цветна точка на селектора | изпълненият селектор има точка в цвета на подсветката в изгледа | | ⬜ |
| **Join** | основата и инструментите се сливат | | ⬜ |
| **Cut** | инструментите се изваждат от основата | | ⬜ |
| **Intersect** | от основата остава само общото с инструментите | | ⬜ |
| **Keep Toolbody** | инструментът остава като отделно тяло, но се скрива след операцията. Без отметката той се „изразходва“ и не може да участва в други операции | | ⬜ |
| Видимост на инструментите | бутон за видимост държи телата-инструменти видими за следващ избор | | ⬜ |
| Изтриване на Combine | изразходваните инструменти се връщат; запазените остават скрити | | ⬜ |
| OK / Apply / Cancel | Apply създава операцията и оставя командата отворена | | ⬜ |

### 3.2 Split

| Опция | Поведение в Inventor | Ограничения | При нас |
|---|---|---|---|
| Команда | 3D Model → Modify → Split | | ⬜ |
| **Split Face** | стените се делят по линията, където инструментът ги среща; тялото остава същото | | ⬜ |
| Инструмент на Split Face | 2D скица, 3D скица, работна равнина или повърхнина | 3D скицата трябва да лежи върху стените и да ги пресича изцяло | ⬜ |
| **Faces** | избор на стени на тяло или повърхнина | | ⬜ |
| **All Faces** + тяло | делят се всички стени на избраното тяло | | ⬜ |
| **Keep sketch visible on (+)** | (Advanced Settings) скицата остава видима след Apply | | ⬜ |
| Face Draft след Split Face | всяка част на разделената стена може да се наклони отделно | | ⬜ |
| **Trim Solid** | тялото се реже с инструмента и едната страна се маха | | ⬜ |
| Keep Default / Keep Flip | стрелка в прегледа сочи страната, която се маха; Default пази другата, Flip — тази | | ⬜ |
| **Split Solid** | тялото става две тела (Keep Both) | | ⬜ |
| Тяло (Solid) | при едно тяло — то само; при няколко — избор | | ⬜ |
| Инструмент на Trim / Split Solid | работна равнина, 2D скица или повърхнина | | ⬜ |
| OK / Cancel | | | ⬜ |
| Два детайла от един | Save Copy As, после Split с обратната страна | не са асоциативни | ⬜ (Save Copy As е отделна функция, 0.6) |

## 4. Поведение в дървото и при редакция

| Поведение | Inventor | При нас |
|---|---|---|
| Ред в дървото | Combine1 / Split1 в историята; скицата-инструмент е вложена под Split | ⬜ |
| Solid Bodies | броят се обновява: изразходваните инструменти изчезват, Split Solid добавя тяло | ⬜ |
| Edit Feature | диалогът се отваря с входовете; детайлът се показва както преди операцията | ⬜ |
| Delete | Combine: инструментите се връщат; Split: телата и стените се връщат | ⬜ |
| Повторение в масив | Combine и Split не се повтарят сами (Inventor ги повтаря само като част от тяло) | ⬜ |

## 5. Гранични случаи и грешки

| Случай | Поведение | При нас |
|---|---|---|
| Детайл с едно тяло | Combine не е достъпна (няма инструмент) | ⬜ |
| Основата е и инструмент | отказ | ⬜ |
| Cut без допир | отказ: инструментът не пресича основата | ⬜ |
| Intersect без общ обем | отказ | ⬜ |
| Инструментът не реже тялото | Split Solid / Trim Solid: отказ | ⬜ |
| Стена, която инструментът не среща | Split Face: отказ, с името на стената | ⬜ |
| Тяло с кухина | ⬜ ядрото не дели тела с кухини | ⬜ |
| Инструмент по протежение на стена | ⬜ ядрото отказва | ⬜ |
| Реж през конуса на фаска (SolidCraft #1691) | обемите на частите се събират | ⬜ |
| Отказ | детайлът остава непроменен | ⬜ |
