# 2.13 Combine и Split (тела и стени)

Статус: ✅ готово · 🟡 частично · ⬜ предстои · ⛔ чака друга функция.

Всички реализирани редове са 🟡: проверени с тестове (`tests/combine_split.rs`), чакат визуална
проверка в приложението.

## 1. Предназначение

**Combine** събира тела на един детайл с много тела: едно тяло е основа, другите са
инструменти. Резултатът е Join (сбор), Cut (основата без инструментите) или Intersect
(само общият обем).

**Split** реже с инструмент (скица, работна или основна равнина, повърхнина):
- **Split Face** дели само стените. Тялото не се променя, но една стена става две и всяка може
  да се наклони отделно (Face Draft), да се изтрие и т.н.;
- **Trim Solid** маха едната страна на тялото;
- **Split Solid** оставя и двете страни като две отделни тела.

## 2. Входни данни

- **Combine:** Base (едно твърдо тяло), Toolbodies (едно или повече други твърди тела),
  операция, Keep Toolbody.
- **Split:** метод (Split Face / Trim Solid / Split Solid), инструмент (Split Tool), стени
  или тяло, страна (за Trim Solid).

## 3. Настройки

### 3.1 Combine

| Опция | Поведение в Inventor | Ограничения | При нас |
|---|---|---|---|
| Команда | 3D Model → Modify → Combine | само в детайл с много тела | 🟡 бутон в Modify; при едно тяло командата отказва със съобщение (в Inventor бутонът е неактивен); чака визуална проверка |
| **Base** | селекторът е активен при отваряне; щракнато тяло става основа. Ако телата имат различен външен вид, резултатът носи вида на основата | едно тяло | 🟡 клик върху стена избира тялото ѝ; тяло, избрано преди командата, става основа; резултатът носи името на основата, затова и външния ѝ вид (тест `combine_keeps_the_base_appearance`); чака визуална проверка |
| **Toolbodies** | селекторът се активира сам след основата; едно или повече тела; броят се показва в селектора; изборът с рамка ускорява много тела | не основата | 🟡 автоматичен преход, брой в реда, втори клик маха тяло; ⬜ избор с рамка |
| Цветна точка на селектора | изпълненият селектор има точка в цвета на подсветката в изгледа | | 🟡 общ модул `command_ui` (§4.1 на 0-ui) |
| **Join** | основата и инструментите се сливат | | 🟡 2–4 тела, аналитични обеми |
| **Cut** | инструментите се изваждат от основата | | 🟡 инструмент без допир: отказ |
| **Intersect** | от основата остава само общото с инструментите | | 🟡 без общ обем: отказ |
| **Keep Toolbody** | инструментът остава като отделно тяло, но се скрива след операцията. Без отметката той се „изразходва“ и не може да участва в други операции | | 🟡 запазеното тяло влиза в `PartDocument::hidden_bodies` (не се рисува, не се избира); изразходваното изчезва от Solid Bodies и от изборите Solids |
| Видимост на инструментите | бутон за видимост държи телата-инструменти видими за следващ избор | | 🟡 отметка „Keep toolbodies visible“; в дървото тялото има Visibility в контекстното меню |
| Изтриване на Combine | изразходваните инструменти се връщат; запазените остават скрити | | 🟡 регенерацията просто не ги изразходва (тест `deleting_combine_restores_the_tools`) |
| OK / Apply / Cancel | Apply създава операцията и оставя командата отворена | | 🟡 Apply пази операцията и Keep Toolbody, селекторите се изчистват |

### 3.2 Split

| Опция | Поведение в Inventor | Ограничения | При нас |
|---|---|---|---|
| Команда | 3D Model → Modify → Split | | 🟡 бутон в Modify; методът е радио бутон в панела и в контекстното меню |
| **Split Face** | стените се делят по линията, където инструментът ги среща; тялото остава същото | | 🟡 `sk::split_faces_with_map`; парчетата се казват `<стена>~<id>.<k>`, `k` от задната страна на равнината |
| Инструмент на Split Face | 2D скица, 3D скица, работна равнина или повърхнина. Основните равнини са работни равнини (в API на Inventor инструментът е WorkPlane, WorkSurface, SurfaceBody или Path); стена на модела **не** е инструмент (потребителите правят работна равнина върху нея) | 3D скицата трябва да лежи върху стените и да ги пресича изцяло | 🟡 работна/основна равнина и 2D скица (линии, дъги, окръжности, сплайни; свързаните криви са една верига); повърхнина от **една** стена (Extrude / Revolve с Output Surface): повърхнината ѝ се удължава (`SplitTool::Face`), парчетата се номерират от гърба ѝ; ⬜ повърхнина от няколко стени (отказ „not supported yet: a surface of several faces“ — всяка удължена стена би режела и извън повърхнината); ⬜ 3D скица (няма 3D скици) |
| **Faces** | избор на стени на тяло или повърхнина | | 🟡 клик добавя, втори клик маха; стена, която инструментът не среща: отказ с името ѝ |
| **All Faces** + тяло | делят се всички стени на избраното тяло | | 🟡 стените, които равнината пресича, се намират по триъгълниците им; при скица — по обхващащата кутия и после по отговора на ядрото |
| **Keep sketch visible on (+)** | (Advanced Settings) скицата остава видима след Apply | | 🟡 отметка в „Advanced Settings“ на панела; иначе скицата се скрива и се вписва под Split в дървото |
| Face Draft след Split Face | всяка част на разделената стена може да се наклони отделно | | 🟡 Face Draft на парче се прави отделно (`split::draft_pieces`: призма между старата и наклонената равнина се изрязва или добавя), защото наклонът на ядрото за изпъкнали тела наклонява цялата равнина; обемите съвпадат точно (тест `split_face_then_face_draft_on_one_piece`, ±5°, горно и долно парче) |
| **Trim Solid** | тялото се реже с инструмента и едната страна се маха | | 🟡 |
| Keep Default / Keep Flip | стрелка в прегледа сочи страната, която се маха; Default пази другата, Flip — тази | | 🟡 стрелката е по нормалата на инструмента (при Flip — обратно); Default маха предната страна. Повърхнина: стрелката стои в най-близката до центъра на тялото точка на повърхнината, по нормалата ѝ; отворена верига: в средата ѝ, наляво |
| Избор на инструмента | селекторът приема работни и основни равнини, скици и повърхнини в изгледа и в дървото; основните равнини се показват временно | | 🟡 изгледът: работни и основни равнини (основните се рисуват, докато селекторът е активен, посочената свети), криви на скица, стени на повърхнинно тяло (жълти); дървото: Origin → XY / XZ / YZ, ред на работна равнина, ред на скица, Surface Bodies → повърхнина; подсветка само на това, което селекторът приема; стените на модела не са инструмент (както в Inventor) |
| **Split Solid** | тялото става две тела (Keep Both) | | 🟡 задната част пази името на тялото, предната е новото тяло `<id>#2` (Solid2…); няколко парчета от една страна са едно тяло с няколко части |
| Тяло (Solid) | при едно тяло — то само; при няколко — избор | | 🟡 |
| Инструмент на Trim / Split Solid | работна равнина, 2D скица или повърхнинно тяло (често се ползва повърхнина за Split Solid). При 3D крива Trim Solid и Split Solid са забранени | | 🟡 работна/основна равнина; скица с една права линия (равнината през нея, перпендикулярна на скицата); скица със затворени контури (призма през тялото: вън = отзад, вътре = отпред); **отворена верига** — сплайн, линии и дъги (краищата продължават по допирателните до рамка около тялото, областта отляво на посоката на кривата е предната страна; призма през тялото); повърхнина (Extrude / Revolve с Output Surface, една или няколко стени): всяка стена, която стига до кутията на тялото, реже с удължената си повърхнина (`sk::split_body` + `SplitTool::Face`), частите се разпределят по страната на повърхнината (най-близкият ѝ триъгълник) и частите от една страна се съединяват; ⬜ quilt от Sweep / Loft / Stitch (те още нямат Surface изход) |
| Отказ за крива, която не може да реже | | | 🟡 затворена крива, която се самопресича (осморка), или отворена, която пресича себе си или продължението си: `a curve of the sketch crosses itself …`; няколко отворени вериги или отворени заедно със затворени: изрично съобщение |
| OK / Cancel | | | 🟡 + Apply |
| Два детайла от един | Save Copy As, после Split с обратната страна | не са асоциативни | ⬜ (Save Copy As е отделна функция, 0.6) |

## 4. Поведение в дървото и при редакция

| Поведение | Inventor | При нас |
|---|---|---|
| Ред в дървото | Combine1 / Split1 в историята; скицата-инструмент е вложена под Split | 🟡 скицата е „изразходвана“ (`Feature::sketch`), вписва се под Split |
| Solid Bodies | броят се обновява: изразходваните инструменти изчезват, Split Solid добавя тяло | 🟡 скритите тела са с бледо име; Visibility в контекстното меню |
| Edit Feature | диалогът се отваря с входовете; детайлът се показва както преди операцията | 🟡 `rollback` + `replace_feature` |
| Delete | Combine: инструментите се връщат; Split: телата и стените се връщат | 🟡 |
| Повторение в масив | Combine и Split не се повтарят сами (Inventor ги повтаря само като част от тяло) | 🟡 не пазят `ToolSet`; масив на Combine/Split отказва „pattern the solid“ |
| Зависимости | | 🟡 парче `X~Split1.2` зависи и от Split1 (`history::names_feature`) |

## 5. Гранични случаи и грешки

| Случай | Поведение | При нас |
|---|---|---|
| Детайл с едно тяло | Combine не е достъпна (няма инструмент) | 🟡 съобщение `Combine: the part has one solid body …` |
| Основата е и инструмент | отказ | 🟡 |
| Cut без допир | отказ: инструментът не пресича основата | 🟡 |
| Intersect без общ обем | отказ | 🟡 |
| Инструментът не реже тялото | Split Solid / Trim Solid: отказ | 🟡 `the tool does not split the body` |
| Стена, която инструментът не среща | Split Face: отказ, с името на стената | 🟡 |
| Тяло с кухина | ядрото на SolidCraft не дели такива с `split_body` | 🟡 тогава се ползва `split_by_plane` (булеви операции с полупространства) |
| Инструмент по протежение на стена | ядрото отказва | 🟡 същото резервно решение |
| Реж през конуса на фаска (SolidCraft #1691) | обемите на частите се събират | 🟡 по оста и при z = 19 през конуса: сборът съвпада до 2·10⁻⁶ (тест) |
| Spiral (Coil) разделен с равнина (#793) | | ⛔ няма Coil (2.7) |
| Shell без едно парче на разделена стена | отваря само парчето | 🟡 известна грешка: shell на изпъкнало тяло в SolidCraft маха цялата равнина (7152 вместо 8088 mm³ в теста) |
| Отказ | детайлът остава непроменен | 🟡 `insert_feature_checked` |

## 6. Реализация

- `part/combine.rs`: `CombineFeature` (`Feature::Combine`): `base`, `tools` (лични имена на тела),
  `operation`, `keep_tools`; точен строеж `build_exact` (булеви операции по ред; резултатът носи
  името на основата), фасетиран `build_faceted` (BSP). `PartDocument::add_combine`,
  `hidden_bodies`, `body_visible`; `bodies_before` пропуска изразходваните тела.
- `part/split.rs`: `SplitFeature` (`Feature::Split`): `method`, `tool` (`SplitToolRef::Plane /
  Sketch / Surface`), `faces`, `all_faces`, `solid`, `flip`, `keep_sketch_visible`;
  `resolve_tool`, `sketch_chains`, `build_exact`, `draft_pieces` (наклон на парче).
  `PartDocument::add_split`.
- `kernel/exact.rs`: `SplitBy`, `split_faces` / `split_faces_lenient` (`sk::split_faces_with_map`),
  `split_by_plane` (`sk::split_body`, резерва `sk::split_by_plane`), `face_corners`,
  `ExactSolid::rename_prefix`.
- Имена: парче на стена `<стена>~<id>.<k>`; сечение `<id>:Cut` (задна или запазена част) и
  `<id>#2:Cut` (предна); при затворен контур `<id>:Cut:Side:<k>`; новото тяло `<id>#2`.
- GUI: `gui/combine_split.rs` (панели, избор, преглед, стрелка, OK/Apply), селекторите в
  `command/flow.rs` (`combine_selectors`, `split_selectors`), общото меню и Enter в
  `gui/command_ui.rs`; скритите тела се пропускат при рисуване и избор.
- Формат: ревизия 13 (12 е запазена за Sweep/Loft), фикстура `tests/compat/r13/`. Повърхнината като инструмент (`SplitToolRef::Surface`) и отворените вериги не добавят нищо ново във файла (вариантът е от ревизия 13; отворените криви на Extrude Surface са `ExtrudeFeature::open`), така че ревизията не се вдига.
- Точни повърхнини (`kernel/exact/sheet.rs`): `extrude_sheet`, `revolve_sheet` (SolidCraft), `ExactSolid::is_open` (полето `sheet` пази повърхнина, дори когато обвивката ѝ се затваря), `SheetSide` (коя страна на повърхнината е точка), `split_by_sheet`. При регенерация повърхнините не влизат в операциите на другите елементи (само Split ги вижда). Стени `<id>:Side:<сегмент>`.
- Отворени вериги: `split.rs::open_region` (продължения по допирателните, рамка обратно на часовника), `crosses_itself`.
