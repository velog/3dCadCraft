# 1.11a Insert AutoCAD File (DXF into a sketch)

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ waiting for another feature.

## 1. Purpose

Inventor's **Insert AutoCAD File** (Sketch tab › Insert panel › ACAD) brings the 2D geometry of an
AutoCAD drawing into the open sketch, so an existing drawing becomes profiles for features: a plate
outline, a gasket, a laser-cut part. The geometry is not linked to the file.

## 2. Inputs

- An open 2D sketch (part or drawing view sketch).
- A DXF file (Inventor also reads DWG; we read DXF only and name a DWG when one is picked).

## 4. Browser and editing

The geometry is ordinary sketch geometry: no browser node, no link to the file.

## 5. Edge cases and errors

- A DWG: "this is a DWG file, not a DXF: save the drawing as ASCII DXF and insert that".
- Binary DXF: named and refused. A file with no ENTITIES section: "not a DXF drawing".
- An empty model space, or no layer chosen: nothing changes (rule 5), the status line says why.
- Size caps: files over 256 MB, more than 500 000 entities, blocks nested deeper than 16 or expanding
  to too much work are refused, never a hang.

## 6. Implementation

- `sketch::dxf` (GUI-free): `read` → `DxfDrawing` (items with layers, the unit), adapted from
  SolidCraft `crates/io/src/dxf.rs` (MIT OR Apache-2.0; ATTRIBUTION.md); `Sketch::insert_dxf` with
  `InsertOptions` → `InsertReport`. Ellipses are kept in conjugate form `c + u cos t + v sin t`, which
  every block transform keeps exact.
- GUI `gui/insert_dxf.rs` (`DxfDraft`: the panel in Properties, the preview in the view), dialog purpose
  `InsertDxf` in `gui/files.rs`, command `sketch.insert_acad`.
- Tests: `sketch::dxf::tests` (units, bulges both ways, nested and arrayed blocks, layer 0, unequal
  scale, mirrored entities, ellipses, splines with knots, MTEXT codes, DWG / binary refusals; an
  inserted plate outline with a hole is one region; a rational quarter circle through points on it).
