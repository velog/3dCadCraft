# 5.8 Plastic part features — Grill, Boss, Rest, Snap Fit, Rule Fillet, Lip

Statuses: ✅ done and checked in the app, 🟡 partial (what is missing), ⬜ to do. Every row stays ⬜ / 🟡 until
it has been seen in the running app.

## 1. Purpose

Six commands of the *Plastic Part* panel that add the usual details of a thin-walled moulded part in one
feature each. All six are `BodyOp` variants (format revision 64), built with tools and Booleans on the exact
kernel. Each works on a target body (Solid selector; empty = the only / nearest one).

## 2. Inputs

| Command | Inputs |
|---|---|
| Grill | closed boundary profile; optional island profiles; rib and spar curves; all on planes parallel to the boundary |
| Boss | sketch points (From Sketch) or points + a direction (On Point) |
| Rest | closed profile on a plane between the wall's faces |
| Snap Fit | sketch points (From Sketch) or points + two directions (On Point) |
| Rule Fillet | rows: source (features or faces), rule, radius |
| Lip | path edges on a flat rim; guide face or pull direction |

A sketch pick carries the clicked point: a region, a curve or a point of that sketch is chosen by it. A sketch
picked as a whole gives every region / every Center Point.

## 3. Options

### Grill

| Option | Inventor's behaviour | Status |
|---|---|---|
| Boundary: Profile | closed outline, the only required sketch; direction from the profile towards the nearest point of the part along the plane's normal; outline + 10 % must lie on the part, no holes inside | ⬜ |
| Boundary: Thickness, Height, Outside Height | wall of the boundary; its height; its top above the part's surface | ⬜ |
| Island: Profile, Thickness | closed areas of material, same top and bottom as the boundary; ribs and spars stop at them; thickness 0 = solid | ⬜ |
| Rib: Profiles, Thickness, Height, Top Offset | centre lines, trimmed automatically; top offset below the boundary's top | ⬜ |
| Spar: Profiles, Thickness, Top Offset, Bottom Offset | second set of centre lines; offsets from the ribs' top and bottom | ⬜ |
| Draft: Angle | unsigned; outside faces stay neutral, walls widen inwards | ⬜ |
| Draft: Parting Element, offset | modelled as given | ⬜ shown, disabled |
| Flow Area | area of the openings, drafts ignored; shown in the panel | ⬜ |

### Boss

| Option | Inventor's behaviour | Status |
|---|---|---|
| Placement: From Sketch | points of one sketch; direction along the normal towards the nearest body; Flip; Offset from the sketch plane | ⬜ |
| Placement: On Point | points + a direction element | ⬜ |
| Type: Head / Thread | the screw-head or the thread side | ⬜ |
| Extent | to the next face of the target body; an error when none is reached | ⬜ |
| Fillet | constant radius where boss and ribs meet the body | ⬜ |
| Head: Counterbore | Wall Thickness, Shank Height, Clamp Height, Shank / Clamp / Head Diameter | ⬜ |
| Head: Countersink | the same + Countersink Angle | ⬜ |
| Head: drafts | Outer, Inner, Shaft, Clamp | ⬜ |
| Thread: Hole off | a solid post (Thread Diameter, Outer Draft) | ⬜ |
| Thread: Depth / Full Depth / Through | hole of the given depth / to the inner wall face / through the wall; Inner Draft | ⬜ |
| Ribs: Number, Thickness, Rib Draft, Shoulder Length, Top Offset, Flare Angle | around each boss | ⬜ |
| Ribs: Shoulder Radius, Rib Radius, Blend Radius | rounds on the shoulder, along the rib, at the boss | ⬜ |
| Ribs: Start Angle, Space Angle | first rib from the sketch's X axis; total angle divided by the number | ⬜ |

Head geometry, from the mating plane towards the wall (our reading of the names; Help gives only the list):
a plate *Shank Height* thick with the shank hole, a raised seat ring (*Clamp Diameter*, *Clamp Height*), the
head recess (*Head Diameter*) through the wall; outside diameter = head + 2 × wall.

### Rest

| Option | Inventor's behaviour | Status |
|---|---|---|
| Profile, Solid | closed profile | ⬜ |
| Flip | direction into the body | ⬜ |
| Thickness; Inside / Outside / Both Sides | thin wall on the chosen side of the profile (Both: half each) | ⬜ |
| Platform: Through All / Distance / To Surface + Offset | platform walls run to the wall of the body, a height or a surface | ⬜ |
| Landing: Distance / To Surface + Offset | the landing's place from the sketch plane or on a surface | ⬜ |
| Clearance | the walls above the landing; the space above it is cut through the whole body | ⬜ |
| Landing Taper, Clearance Taper | drafts of the platform and clearance walls | ⬜ |

A boundary whose projection leaves the body is refused (Inventor builds unwanted walls there).

### Rule Fillet

| Option | Inventor's behaviour | Status |
|---|---|---|
| Rows | each with source, rule, selection, radius; rows that match nothing are skipped | ⬜ |
| Feature: All Edges / Against Part / Free Edges / Against Features | by owner of the faces at the edge | ⬜ |
| Face: All Edges / Against Features / Incident Edges | edges of the faces; Incident: along an axis within a tolerance | ⬜ |
| All Rounds / All Fillets | convex / concave filter | ⬜ |
| Remove Merged Faces | drops edges on faces flush with the body | ⬜ |

Edges are found again at every regeneration, so the fillet follows model changes.

### Lip

| Option | Inventor's behaviour | Status |
|---|---|---|
| Type: Lip / Groove | | ⬜ |
| Path Edges | connected boundary edges | 🟡 flat rims only |
| Guide Face / Pull Direction | cross section at a constant angle to the face, or parallel to the direction | ⬜ |
| Height, Width, Shoulder Width | the bead's size and its distance from the path | ⬜ |

## 4. Browser and editing

One browser node per feature, icon of its command; Edit Feature reopens the panel with the values. Numeric
fields are parameters where listed in `BodyOpFeature::fields`.

## 5. Edge cases and errors

- Non-positive sizes: refused before any geometry (`validate`).
- A centre with no body in its direction, a profile leaving the body: feature error, no change (rule 5).
- Kernel failure of a Boolean or fillet: feature health, never a faceted rebuild.

## 6. Implementation

`part/plastic/` (`boss.rs`, `snap_fit.rs`, `rest.rs`, `grill.rs`, `lip.rs`, `rule_fillet.rs`, `common.rs`); GUI
