# 3.1b Motion and contact

## 1. Purpose

A mechanism has to move and to stop against itself. Inventor does this with the Motion and
Transitional tabs of Constrain, Drive with Collision Detection, and the Contact Solver with its contact
sets. Ours keeps those names and adds what SolidCraft has: motion studies and exploded views (adapted
from its code, MIT OR Apache-2.0, see `ATTRIBUTION.md`).

## 2. Inputs

- the relationships of an assembly that have a value (joints with one, Mate, Flush, Angle, Insert,
  Tangent), and a Mate of axes, whose value is the turn about them;
- the components of the view's selection for contact sets and manual exploded moves.

## 3. Options

### 3.1 Mate of axes (Constrain)

| Option | Behaviour | Status |
|---|---|---|
| Value | a Mate or Flush of two axes, holes, shafts or circles leaves a turn and a slide: its value is the **angle** of the turn, never a distance | ✅ |
| Lock Rotation | holds the turn at the angle (taken from the present position when switched on) | ✅ |
| Drive | drives that angle | ✅ |
| Limits | minimum / maximum of the angle | ✅ (solver) |

### 3.2 Mate and Flush

| Option | Behaviour | Status |
|---|---|---|
| Solution in Constrain | the choice stays the user's (prediction no longer overrides it) | ✅ |
| Solution in Properties | a placed Mate changes to Flush and back at any time | ✅ |
| From either side | the solver turns a component half round when the faces stand the wrong way: the residual has no slope there | ✅ |

### 3.3 Contact Solver and Contact Sets

| Option | Behaviour | Status |
|---|---|---|
| Activate Contact Solver | components in contact stop each other when dragged, driven or played | ✅ |
| Contact Sets | sets made of the selected components; add, take out, suppress, delete | ✅ |
| Enable All Contact | every component with every other | ✅ |
| Collision Detection (Drive) | the drive stops short of the contact, by bisection; on by default when the solver is on | ✅ |
| Check Now | names the first pair passing through each other | ✅ |
| Starting overlapped | an assembly that overlaps may move out of it | ✅ |
| Limits | samples the display triangles along the motion: not exact continuous collision detection; a touch within 0.05 mm + 0.02 % of the size is allowed, because a shaft's and a hole's meshes cross by their sag | 🟡 |

### 3.4 Motion links (Inventor's Motion tab)

| Option | Behaviour | Status |
|---|---|---|
| Driver, Driven | two relationships with a value | ✅ |
| Type Rotation | Ratio: a turn drives a turn (gears) | ✅ |
| Type Rotation-Translation | Distance per turn: rack and pinion, a screw | ✅ |
| Type Linear | any other pair of values | ✅ |
| Forward / Reverse | the ratio's sign | ✅ |
| Dragging either side | the dragged side leads, the other follows | ✅ |
| A turn past ±180° | followed without a jump | ✅ |
| Picking faces directly (Inventor's selections) | through their joints or axis Mates for now | 🟡 |
| Transitional (cam and follower) | | ⬜ |

### 3.5 Motion Study

| Option | Behaviour | Status |
|---|---|---|
| Timeline | steps; a track per relationship with keys (step, value), linear between keys, held outside | ✅ |
| Transport | to the start, back, pause, play, to the end, slider, Loop, steps per second | ✅ |
| Contact | playback stops at contact | ✅ |
| Stop | puts the components back | ✅ |
| Copy CSV | each component's place at every step | ✅ |

### 3.6 Exploded View

| Option | Behaviour | Status |
|---|---|---|
| Auto Explode | each component away from the middle, by Scale | ✅ |
| Move selected | adds a move for the selected components | ✅ |
| Show, Explode slider | drawn only; the design keeps its places | ✅ |
| Drawing views of an exploded view | | ⬜ (presentations) |

## 4. Browser and editing

The window **Motion and Contact** has a tab per tool (ribbon: Assemble › Motion). Everything is stored in
`AssemblyDocument::motion` and takes part in Undo. A deleted component or relationship leaves its entries
idle.

## 5. Edge cases and errors

- A driven relationship that cannot reach its value: the solver reports it as for any other constraint.
- A relationship deleted from a link: the link does nothing.
- Exploded views are not used for picking while shown.

## 6. Implementation

`assembly/motion.rs` (data, `mesh_overlap`, `auto_explode`), `gui/motion.rs` (the window, `motion_links_follow`,
`contact_guard`, `drive_with_contact`, study playback), `assembly/solve.rs` (`turn_wrong_sides`),
`assembly/relation.rs` (`wrong_side`, `is_axis_mate`).
