# 3.7a Pattern Component at Placements

**Status:** 🟡 2026-11-16 (rims on one plane, associativity, Edit checked in the app; other planes and orientation unit-tested only). Our own extension of Pattern Component
(spec [3.0-assembly-commands.md](3.0-assembly-commands.md) §3.7, FEATURES 3.7); Inventor has no such tab.

## 1. Purpose

Copies one or more components (a bolt and the T-nut it goes into, a screw with its washer) to places
that follow **no grid**: the centres of holes drilled where the design needed them, points on other
faces of the part, faces at other angles. The user picks the components, says once *how they sit*
(a reference plane and a start point, optionally an orientation), then picks only the new places.
No assembly relationship is created: the pattern places the copies itself, as the Rectangular and
Circular tabs do, so one command replaces dozens of Mate / Insert relationships.

Inventor reaches non-grid component places only indirectly: a sketch-driven pattern (or a pattern of
work points) is made in a *part*, and the component pattern's Associative tab follows that feature
pattern. Here the places are picked directly in the assembly, on any components, and the copies stay
associative to what was picked.

## 2. Inputs

| Input | What it takes | Required |
|---|---|---|
| **Components** | the occurrences to copy (one or several; they move together) | yes |
| **Reference Plane** | the plane the components sit on now: a planar face of any component, a work plane, an origin plane | no, when the start point is a round edge (its own plane) |
| **Start Point** | where the components sit now on that plane: a vertex, a round edge (its centre), a hole's wall (its axis meets the plane), a work point | yes |
| **Orientation** | an in-plane direction the components are turned by: a straight edge or an axis | no |
| **Places** | the new places, one or more picks each (below) | at least one place |

The places selector reads its picks in order:

- a **round edge** (a hole's rim) is a whole place at once: its plane, its centre and its axis
  (the copy stands on the rim's planar face, square to it — as Bolted Connection's smart route);
- a **planar face** or work plane sets the plane of the places that follow (until another plane);
- a **vertex**, a work point or a **hole's wall** (its axis) is a place on the current plane — the
  reference plane until a plane was picked;
- a **straight edge** turns the last place: its orientation.

So on the reference plane each new hole is one click; on another face it is face + point (+ edge).

## 4. Browser and editing

The pattern is an ordinary Component Pattern node: Element:1 = the sources, Element:2… = one per
place, in the order the places were picked. Removing a place in Edit renumbers the following
elements (their copies move to the next place's position); the last element's copies are deleted.
A deleted copy leaves its place empty, as on the other tabs.

## 5. Edge cases and errors

- *Pattern Component: select the start point* / *select a plane for place 2* (a vertex picked before
  any plane while the reference has none).
- A straight edge as the first pick of Places: *pick a place first; an edge turns the last place*.
- An orientation edge square to its plane: *the orientation edge stands square to the plane*.
- A hole wall whose axis lies in the plane: *the axis does not cross the plane*.
- More than 1000 places: refused.

## 6. Implementation

- Data: `assembly::pattern::Layout::Placements { reference: Anchor, places: Vec<Anchor> }`,
  `Anchor { plane: Option<GeomRef>, point: GeomRef, orient: Option<GeomRef> }` — a new variant of the
  internally tagged `Layout`, so **format revision 75** (fixture `tests/compat/r75/`).
- Frames: `pattern::frame_of(anchor, fallback plane)` → origin, unit normal, optional x;
  `pattern::motion_between` → rigid motion. `place` is per place lenient (§3 Health).
- Picks → places: `pattern::places_from_picks` (GUI-free grammar of §2).
- GUI: `gui/asm_pattern.rs` (tab, see-through sources, picking grammar, preview, Edit),
  `gui/asm_planned.rs` (tab rows).
