# Тестова матрица на основните функции

`tests/matrix.rs` пуска основните функции върху **проста**, **сложна** и **много сложна**
геометрия. Всеки случай проверява:

- построен е с точното ядро (или е отказан с ясна грешка, където това е правилният отговор);
- тялото е валиден B-Rep (затворено, ориентирано, Ойлер);
- обемът съвпада с формулата (0,2 %);
- времето е в бюджета.

`cargo test --test matrix -- --nocapture` показва таблицата. Случай над бюджета се пуска още
веднъж и се брои по-бързото време (натоварена машина не проваля случая; бавният код е бавен и в
двата опита). Нов случай се добавя при всяка
нова функция или поправена грешка; бюджет над измереното не се вдига, търси се по-бързо
решение (`docs/PERF.md`).

| Ниво | Случай | Какво проверява |
|---|---|---|
| проста | кутия 40×30×20, цилиндър, тръба с Revolve, Fillet r5 на ръб, отвор Ø10 | основни Extrude/Revolve/Fillet/Cut |
| проста | Extrude Symmetric, Asymmetric 15/5, наклон +5°; Revolve 270°; Chamfer Two Distances 2×4 | опциите на Extrude/Revolve/Chamfer |
| сложна | Intersect (цилиндър в кутия); бобина с закръглена основа (вдлъбнат ръб) | Intersect, вдлъбнат Fillet по окръжност |
| сложна | плоча + отделно тяло (New Solid, From стена, Cut само на тялото); Extrude **To** стена и **To Next** | границите, избор на тяло (Solids) |
| сложна | радиална решетка (кръгов масив от линия през центъра, 4 от 8 сектора) | масив през центъра, региони, Cut на много профили |
| сложна | шахматна решетка 6×6 с ребра 2 mm | много отвори наведнъж |
| сложна | „чиста“ шахматна дъска (квадратите се допират в ъглите) | съвпадащи ръбове със проектирания контур, региони |
| сложна | Cut, насочен навън от тялото | грешка „does not intersect the body“ |
| сложна | Edit Feature: отвор от Through All на 4 mm, Fillet след него | замяна на място, следващата операция оцелява |
| много сложна | шахматна решетка 12×12 (72 отвора) | бързодействие (union_apart) |
| много сложна | радиална решетка 24 сектора | много региони |
| много сложна | 36 отвора Ø4 с фаска 0,5 / закръгление r0,5 по горния ръб | Chamfer/Fillet на много кръгли ръбове, кеш на регенерацията, паралелно разпознаване на повърхнините |

Празната кутия (вътрешни/външни закръгления и фаски, ръб по ръб) е в `src/part/exact.rs`
(`hollow_box`), със същите проверки.

## Сравнение с Inventor (след всяка итерация)

| Поведение | Inventor | При нас |
|---|---|---|
| Кръгов масив от линия, която започва в центъра | копията споделят центъра | ✅ (беше грешка „the two points must differ“) |
| Крива върху проектиран ръб | един ръб, профилите се затварят | ✅ (даваше 0 региона) |
| Cut, смяна на операцията | посоката се насочва към материала | ✅ `sync_extrude_direction` |
| Cut, който не маха нищо | предупреждение | ✅ грешка на операцията |
| Регенерация | само от променената операция нататък | ✅ кеш на стъпките (`BuildCache`) |
| Всяко числово поле приема изрази и параметри | да | ✅ `ExprValue` / `field_row`; размерите на Box са параметри |
| Дръжки на масива в диалога | да (преглед на живо) | ✅ |
