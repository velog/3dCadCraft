# 1.4 Dimensions (Sketch → Constrain → Dimension)

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ blocked by another feature.

## 1. Purpose

Dimensions set the **magnitudes**: lengths, distances, radii and angles. They are parametric: changing the value reshapes the geometry. Inventor has one command, **Dimension** (General Dimension), which recognises the kind of dimension by itself from the selection and from the place where you put it.

## 2. What Dimension (D) creates

| Selection | Placement | Dimension | Status |
|---|---|---|---|
| circle | anywhere | **diameter** Ø | ✅ |
| arc | anywhere | **radius** R | ✅ |
| circle/arc, another kind from the context menu | right click → Radius / Diameter / Arc Length | changes the kind | ⬜ |
| line | above/below → horizontal; to the side → vertical; otherwise aligned | distance | ✅ |
| a **model edge** (not in the sketch) | — | the edge is projected into the sketch automatically and used (Inventor); also for the constraint tools | 🟡 straight edges (`PartDocument::project_edge`, one Undo step "Project Geometry"); with one pick made, a click on an edge is the second pick, not the placement; curved edges ⬜; waiting for a visual check |
| two points | the same rule | distance | ✅ |
| point + line | — | perpendicular distance | ✅ |
| two parallel lines | — | the distance between them | ✅ |
| two non-parallel lines | the angle is chosen by the placement quadrant | **angle** | ✅ |
| three points | — | angle with the vertex at the middle one | ⬜ |
| line, point or circle + centerline | placed **on the other side** of the axis → **diametric** dimension (Ø, twice the distance to the axis); on the same side → an ordinary one | **diametric** dimension (for Revolve) | ✅ |
| circle + circle / line / point | to the tangent or the centre | 🟡 to the centre (point–centre, line–centre, centre–centre); the tangent variant is not there yet |

**Sequence:** selection (1 or 2 clicks) → click in an empty place for the placement → **Edit Dimension** box with the measured value.

| Placement behaviour | Status |
|---|---|
| **Live preview:** after the selection the dimension is drawn in full (lines, arrows, value) and **follows the cursor**; the kind (horizontal / vertical / aligned, the angle's quadrant, diametric about a centerline) changes with the cursor position | ✅ |
| The third click places the dimension already shown exactly where it was seen | ✅ |
| **Editing on the dimension itself:** the value field opens at the place of the dimension text (not a separate window); Enter applies, Esc keeps the measured value; accepts an expression (`d0/2`, `10 mm`) | ✅ |
| Double click on an existing dimension — the same field over the text | ✅ |
| In the field: a **Tolerance** button | ✅ (±) |
- **Enter** applies the value.
- **Keep measured** keeps the measured value.
- **Esc** also keeps the measured value (the dimension has already been created).
- Status: ✅.

## 4. Driven (reference) dimensions

| Behaviour | Inventor | Status |
|---|---|---|
| A dimension that would over-constrain | a question: create it as **driven** or cancel (Application Options → Overconstrained dimensions: *Apply driven dimension* / *Warn of overconstrained condition*) | ✅ question; ⬜ the setting |
| Display | the value is **in parentheses**; it does not move the geometry; it cannot be edited directly | ✅ |
| Toggling | Driven Dimension in Format or the "ref" check box in Properties | ✅ ("ref") |
| Relax mode | while dragging, conflicting dimensions become driven (Inventor) | ✅ (see [1.3](1.3-constraints.md), section 5) |

## 8. Dimension appearance (how it is drawn)

A dimension is a **graphic object** in the sketch, not just a number. Each kind is drawn as in a technical drawing and in Inventor. All lines are thin, in the dimension colour: dark blue; driven — grey, in parentheses; selected or hovered — orange.

| Kind | Elements | Status |
|---|---|---|
| **Aligned** (Distance) | two **extension lines** from the points, perpendicular to the segment between them, to the **dimension line**; the dimension line is parallel to the segment, at the label's distance; **arrows** at both ends, pointing outwards to the extension lines (inwards if the text does not fit); the text is above the dimension line, in the middle or where it was dragged | ✅ |
| **Horizontal / vertical** | the same, but the extension lines are vertical or horizontal, and the dimension line is horizontal or vertical, at the label's height (or x respectively) | ✅ |
| **Point–line** | an extension line from the point, perpendicular to the line; the dimension line is parallel to the perpendicular | ✅ |
| **Radius** R | a **leader line** from the centre through the circle to the label, with an arrow at the point on the circle; text `R…` | ✅ |
| **Diameter** Ø | a line through the centre in the direction of the label, with arrows at both points on the circle (or a leader line outwards if the label is outside the circle); text `Ø…` | ✅ |
| **Angle** | an **arc** centred at the (virtual) intersection point of the lines, with a radius to the label, between the two rays; arrows at the ends of the arc; extension lines continuing the lines if the arc is beyond them; text `…°` | ✅ |
| Text | 12 px, with a background so it reads over the geometry; always horizontal (does not rotate with the dimension) | ✅ |
| Default position | if none is stored: 22 px from the geometry, **outwards** from the middle of the sketch (below the bottom side, right of the right side) | ✅ |

## 9. Label position and dragging

| Behaviour | How it works | Status |
|---|---|---|
| **Position at creation** | the label is where the placement click was; the same place also decides the kind (horizontal, vertical or aligned) | ✅ |
| **How it is stored** | as an offset from the dimension's **anchor**: the middle of the two points (linear), the centre (R, Ø), the vertex of the angle (angle). Stored in the sketch and in the file | ✅ |
| **Follows the geometry** | when the geometry changes or is dragged, the anchor moves and the label moves with it; the offset stays | ✅ |
| **Dragging the label** | pressing on the text and dragging (the move cursor appears on hover) moves the label: for linear ones — the dimension line goes to the new distance and the text slides along it; for R/Ø — the leader line rotates about the centre; for the angle — the arc changes its radius | ✅ |
| Dragging over the geometry | dragging the label **does not move** the geometry and **does not change the value** | ✅ |
| Click without dragging | selects the dimension (Shift adds); a double click opens Edit Dimension | ✅ |
| Undo | one drag is one step ("Move Dimension") | ✅ |
| Changing the kind while dragging | in Inventor a linear dimension does **not** change its kind when dragged after creation; the kind is chosen only at placement | ✅ |
| Angle: quadrant | at placement, the quadrant the cursor is in decides which of the two supplementary angles is measured (θ or 180° − θ) | ✅ (the supplementary angle is stored as `supplement` in the constraint) |
| Snapping | while dragging, the label is centred between the extension lines when it is near the middle | ⬜ |
| No overlap | a new dimension is not placed over an existing label; if they overlap, the second one is moved aside | 🟡 constraint glyphs are moved away from dimensions and from each other; dimensions are not moved |

## 11. Edge cases

- A value ≤ 0 for a length or radius → refused; an angle outside ±180° → refused. ✅
- A zero distance between two points → points to Coincident. ✅
- A dimension between projected points → driven by necessity (they are fixed). ✅
