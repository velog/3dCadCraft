# 1.4 Размери (Sketch → Constrain → Dimension)

Статус: ✅ готово · 🟡 частично · ⬜ предстои · ⛔ чака друга функция.

## 1. Предназначение

Размерите задават **величините**: дължини, разстояния, радиуси и ъгли. Те са параметрични: промяна на стойността преоформя геометрията. Inventor има една команда, **Dimension** (General Dimension), която сама разпознава вида на размера от избора и от мястото, където го поставиш.

## 2. Какво създава Dimension (D)

| Избор | Поставяне | Размер | Статус |
|---|---|---|---|
| окръжност | където и да е | **диаметър** Ø | ✅ |
| дъга | където и да е | **радиус** R | ✅ |
| окръжност/дъга, друг вид от контекстното меню | десен клик → Radius / Diameter / Arc Length | смяна на вида | ⬜ |
| линия | над/под → хоризонтален; встрани → вертикален; иначе подравнен | разстояние | ✅ |
| две точки | същото правило | разстояние | ✅ |
| точка + линия | — | перпендикулярно разстояние | ✅ |
| две успоредни линии | — | разстояние между тях | ✅ |
| две неуспоредни линии | ъгълът се избира според квадранта на поставяне | **ъгъл** | ✅ |
| три точки | — | ъгъл с връх в средната | ⬜ |
| линия, точка или окръжност + centerline | поставен **от другата страна** на оста → **диаметрален** размер (Ø, удвоеното разстояние до оста); от същата страна → обикновен | **диаметрален** размер (за Revolve) | ✅ |
| окръжност + окръжност / линия | към допирателната или центъра | разстояние до допирателна | ⬜ |

**Последователност:** избор (1 или 2 клика) → клик в празно място за поставяне → прозорец **Edit Dimension** с измерената стойност.

| Поведение при поставяне | Статус |
|---|---|
| **Преглед на живо:** след избора размерът се рисува изцяло (линии, стрелки, стойност) и **следва курсора**; видът (хоризонтален / вертикален / подравнен, квадрант на ъгъла, диаметрален спрямо централна линия) се сменя според мястото на курсора | ✅ |
| Третият клик поставя вече показания размер точно където е видян | ✅ |
| **Редакция върху самия размер:** полето за стойност се отваря на мястото на текста на размера (не отделен прозорец); Enter прилага, Esc оставя измерената стойност; приема израз (`d0/2`, `10 mm`) | ✅ |
| Двоен клик върху съществуващ размер — същото поле върху текста | ✅ |
| В полето: бутон за **Tolerance** | ✅ (±) |
- **Enter** прилага стойността.
- **Keep measured** оставя измерената стойност.
- **Esc** също оставя измерената (размерът вече е създаден).
- Статус: ✅.

## 3. Редакция

| Поведение | Inventor | Статус |
|---|---|---|
| Двоен клик върху размер | Edit Dimension | ✅ |
| Dimension + клик върху размер | Edit Dimension | ✅ |
| Десен клик | Edit Dimension, Delete, Driven/Driving, Dimension Properties | ✅ без Dimension Properties |
| Стойност в Properties | редакция на място в списъка с ограничения | ✅ |
| Влачене на етикета | премества етикета, без да сменя стойността | ⬜ (етикетът е на фиксирано място) |
| Въвеждане на израз | `2*d1 + 5 mm`, параметри, единици | ✅ |
| fx пред размер, изчислен от израз | маркер, че стойността идва от уравнение | ✅ |

## 4. Driven (справочни) размери

| Поведение | Inventor | Статус |
|---|---|---|
| Размер, който би свръхограничил | въпрос: да се създаде като **driven** или да се откаже (Application Options → Overconstrained dimensions: *Apply driven dimension* / *Warn of overconstrained condition*) | ✅ въпрос; ⬜ настройката |
| Показване | стойността е **в скоби**; не мести геометрията; не може да се редактира пряко | ✅ |
| Превключване | Driven Dimension във Format или отметка „ref“ в Properties | ✅ („ref“) |
| Relax mode | при влачене конфликтните размери стават driven (Inventor) | ✅ (виж [1.3](1.3-constraints.md), раздел 5) |

## 5. Показване (Dimension Display)

| Режим | Значение | Статус |
|---|---|---|
| **Value** | изчислената стойност | ✅ |
| Name | името на параметъра (`d0`, `d1`…) | ✅ |
| Expression | изразът (`d1 = 2 * d0`) | ✅ |
| Tolerance | стойността с толеранса | ✅ |
| Precise Value | без закръгляне до точността на документа | ⬜ |
| Точност (брой знаци) | от Document Settings | ⬜ (засега 2 знака) |
| Единици | mm по подразбиране; inch и др. от Document Settings | ⬜ (засега само mm) |

## 6. Допуски (Tolerance)

| Поведение | Inventor | Статус |
|---|---|---|
| Вид | **Default** (без), **Symmetric** (±a), **Deviation** (+a / −b), **Limits** (горна/долна граница), **Max**, **Min**, **Basic** (в рамка) | ✅ |
| Стойности | горно и долно отклонение (mm или °) | ✅ |
| **Evaluated size** | Upper / Median / Nominal / Lower — по коя стойност се строи моделът; по подразбиране Nominal | ✅ |
| Показване в скицата | `25.00 ±0.10`, `25.00 +0.10/−0.05`, `25.10/24.95`, `25.00 max`, `[25.00]` | ✅ (режим Tolerance) |
| Глобално превключване | лентата на състоянието: Value / Name / Expression / **Tolerance** — както в Inventor; Model Value „всички на Upper/Lower/Median/Nominal“ | 🟡 Value / Name / Expression / Tolerance ✅; ⬜ „всички на Upper/Lower…“ с една команда |
| Таблица Parameters | колона Tolerance (виж [0.5](0.5-parameters.md)) | ✅ |

## 8. Изглед на размера (как се рисува)

Размерът е **графичен обект** в скицата, не само число. Всеки вид се рисува така, както в техническия чертеж и в Inventor. Всички линии са тънки, в цвета на размерите: тъмносиньо; driven — сиво, в скоби; избран или посочен — оранжево.

| Вид | Елементи | Статус |
|---|---|---|
| **Подравнен** (Distance) | две **помощни линии** от точките, перпендикулярни на отсечката между тях, до **размерната линия**; размерната линия е успоредна на отсечката, на отстоянието на етикета; **стрелки** в двата края, насочени навън към помощните линии (навътре, ако текстът не се побира); текстът е над размерната линия, в средата или там, където е влачен | ✅ |
| **Хоризонтален / вертикален** | същото, но помощните линии са вертикални или хоризонтални, а размерната линия е хоризонтална или вертикална, на височината (съответно x) на етикета | ✅ |
| **Точка–линия** | помощна линия от точката, перпендикулярна на линията; размерната линия е успоредна на перпендикуляра | ✅ |
| **Радиус** R | **водеща линия** от центъра през окръжността към етикета, със стрелка в точката на окръжността; текст `R…` | ✅ |
| **Диаметър** Ø | линия през центъра по посока на етикета, със стрелки в двете точки на окръжността (или водеща линия навън, ако етикетът е извън окръжността); текст `Ø…` | ✅ |
| **Ъгъл** | **дъга** с център във (виртуалната) пресечна точка на линиите и радиус до етикета, между двата лъча; стрелки в краищата на дъгата; помощни продължения на линиите, ако дъгата е извън тях; текст `…°` | ✅ |
| Текст | 12 px, с фон, за да се чете върху геометрията; винаги хоризонтален (не се завърта с размера) | ✅ |
| Позиция по подразбиране | ако няма запазена: на 22 px от геометрията, **навън** от средата на скицата (под долната страна, вдясно от дясната) | ✅ |

## 9. Позиция на етикета и влачене

| Поведение | Как работи | Статус |
|---|---|---|
| **Позиция при създаване** | етикетът е там, където е кликнато при поставянето; от същото място зависи и видът (хоризонтален, вертикален или подравнен) | ✅ |
| **Как се пази** | като отместване от **котвата** на размера: средата на двете точки (линейни), центъра (R, Ø), върха на ъгъла (ъгъл). Пази се в скицата и във файла | ✅ |
| **Следва геометрията** | при промяна или влачене на геометрията котвата се мести и етикетът се мести с нея; отместването остава | ✅ |
| **Влачене на етикета** | натискане върху текста и влачене (курсорът за местене се появява при посочване) мести етикета: за линейните — размерната линия отива на новото отстояние и текстът се плъзга по нея; за R/Ø — водещата линия се завърта около центъра; за ъгъла — дъгата сменя радиуса си | ✅ |
| Влачене през геометрията | влаченето на етикета **не мести** геометрията и **не сменя стойността** | ✅ |
| Клик без влачене | избира размера (Shift добавя); двоен клик отваря Edit Dimension | ✅ |
| Undo | едно влачене е една стъпка („Move Dimension“) | ✅ |
| Смяна на вида при влачене | в Inventor линейният размер **не** сменя вида си при влачене след създаването; видът се избира само при поставянето | ✅ |
| Ъгъл: квадрант | при поставяне квадрантът, в който е курсорът, определя кой от двата допълнителни ъгъла се мери (θ или 180° − θ) | ✅ (допълнителният ъгъл се пази като `supplement` в ограничението) |
| Прихващане | при влачене етикетът се центрира между помощните линии, когато е близо до средата | ⬜ |
| Без застъпване | новият размер не се поставя върху съществуващ етикет; ако се застъпват, вторият се отмества | 🟡 знаците на ограниченията се отместват от размерите и един от друг; размерите не се местят |

## 10. Менюта на размера (десен клик върху текста)

| Команда | Действие | Статус |
|---|---|---|
| **Edit Dimension** | прозорецът за стойност | ✅ |
| **Driven / Driving** | превключва вида (Format → Driven Dimension) | ✅ |
| **Delete** | изтрива размера | ✅ |
| **Flip Direction** | обръща посоката, в която размерът мести геометрията (за разстояния и ъгли) | ✅ (хоризонтален/вертикален, точка–линия, ъгъл) |
| **Reset Position** | връща етикета на мястото по подразбиране (в средата) | ✅ |
| Dimension Properties | показване (Value/Name/Expression…), точност | ⛔ (0.5, 0.11) |

## 11. Крайни случаи

- Стойност ≤ 0 за дължина или радиус → отказ; ъгъл извън ±180° → отказ. ✅
- Нулево разстояние между две точки → насочва към Coincident. ✅
- Размер между проектирани точки → driven по необходимост (те са фиксирани). ✅

## 12. Реализация

`sketch/constraint.rs` (Distance, HorizontalDistance, VerticalDistance, PointLineDistance, Angle, Radius, Diameter; `measure`), `sketch/mod.rs` (`set_dimension`, `set_driven`, `relax_dimensions`, `remeasure_dimensions`), `gui/sketch_tools.rs` (`dimension_click`, `distance_by_placement`), `gui/mod.rs` (Edit Dimension, въпросът за driven).
