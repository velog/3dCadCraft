# 0.6c Templates

## 1. Purpose

In Inventor every new file starts as a copy of a **template**: an ordinary part, assembly, drawing or
presentation file kept in a templates folder. A template carries what a company wants in every new
document: units and modelling defaults for parts, the drafting standard, sheets, title block and styles
for drawings, and file properties (Properties) for all of them. File → New picks a template; the
*standard* template of each kind is what the quick New entries use.

Ours works the same way: a template is a `.ccpart`, `.ccasm` or `.ccdrw` file (spec
[0.6a](0.6a-file-types-projects.md)) in the templates folder; anything the program can save can be a
template.

## 2. Inputs

- the templates folder: the active design project's `templates` (spec 0.6a §3.2 Folder Options), else
  the Application Options default;
- the template chosen in Create New File, or the standard template of a kind (New drop-downs, Ctrl+N
  shortcuts of Home);
- for Save Copy As Template: the active document and a name.

## 4. Browser and editing behaviour

A template is a normal file: it can be opened, edited and saved like any other. A document made from a
template keeps no link to it.

## 5. Edge cases and errors

- The templates folder does not exist and cannot be created: Create New File shows the built-in
  documents only, with the reason above the list.
- A file in the templates folder that cannot be read is listed greyed with the reason in its tooltip.
- A template whose extension does not match its content: it is listed under the kind of its content
  (spec 0.6a: the manifest decides).
- Two templates of the same name in different folders: both listed, each in its folder.

## 6. Implementation

- `src/document/templates.rs`: `TemplateDir` (folder, `ensure_builtin`), `Template` (path, kind, name),
  `list` (folder tree), `standard(kind)`, `instantiate` (template → `DocumentData` + Properties),
  `save_as_template`.
- GUI: `gui/new_file.rs` (Create New File), `gui/files.rs` (quick New, Save Copy As Template),
  `gui/projects.rs` (the project choice and the Projects editor).
