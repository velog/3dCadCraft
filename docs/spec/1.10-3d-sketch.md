# 1.10 3D sketch

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ waiting for another feature.

## 1. Purpose

A sketch that is not bound to a plane: lines, arcs, splines and helices drawn directly in space.
It is the path of sweeps (tubes, cables, hoses, wires), the skeleton of frames and the centre line
of lofts, and it can hold curves taken from the model (intersections, projections onto faces,
silhouettes). Machine design uses it mostly for routed paths: straight runs joined by bends of a
given radius.

## 2. Inputs

- **Start 3D Sketch** (3D Model › Sketch, alias `S3`): opens an empty 3D sketch (no plane to pick)
  and the 3D Sketch tab.
- Points are given by **coordinates** (Precise Input: X, Y, Z, absolute or relative to the previous
  point), by a click on a model vertex, a work point, a point of the same 3D sketch, or on the plane
  of the coordinate triad under the cursor.
- **Finish 3D Sketch** (or Esc with no tool running) closes it; double click in the browser, or Edit
  3D Sketch in its menu, opens it again.

## 4. Browser and editing behaviour

- A 3D sketch has an immutable `id` (`Sketch3D1`) and a free `name` (`3D Sketch1`), like 2D sketches.
- Its geometry is stored in part coordinates (rule 8): no plane, no placement.
- Editing it changes the features that use it at the next regeneration (Finish 3D Sketch regenerates).

## 5. Edge cases and errors

- A bend whose radius does not fit between the corner and the lines' other ends: refused, the sketch
  unchanged.
- Parallel or perpendicular that cannot be met (both lines fixed): "3D Sketch: the constraint cannot
  be met", the sketch unchanged.
- A path with a branch (three lines at one point) cannot be swept: "the path branches at a point".

## 6. Implementation

- `part::sketch3d` (GUI-free): `Sketch3d { id, name, points, lines, bends, constraints, visible }`,
  `pieces()` → path pieces (`PathPiece::Line` / `PathPiece::Arc`) in chain order, `solve`.
- `PartDocument::sketches3d`, `add_sketch3d`; `Feature::sketch_ids` lists a 3D sketch a sweep uses
  (consumers, regeneration cache key).
- GUI `gui/sketch3d.rs`: the 3D Sketch panel (Line, Point, Bend, Coincident, Parallel, Perpendicular,
  Finish), the overlay in the view, picks.
