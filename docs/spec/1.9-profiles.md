# 1.9 Профили и региони

Статус: ✅ готово · 🟡 частично · ⬜ предстои · ⛔ чака друга функция.

## 1. Предназначение

Затворените области на скицата са **профилите**, които Extrude, Revolve и другите операции изтеглят. Правоъгълник с две окръжности вътре дава три региона: плоча с два отвора и два диска. Потребителят избира регионите с клик. В Inventor се избира и цял контур (*Select Other → loop*).

## 2. Правила

| Правило | Статус |
|---|---|
| Участват кривите в стил Normal; construction и centerline не | ✅ |
| Линиите, дъгите и окръжностите се разделят във всички пресечни и допирни точки | ✅ |
| Сплайните се свързват само в краищата си | 🟡 (⬜ пресичане на сплайни) |
| Висящите ръбове (отворени краища) се отрязват; не влияят на регионите | ✅ |
| Вложени контури: остров в отвор е отделен регион | ✅ |
| Външният контур е обратно на часовниковата стрелка, отворите по часовниковата стрелка (конвенцията на ядрото) | ✅ |
| Избор на **контур** вместо регион (Select Other) | ⬜ |
| Отворени профили (за Surface или Match Shape) | ⛔ (булеви операции, повърхнини) |

## 3. Показване

| Поведение | Статус |
|---|---|
| В редактираната скица затворените региони са леко запълнени | ✅ |
| При Extrude предлаганите региони са бледозелени, избраните наситено зелени | ✅ |
| Регионите се кешират и се преизчисляват само при промяна на скицата | ✅ |

## 4. Устойчивост на избора

Операцията помни региона по **кривите на външния му контур**, с точка вътре като резерва. Така изборът оцелява при промяна на размерите. Ако регионът изчезне, операцията става болна. ✅

## 5. Реализация

`sketch/profile.rs` (`Sketch::regions`, `Region`, `ProfileLoop`, `interior_point`), `kernel/mesh.rs` (`triangulate_with_holes`), `part/extrude.rs` (`ProfileRef`).
