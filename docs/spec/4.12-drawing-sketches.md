# 4.12 Drawing sketches and Draft View (drawing stage D-S5)

> A 2D sketch drawn on a drawing: on the sheet itself (it stays where it is drawn), or owned by a view (it
> moves and scales with the view). Its curves are drawn and printed on the Sketch Geometry layer. A Draft
> View is a view that has no model, only sketches.

## 1. Purpose

Not everything on a drawing comes from the model: a mounting frame drawn round a view, a weld preparation,
a simple bracket that has no 3D model, construction for a note's position. Inventor lets the user sketch on
the drawing with the same Sketch tab as in a part; the sketch belongs either to the sheet or to a view. A
**Draft View** is a view whose whole content is such sketches — with a label and a scale like any other view.
Section lines and Break Out profiles are view sketches too (specs 4-drawings, 4.11); this spec covers the
sketches the user makes on purpose.

## 2. Inputs

1. Place Views or Annotate › Sketch › **New Sketch** (Inventor: Start Sketch / Create Sketch; alias DS).
2. The owner: the view selected when the command starts; else a click — inside a view's box the sketch is that
   view's, anywhere else on the sheet it is a sheet sketch.
3. The geometry, with the Sketch tab (or the floating toolbar).
4. Finish Sketch (Enter, right-click menu, ribbon); Cancel leaves the drawing as it was before the command.

Draft View:

1. Place Views › Create › **Draft View** (alias DFV).
2. The Draft View dialog: View Identifier, Scale, label visibility; OK.
3. A click on the sheet places the empty view; its sketch opens at once.

## 4. Browser and editing

- The sheet node lists its views, then the sheet's sketches; a view node lists its breaks, break outs and
  child views, then its sketches.
- A sketch row: double-click = Edit Sketch; its menu: Edit Sketch, Visibility (check mark), Delete.
- Each Finish Sketch, Visibility change and Delete is one Undo step.

## 5. Edge cases and errors

- A sketch with no curves at Finish Sketch is kept (Inventor keeps empty sketches); it draws nothing.
- Editing a view sketch while its view's lines are not computed yet: the sketch opens once the view is drawn.
- Deleting a view deletes its sketches (a Draft View with all its content).
- A Draft View with no sketch geometry has a small box (so it can be picked and moved).
- Old builds: sheet and view sketches are ignored (fields they do not know); a Draft View needs format
  revision 65 (old builds refuse the file).

## 6. Implementation

- `drawing::view_sketch::DrawingSketch` (id, name, visible, the `ViewSketch`); `Sheet::sketches`,
  `DrawingView::sketches`, `DrawingDocument::next_sketch_id`; `add_sketch`, `set_sketch`, `remove_sketch`,
  `sketch_visible`.
- `ViewKind::Draft` (format revision 65): no model, no lines job; `DrawingDocument::draft_lines` gives an empty
  `ViewLines` whose extent is the sketches' (anchor at the view's origin, so drawing does not move it).
- `drawing::render::sketch_prims`: the sketches of a sheet as `Prim`s on the sketch layer (screen and PDF).
- `style::ObjectDefaults::sketch_layer` (default `Sketch Geometry (<std>)`).
- GUI `gui/drawing_sketch.rs`: `SketchFor::Sketch { view, id }` / `NewSketch`; the sheet is view `SHEET` (0),
  placed at identity; `DrwTool::StartSketch` waits for the click; `DrwTool::DraftView` places the draft view.
