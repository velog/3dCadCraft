# 1.2 Sketch geometry (Sketch → Create, Format)

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ waiting for another feature.

## 1. General rules for all tools

| Rule | Status |
|---|---|
| The meaning of a click depends on what is under the cursor: empty space, a point, the middle of a line or a curve. Snapping adds a constraint (see [1.5](1.5-inference.md)) | ✅ |
| The tool stays active after creating; Esc cancels the current input, a second Esc → Select | ✅ |
| Preview (rubber band) at every step | ✅ |
| Status-bar prompt at every step | ✅ |
| Composite shapes come with Inventor's constraints and **no redundant constraints**; each has a test for the exact number of degrees of freedom | ✅ |
| Construction mode (Format → Construction with no selection) makes the new geometry construction | ✅ |
| Entering values next to the cursor (Heads-Up Display) | ⬜ |

## 2. Tools

### 2.1 Line and splines

| Tool | Input (clicks) | Automatic | Status |
|---|---|---|---|
| **Line** (L) | click, click…: a chain with **shared** points; Esc or right click → Done ends the chain | H/V (up to 3°), ⊥/∥ to the previous line, Coincident on a snap | ✅ |
| Line → arc by dragging | press on the end of a line or arc and drag: along the tangent → **tangent arc**, across → **perpendicular arc** | Tangent or centre on the normal | ✅ |
| **Control Vertex Spline** | control points; Enter or a double click ends | the ends may be shared with other curves | ✅ |
| Interpolation Spline | points it passes **through**; tension, handles for direction | Smooth (G2) to the neighbours | ⬜ |
| Equation Curve | a curve from equations in explicit, parametric or polar form | — | ⬜ |
| Bridge Curve | a smooth (G2) connection between the ends of two curves | Smooth | ⬜ |

| Tool | Inventor behaviour | Status |
|---|---|---|
| **Fillet** | radius in the dialog; two curves or a shared end; the first fillet in the command gets an R dimension, the next ones — Equal; trims the curves | ✅ two lines; ⬜ line–arc, arc–arc |

## 4. Selection, deletion, editing

| Behaviour | Status |
|---|---|
| Select (Esc) selects with a click; Shift adds | ✅ |
| Delete deletes the selection; deleting a point deletes its curves and its constraints | ✅ |
| Projected geometry cannot be deleted or changed | ✅ |
| Dragging a point or a whole curve; the constraints are respected (see Relax mode in [1.3](1.3-constraints.md)) | ✅ |
| A dropped point is attached to the point or curve under it | ✅ |
| Context menu of a curve: Construction, Centerline, Normal, Fix, Delete Constraints, Display Degrees of Freedom, Delete | ✅ |

## 5. Edge cases

- A circle or arc with zero radius, three collinear points for an arc → refused with a reason, no change. ✅
- A spline with fewer than 2 points → refused. ✅
- A Fillet with a radius larger than the lines, or on parallel lines → refused. ✅
