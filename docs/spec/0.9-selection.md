# 0.9 Избор, предварително осветяване и контекстни предложения

Статус: ✅ готово · 🟡 частично · ⬜ предстои · ⛔ чака друга функция.

## 1. Предназначение

Всяка команда започва с избор: стена, ръб, връх, тяло, операция, скица или крива. Изборът трябва да е **бърз, видим и предвидим**:
- това, което ще се избере, светва още при посочване;
- припокриващите се обекти се стигат лесно;
- до избрания обект се появява кратък списък с действията, които имат смисъл за него.

## 2. Видове обекти и филтри

| Обект | Как се посочва | Статус |
|---|---|---|
| Стена (Face) | клик върху стената | 🟡 клик в изгледа избира стената (синя) и операцията ѝ в Properties; Start Sketch, To/From ✅ |
| Ръб (Edge) | клик близо до ръба (радиус на прихващане в пиксели) | ✅ в спокоен изглед: ръбът под курсора (6 px, скритите зад стени не се броят) светва, клик го избира |
| Връх (Vertex) | клик близо до върха | 🟡 (To/From) |
| Тяло (Body) | филтър **Select Bodies** или в папката Solid Bodies | ✅ визуално: клик върху стена избира цялото тяло (`part::select::faces_of_body`) |
| Операция (Feature) | филтър **Select Features**: клик върху стена избира операцията, която я е създала; или в дървото | ✅ визуално: светват всички стени на операцията, дървото и Properties я показват (`faces_of_feature`) |
| Скица и нейните криви | филтър **Select Sketch Features**; видимите скици в изгледа | ✅ визуално: клик върху крива на видима скица избира скицата; ⬜ отделни криви извън скицата |
| Работни елементи и Origin | клик в изгледа или в дървото | 🟡 (равнините на Origin) |

| Филтър (Inventor: в Quick Access Toolbar) | Поведение | Статус |
|---|---|---|
| **Select Faces and Edges** (по подразбиране в детайл) | стени, ръбове, върхове | ✅ стени и ръбове (падащото меню **Select** в Quick Access Toolbar, `gui/select.rs`); ⬜ върхове |
| **Select Features** | цели операции | ✅ |
| **Select Bodies** | цели тела | ✅ |
| **Select Sketch Features** | скици и кривите им | ✅ скици |
| Приоритет при посочване | върх > ръб > стена > работна равнина > равнина на Origin (виж [0-ui §3.2](0-ui.md)) | 🟡 ръб > стена > равнина на Origin ✅; ⬜ върхове, работни елементи |

## 3. Предварително осветяване (Prehighlight)

| Поведение | Inventor | Статус |

| Обектът под курсора светва, преди да се кликне (стена — запълване, ръб — удебелена линия, връх — точка) | **Enable Prehighlight** (Application Options → Colors), включено по подразбиране | 🟡 стени, ръбове, операции, тела, скици ✅ (зелено; изключва се от менюто Select); ⬜ върхове |
| Цветът на предварителното осветяване се различава от цвета на избраното | | ✅ зелено (под курсора) / синьо (избрано) / оранжево (при Start Sketch) |
| Подсказка до курсора: вид и име (`Face Extrusion1:End`, `Edge`, `Solid1`) | | 🟡 стена „Face … · операция · SolidN“, ръб „Edge … · L 40.00 mm“ ✅; ⬜ връх |
| Важи за всички команди, които чакат избор (не само Start Sketch) | | ⬜ |

## 6. Контекстни предложения (наша функция по идея на Inventor)

Inventor дава контекстни команди по два начина:
- **Marking menu** с десен клик: радиално меню, центрирано на курсора, с команди според средата (скица, детайл, сглобка). До него стои кратко контекстно меню (*overflow*). Удар с мишката към сектора изпълнява командата (Mark Mode).
- По-старата **mini-toolbar**: при избран ръб показва Fillet и Chamfer.

У нас: **при всеки избор в изгледа до него се появява малка лента с предложения**, подредени по вероятност. Клик стартира командата с вече избрания обект като вход. Esc или клик другаде я скрива.

| Избран обект | Предложения | Статус |
|---|---|---|
| Ръб (прав или кръгъл) | **Fillet**, **Chamfer**, Select Tangencies, Measure; ръб, на който лежи скица: Project | 🟡 лента: Fillet/Chamfer (неактивни, ⛔ 2.4/2.5), Edit Feature ✅; дължината е в подсказката |
| Няколко ръба | Fillet, Chamfer (с всички тях) | ⛔ 2.4 / 2.5 |
| Плоска стена | **New Sketch**, **Extrude** (Press/Pull — Cut/Join от стената), Shell (махни стената), Draft, Work Plane (offset), Look At, Measure | 🟡 лента: New Sketch ✅, **Extrude (Press/Pull)** ✅ (скица върху стената, контурът ѝ като профил, Join; Cancel маха скицата), Edit Feature ✅, Edit Sketch ✅, Look At ✅; ⬜ Shell, Draft, Work Plane, Measure |
| Цилиндрична стена | **Hole** (съосен), Work Axis, Thread, Measure (диаметър) | ⛔ 2.3 / 2.9; ⬜ останалото |
| Тяло | Visibility, Hide Others, Appearance, Move Bodies, Combine, Mass | ⬜ ([2.13 §2а](2.13-booleans.md)) |
| Операция | **Edit Feature**, Edit Sketch, Suppress, Delete, Rename | 🟡 (в дървото) |
| Скица | Edit Sketch, Extrude, Revolve (ако има централна линия), Share/Unshare, Visibility | 🟡 (в дървото) |
| Крива в скица | конструктивна/централна линия, Dimension, Trim, Offset, Fix | 🟡 (контекстно меню в скицата) |
| Размер в скица | Edit (поле с израз, [0-ui §2.7](0-ui.md)), Driven, Tolerance, Delete | 🟡 |

| Поведение на лентата | Статус |
|---|---|
| Иконите са същите като в лентата с команди; име в подсказката | ✅ |
| Лентата не закрива избрания обект (поставя се над/под него, в рамките на изгледа) | 🟡 над точката на клика, в рамките на изгледа; ⬜ отчитане на очертанието на стената |
| Десен клик: пълното контекстно меню със същите команди + общите (Look At, Measure, Properties) | 🟡 |
| Може да се изключи (Application Options) | ⬜ |

## 7. Реализация (план)

- `kernel/query.rs`: `pick_face` ✅; добавяне на `pick_edge`, `pick_vertex` в екранни пиксели и `pick_all` (всички кандидати по дълбочина) за Select Other.
- `gui`: общо състояние `Hover { candidates, index }`. От него се рисуват prehighlight, подсказката и Select Other. Изборът е `Selection::{Face, Edge, Vertex, Body, Feature, …}` по устойчиви имена (правило 2). Контекстната лента е таблица „вид обект → команди“.
- Командите приемат предварително избрани обекти (pre-selection): Fillet с избрани ръбове, Extrude с избрана стена и т.н.
