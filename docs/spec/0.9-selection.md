# 0.9 Selection, prehighlight and context suggestions

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ waiting for another feature.

Filters, priority and the Shift + right-click menu are described in
[0.9a-selection-filters.md](0.9a-selection-filters.md).

## 1. Purpose

Every command starts with a selection: a face, edge, vertex, body, feature, sketch or curve. Selection must be **fast, visible and predictable**:
- what will be selected lights up as soon as it is pointed at;
- overlapping objects are easy to reach;
- a short list of the actions that make sense for the selected object appears next to it.

## 6. Context suggestions (our feature, after an Inventor idea)

Inventor offers context commands in two ways:
- the **Marking menu** on right click: a radial menu centred on the cursor, with commands depending on the environment (sketch, part, assembly). Next to it there is a short context menu (*overflow*). A mouse stroke towards a sector runs the command (Mark Mode).
- the older **mini-toolbar**: with an edge selected it shows Fillet and Chamfer.

Ours: **on every selection in the view a small bar of suggestions appears next to it**, ordered by likelihood. A click starts the command with the already selected object as its input. Esc or a click elsewhere hides it.

| Selected object | Suggestions | Status |
|---|---|---|
| Edge (straight or circular) | **Fillet**, **Chamfer**, Select Tangencies, Measure; an edge a sketch lies on: Project | 🟡 bar: Fillet/Chamfer (disabled, ⛔ 2.4/2.5), Edit Feature ✅; the length is in the tooltip |
| Several edges | Fillet, Chamfer (with all of them) | ⛔ 2.4 / 2.5 |
| Planar face | **New Sketch**, **Extrude** (Press/Pull — Cut/Join from the face), Shell (remove the face), Draft, Work Plane (offset), Look At, Measure | 🟡 bar: New Sketch ✅, **Extrude (Press/Pull)** ✅ (a sketch on the face, its outline as the profile, Join; Cancel removes the sketch), Edit Feature ✅, Edit Sketch ✅, Look At ✅; ⬜ Shell, Draft, Work Plane, Measure |
| Cylindrical face | **Hole** (coaxial), Work Axis, Thread, Measure (diameter) | ⛔ 2.3 / 2.9; ⬜ the rest |
| Body | Visibility, Hide Others, Appearance, Move Bodies, Combine, Mass | ⬜ ([2.13 §2a](2.13-booleans.md)) |
| Feature | **Edit Feature**, Edit Sketch, Suppress, Delete, Rename | 🟡 (in the browser) |
| Sketch | Edit Sketch, Extrude, Revolve (if there is a centerline), Share/Unshare, Visibility | 🟡 (in the browser) |
| Curve in a sketch | construction/centerline, Dimension, Trim, Offset, Fix | 🟡 (context menu in the sketch) |
| Dimension in a sketch | Edit (expression field, [0-ui §2.7](0-ui.md)), Driven, Tolerance, Delete | 🟡 |

| Bar behaviour | Status |
|---|---|
| The icons are the same as in the command ribbon; the name is in the tooltip | ✅ |

## 7. Implementation (plan)

- `kernel/query.rs`: `pick_face` ✅; add `pick_edge`, `pick_vertex` in screen pixels and `pick_all` (every candidate by depth) for Select Other.
- `gui`: a shared state `Hover { candidates, index }`. Prehighlight, the tooltip and Select Other are drawn from it. The selection is `Selection::{Face, Edge, Vertex, Body, Feature, …}` by persistent names (rule 2). The context bar is a table "object kind → commands".
- Commands accept pre-selected objects (pre-selection): Fillet with selected edges, Extrude with a selected face, etc.
