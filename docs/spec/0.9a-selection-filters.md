# 0.9а Един модел на избора: „всичко“ + филтри, приоритет и меню Shift + десен бутон

Статус: ✅ готово · 🟡 частично · ⬜ предстои · ⛔ чака друга функция.

🟡 тук означава: реализирано и с тестове (`command::selection`), чака визуална проверка в
приложението (скриптовете за X11 в `tools/` не работят под Windows).

Допълва [0.9-selection.md](0.9-selection.md) (видове обекти, Select Other, множествен
избор, контекстни предложения). Тук е описано **какво** може да се посочи и как се
съчетават желанието на потребителя (филтри, приоритет) с това, което чака отворената
команда.

## 1. Предназначение

Досега всеки режим и всяка команда имаха собствена логика „какво се посочва“: в режим
Faces and Edges не се избираха скици и работни елементи, в режим Sketch Features —
само скици, а командите проверяваха видовете поотделно. Целта:
- по подразбиране **се посочва всичко** (стени, ръбове, върхове, скици, работни
  елементи, Origin);
- потребителят **изключва** видове с филтри (отметки) и избира **приоритет** — дали клик
  върху стена избира стената, нейната операция или нейното тяло (Inventor: Select
  Priority);
- в команда се посочва **сечението**: видовете, които активният селектор приема
  (`PickKind`), ∩ филтъра на потребителя;
- **Shift + десен бутон** отваря до курсора меню с инструментите за избор (както в
  Inventor).

## 2. Входове

- филтър: множество от категории (виж §3), запазва се в `settings.json` → `options`;
- приоритет (Select Priority), правоъгълник (по посока / винаги Window / винаги
  Crossing), Enable Prehighlight — също се запазват;
- активният селектор на отворената команда (`command::flow::Selector::accepts`) или
  видовете, които командата без `Flow` приема;
- позицията на курсора (кандидати под него, Select Other).

## 3. Категории (филтри)

| Категория | Какво е | Inventor | Статус |
|---|---|---|---|
| Faces | стени на тела (и на повърхнинни тела) | Select Faces and Edges | 🟡 код и тестове; чака визуална проверка |
| Edges | ръбове | Select Faces and Edges | 🟡 код и тестове; чака визуална проверка |
| Vertices | именувани върхове | Select Faces and Edges | 🟡 код и тестове; чака визуална проверка |
| Features | цели операции (при приоритет Features) | Select Features | 🟡 код и тестове; чака визуална проверка |
| Solid Bodies | плътни тела (при приоритет Bodies) | Select Bodies | 🟡 код и тестове; чака визуална проверка |
| Surface Bodies | повърхнинни тела (при приоритет Bodies) | Select Bodies | 🟡 код и тестове; чака визуална проверка |
| Sketches | видими скици (клик върху крива избира скицата) | Select Sketch Features | 🟡 код и тестове; чака визуална проверка |
| Sketch Entities | точки и криви на скица като вход на команда (Hole, Work Point, Loft…) | — | 🟡 код и тестове; чака визуална проверка |
| Work Planes | работни равнини | (работни елементи винаги се избират) | 🟡 код и тестове; чака визуална проверка |
| Work Axes | работни оси | | 🟡 код и тестове; чака визуална проверка |
| Work Points | работни точки | | 🟡 код и тестове; чака визуална проверка |
| Origin | равнините на Origin | | 🟡 в команди (Plane/Axis), където равнините се виждат; в спокоен изглед не се рисуват, затова не се посочват |

| Правило | Поведение | Статус |
|---|---|---|
| **Select All** (по подразбиране) | всички категории са включени; бутон „Select All Filters“ връща всичко | 🟡 |
| Отметка за всяка категория | изключената категория не свети и не се избира — нито в спокоен изглед, нито в команда, нито с правоъгълник, нито в Select Other | 🟡 |
| Запазване | изборът оцелява при рестарт (`AppOptions::selection`, четене поле по поле) | 🟡 |
| Стените закриват и когато са филтрирани | филтрираната стена пак скрива ръбовете и върховете зад себе си (посочва се само видимото) | 🟡 |

## 4. Приоритет (Inventor: Select Priority в падащото меню Select)

| Приоритет | Inventor | Клик върху стена/ръб/връх избира | Статус |
|---|---|---|---|
| **Faces and Edges** (по подразбиране) | Select Faces and Edges | самия обект; скиците и работните елементи също се избират | 🟡 |
| **Features** | Select Features (Feature Priority) | операцията, която го е създала (ако Features е включено; иначе самия обект) | 🟡 |
| **Bodies** | Select Bodies | тялото (Solid Bodies / Surface Bodies) | 🟡 |
| **Sketch Features** | Select Sketch Features | скицата под курсора печели пред стени и ръбове | 🟡 |

| Ред при посочване (един и същ навсякъде) | Статус |
|---|---|
| работна точка > връх > работна ос > крива/точка на скица > ръб > стена > работна равнина > Origin (при Sketch Features: скицата първа) — разширение на [0-ui §3.2](0-ui.md) | 🟡 |
| Select Other обхожда кандидатите от **всички** включени категории в същия ред, при всеки приоритет (досега — само в Faces and Edges) | 🟡 |
| Prehighlight показва само това, което минава и през двата филтъра (команда ∩ потребител) | 🟡 |

## 5. Филтрите в команда

| Правило | Поведение | Статус |
|---|---|---|
| Сечение | посочва се само видът, който активният селектор приема **и** който е включен във филтъра | 🟡 |
| Празно сечение | ако филтърът изключва всичко, което селекторът приема, командата не „заклещва“ потребителя: важат видовете на селектора, а лентата на състоянието казва „Selection filter ignored: this input takes …“ | 🟡 |
| Приоритетът не важи в команда | командата сама решава какво е вход (стена, ръб…) | 🟡 |
| Команди без `Flow` (Fillet, Hole, Thread, Pattern, Work Feature, Extrude, Start Sketch, Project Geometry) | видовете им са описани на едно място (`active_pick_kinds`) | 🟡 |

## 6. Меню Shift + десен бутон (селекция)

Inventor: Shift + десен клик в графичния прозорец отваря менюто на командата Select до
курсора (приоритети и инструменти за избор). Обикновеният десен клик остава
контекстното меню (у нас — Select Other там също).

| Елемент | Спокоен детайл | В команда | В скица | Статус |
|---|---|---|---|---|
| Select Other | ✔ (кандидатите под курсора) | ✔ (само приеманите) | — | 🟡 спокоен детайл; ⬜ в команда (точката е неактивна) |
| Select Loop | ✔ (последният избран ръб или стената под курсора) | — | — | 🟡 |
| Select Tangencies | ✔ | — | — | 🟡 |
| Select Invert | ✔ | — | ✔ | 🟡 |
| Select All | ✔ (всичко, което минава филтъра) | — | ✔ (Ctrl+A) | 🟡 |
| Previous Selection | ✔ | — | — | 🟡 |
| Clear Selection | ✔ | — | ✔ | 🟡 |
| Window / Crossing (по посока, винаги Window, винаги Crossing) | ✔ | ✔ | ✔ | 🟡 |
| Филтри (отметки) | ✔ всички | ✔ само категориите, които селекторът приема | — | 🟡 |
| Select Priority | ✔ | — | — | 🟡 |
| Enable Prehighlight | ✔ | ✔ | ✔ | 🟡 |

| Правило | Статус |
|---|---|
| Менюто се отваря на мястото на курсора; Esc или клик извън него го затваря | 🟡 |
| Shift + десен бутон **не** започва Pan/Orbit (мишка Classic: десен бутон = Pan) и **не** отваря обикновеното контекстно меню | 🟡 |
| Обикновеният десен клик е непроменен | 🟡 |

## 7. Контрола в лентата / Quick Access Toolbar

| Елемент | Поведение | Статус |
|---|---|---|
| Падащо меню **Select** в Quick Access Toolbar | заглавие „Select: <приоритет>“ (+ „*“ когато има изключен филтър); приоритети (радио), филтри (отметки), Select All Filters, Window/Crossing, Enable Prehighlight, инструментите за избор | 🟡 |
| Достъпно в команда | QAT е винаги видим; филтрите се сменят и докато командата е отворена (сечението се преизчислява всеки кадър) | 🟡 |

## 8. Правоъгълник (window / crossing)

| Правило | Inventor | Статус |
|---|---|---|
| По посока: отляво надясно — Window (само изцяло вътре), отдясно наляво — Crossing (и пресечените) | GUID-B8F6E805 | ✅ (0.9) |
| Режим „винаги Window“ / „винаги Crossing“ от менюто | наша добавка (SOLIDWORKS Box/Cross Selection) | 🟡 |
| Правоъгълникът спазва филтъра и приоритета (ръбове, върхове, стени, скици; операции/тела при техния приоритет) | | 🟡 |

## 9. Избор в скица

| Правило | Статус |
|---|---|
| В скица се избират криви, точки, ограничения и размери (както досега, `SketchTools`); 3D филтърът не важи за собствената скица | ✅ (без промяна) |
| Shift + десен бутон: Select All, Select Invert, Clear Selection, Window/Crossing, Enable Prehighlight | 🟡 |
| Филтри вътре в скицата (само точки / само криви / размери) | ⬜ (следваща стъпка) |

## 10. Крайни случаи

- филтрирани са всички категории → нищо не свети, правоъгълникът не избира нищо, Select
  All не избира нищо; бутонът „Select All Filters“ е в менюто;
- изборът, който вече е направен, не се маха при промяна на филтъра (Inventor също);
  смяната на приоритета изчиства избора (видът на елементите се сменя);
- върхове без устойчиво име не се предлагат (правило 2).

## 11. Реализация

- `command::selection` (без GUI, с тестове): `Category`, `Filter` (битова маска,
  запис като списък на изключените), `Priority`, `BoxMode`, `kinds_filter(&[PickKind])`,
  `effective(selector, user)` → `Effective { filter, overridden }`, `resolve(raw,
  priority, filter, surface)`, `rank`, `filter_candidates`, `box_takes`, `shift_menu(ctx)`;
  тестове: сечение (8 комбинации), приоритет, ред и Select Other през смесени видове,
  правоъгълник, съдържание на менюто по контекст, запис; `tests/perf.rs`: 10k кандидата.
- `gui/select.rs`: `SelItem` (+ `Vertex`), кандидати под курсора във всички
  категории, правоъгълник, Select Loop, менюто Shift + десен бутон, падащото меню.
- `gui/mod.rs`: `pick_filter` (сечението за кадъра) се изчислява веднъж в началото на
  `viewport`; общите функции за посочване (`edge_under`, `plane_under`, `vertex_under`,
  `work_axis_or_point_under`, `sketch_under`, лицата по лъча) го питат.
- `PickKind::Point` (връх или работна точка) — за Work Point / Work Plane.
