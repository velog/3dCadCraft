# 1.2a Splines (Spline Interpolation, Control Vertex, Equation, Bridge)

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ waiting for another feature.

## 1. Purpose

Smooth curves for shapes that cannot be described with lines and arcs: handle profiles, blades, decorative outlines, paths for patterns and Sweep.

## 2. Kinds (Inventor 2027; in parentheses — SolidWorks)

| Kind | Behaviour | Status |
|---|---|---|
| **Control Vertex Spline** (Style Spline) | the curve is driven by a control polygon; it passes through the end points and is tangent to the first/last segment | ✅ (degree 3, uniform) |
| **Interpolation Spline** (B-spline through points) | passes **through** the points (fit points); shape from the smoothing method and from the handles | ✅ cubic C2, chord-length parameters, knots at the points (the classic cubic spline); natural ends |
| **Equation Curve** (Equation Driven Curve) | a curve from an equation: explicit y = f(x) or parametric x(t), y(t), with limits on t | ⬜ |
| **Bridge Curve** | a G2 transition between the ends of two curves | ⬜ |

## 3. Creation

| Behaviour | Status |
|---|---|
| CV: a click for every vertex, Enter/Done/double click ends; the start point may be an existing point | ✅ |
| Interpolation: a click for every point of the curve; Enter ends | ✅ (ribbon Sketch → Spline → Interpolation Spline; Enter / double click ends; live preview) |
| Closing: right click on the start point → **Close Curve** (periodic, C2 along the whole chain) | 🟡 Close Curve from the context menu (a checkbox; clearing it opens the curve again) ✅ — periodic C2, with a handle at the start C1; ⬜ right click exactly on the start point while drawing |
| Constraint inference while drawing (coincident at the start/end, tangency at the end) | 🟡 coincident ✅ |
| Input in a dialog: method (Fit points / Control vertices), degree (CV: 1…10 in AutoCAD; Inventor — 3) | ⬜ |

## 6. Implementation (plan)

`sketch`: a new curve kind `InterpSpline { points, handles, fit }`, building a B-spline through the points (global interpolation with chord-length parameterisation; handles = prescribed derivatives at the points), `Constraint::Smooth`. Kernel: `BSplineCurve` already has evaluation, derivatives and `clamped_uniform`; needed: interpolation, knot insertion, curvature. GUI: Interpolation Spline tool, handles in the view, context menu (Insert Point, Close Curve, Convert, Fit, Tension, Display Curvature).
