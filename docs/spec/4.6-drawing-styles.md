# 4.6 Drawing styles (Style and Standard Editor)

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ blocked by another feature.

> Owner's request (2026-10-26): one style editor for everything that shapes a drawing, filled in step by
> step. Interface first (rule 15): every style type and option of Inventor's editor is shown; options
> whose logic is missing are disabled with their status in the tooltip.

## 1. Purpose

A drawing's look (units and precision of dimensions, arrowheads, text heights, line types and weights,
centre marks, hatching, view labels, tables) comes from **styles** grouped by a **standard** (ISO, ANSI,
DIN …). The Style and Standard Editor (Manage › Styles Editor) lists every style type, lets the user
create, rename, change and purge styles, and choose which styles the active standard uses. Annotations
take the style that the standard's **Object Defaults** assign to their object type, and a single
annotation can take another style.

## 2. Inputs

- The active drawing's `DrawingDocument::styles` (a copy of the library's styles, as Inventor keeps
  *document* styles), the standard's defaults for a new drawing (ISO / ANSI / DIN).
- Later: a user style library on disk (Inventor's Design Data folder), Update / Save to library.

## 4. Browser and editing behaviour

- Manage › Styles Editor in a drawing opens the drawing's editor; right-click an annotation → *Edit
  <type> Style* opens it on that style (⬜).
- Every change is one Undo step and redraws the sheet at once (screen and PDF use the same values).

## 5. Edge cases and errors

- A style in use cannot be deleted; the last style of a type cannot be deleted.
- Old drawings (before styles) get the standard's defaults on load (serde default), so they draw as
  before.

## 6. Implementation

- `drawing::style`: `DrawingStyles` (layers, dimension / text / leader / centre mark / hatch / view
  annotation styles, object defaults), `DrawingStyles::of(StandardKind)`; stored in
  `DrawingDocument::styles` (additive, `#[serde(default)]`).
- `drawing::render`, `drawing::annot`, `drawing::sheet` read the active styles (line weights and types
  per layer, arrow sizes, gaps, precision, text heights, hatch angle / spacing, centre mark sizes).
- GUI `gui/drawing_styles.rs`: the editor window.

## 6a. Reference values from Inventor 2027

Read from Inventor 2027's own templates through its API on the owner's machine (`tools/inventor/`,
curated in `tests/data/inventor/styles_2027.json`, checked by `defaults_match_inventor_2027`). Our ISO
and ANSI defaults are these values:

| Item | ISO | ANSI (mm) |
|---|---|---|
| Dimension text | `Ø11,00`: comma, 2 decimals, trailing zeros, aligned | point, 2 decimals, horizontal |
| Arrow (Size × Height) | 2.5 × 1.0 | 2.5 × 1.0 |
| Extension (A) / Origin Offset (B) / Gap (C) / Spacing (D) / Part Offset (E) | 3.175 / 0 / 0.762 / 6 / 10 | 3.175 / 1.5875 / 0.8 / 6 / 10 |
| Note Text | Tahoma 3.5 mm | Tahoma 3.048 mm |
| Center Mark (mark / gap / overshoot) | 5 / 1.5 / 2.5, continuous layer | 6.35 / 3.0 / 3.175 |
| Layers (mm) | visible 0.5, hidden 0.35 dashed, centre 0.25, dimension 0.25, hatch 0.18, section line 0.7 chain, border 0.7, title 0.5 | |
| Border | 10 mm (A0 / A1: 20 mm), 6 × 4 zones from the bottom right, centring marks | |
| Title block | 170 × 30 mm: Designed by, Checked by, Approved by, Date, Date / company / title, Edition, Sheet | |

Differences we keep for now: the font (Tahoma is not ours to embed; the UI font is used); row 2 of
the title block shows part number, scale and material (empty in Inventor's); Inventor's Front view looks
at the XY plane (`FrontViewPlane` of its standard, Y up), ours at XZ (Z up) — an option *Front View
Plane* in the Standard is to do.
