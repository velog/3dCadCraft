# 1.5 Snapping and automatic constraints (Constraint Inference)

Status: ✅ done · 🟡 partial · ⬜ to do.

## 1. Purpose

While drawing, the cursor "senses" the existing geometry and typical positions (horizontal, perpendicular…). A glyph next to the cursor shows what will be created. On a click the corresponding constraint is added automatically (*persist*). This way the sketch comes out almost constrained already while drawing.

## 2. What is recognised

| Kind | Behaviour | Glyph | Status |
|---|---|---|---|
| **Coincident** to a point | the sketch's own points are **shared**; to projected ones a Coincident is added | small circle, "coincident" | ✅ |
| **On Curve** | a point on a line, circle, arc, spline → Coincident (point on curve) | dot, "on curve" | ✅ |
| **Midpoint** | the middle of a line → Midpoint | small circle, "midpoint" | ✅ |
| **Horizontal / Vertical** | a line (or a spline segment) within 3° of horizontal/vertical | H / V | ✅ |
| **Perpendicular / Parallel** | relative to the previous line in the chain | 90° / // | ✅ |
| Perpendicular / Parallel to **another** line | relative to a line the cursor passed over ("scrubbing") | 90° / // | ⬜ |
| **Tangent** | start from the end of an arc, along the tangent | T | 🟡 (dragging from the end gives a tangent arc) |
| **Tangent snap** to a circle/arc (Line) | Inventor: start the line on the circle and drag — a tangency glyph appears; SolidWorks: tangent snap; AutoCAD: the TAN object snap. Ours: when the cursor is on a circle/arc within 12 px of the point where a line from the previous point touches it, the point snaps there → the line ends on the curve (Coincident) and is **Tangent** to it. A line started on a circle/arc that leaves it at less than 8° from the tangent also becomes Tangent | small circle with a tangent, "tangent" | ✅ visually (DOF 5, redundant 0); tests `line_tangent_snap_to_a_circle`, `line_tangent_with_its_end_on_the_circle` |
| **Intersection** | a point at the intersection of two curves (and at a virtual intersection) | X | ⬜ |
| **Point Alignment** | Inventor (Application Options → Sketch → *Point alignment*): the end of the new element aligns in X or Y with a point of existing geometry; a dashed line is shown from the point to the cursor. If the option is off, alignment is "woken up" by passing the cursor over the point. In Inventor alignment only **places** the point, without a constraint | dashed line | ✅ (6 px; all drawing tools; Ctrl turns it off; *Point alignment* option in Constraint Settings and an **Align** button in the status bar). ⬜ "waking up" by passing over the point when the option is off |
| Alignment → constraint (our extension) | with *Persist* on, alignment adds **Horizontal** / **Vertical** between the two points (the same as in Inventor with the Horizontal button on two points). Example: two lines, the third ends at the level of the end of the first → Horizontal between the two ends | dashed line + H/V | ✅ for Line (on a conflict the line is created without it); the other tools only align |
| In X and in Y at once (two points) | the intersection of the two dashed lines | two dashed lines | ✅ |
| Circle quadrants | the points at 0°, 90°, 180°, 270° | — | ⬜ |
| Snap to Grid | to the grid nodes | — | ⬜ |

## 3. Control

| Behaviour | Inventor | Status |
|---|---|---|
| **Ctrl** (held) | no recognition for the current element | ✅ |
| Constraint Settings → Inference | *Infer constraints*, *Persist constraints* (only with Infer), choice of which kinds are recognised (Horizontal, Vertical, Parallel, Perpendicular, Midpoint, On Curve, Coincident), priority (∥/⊥ first to geometry or H/V first to the axes). In ours: a Constraint Settings button in the Constrain panel → Application Options | ✅; ⬜ priority, Tangent, Intersection |
| Snap radius | 12 px to a point, 8 px to a curve; the point has priority | ✅ |
| Snap on drop | a dragged point dropped on a point or curve is attached | ✅ |
| Refusal on a conflict | if the recognised constraint conflicts with the existing ones, the element is created **without** it | ✅ |
