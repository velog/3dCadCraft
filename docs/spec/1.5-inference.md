# 1.5 Прихващане и автоматични ограничения (Constraint Inference)

Статус: ✅ готово · 🟡 частично · ⬜ предстои.

## 1. Предназначение

Докато се чертае, курсорът „усеща“ съществуващата геометрия и типичните положения (хоризонтално, перпендикулярно…). Знак до курсора показва какво ще се създаде. При клик съответното ограничение се добавя автоматично (*persist*). Така скицата се получава почти дефинирана още при чертането.

## 2. Какво се разпознава

| Вид | Поведение | Знак | Статус |
|---|---|---|---|
| **Coincident** към точка | собствените точки на скицата се **споделят**; към проектирани се добавя Coincident | кръгче, „coincident“ | ✅ |
| **On Curve** | точка върху линия, окръжност, дъга, сплайн → Coincident (точка върху крива) | точка, „on curve“ | ✅ |
| **Midpoint** | среда на линия → Midpoint | кръгче, „midpoint“ | ✅ |
| **Horizontal / Vertical** | линия (или сплайн сегмент) до 3° от хоризонтала/вертикала | H / V | ✅ |
| **Perpendicular / Parallel** | спрямо предишната линия във веригата | 90° / // | ✅ |
| Perpendicular / Parallel към **друга** линия | спрямо линия, над която е минал курсорът („scrubbing“) | 90° / // | ⬜ |
| **Tangent** | начало от края на дъга, по допирателната | T | 🟡 (влачене от края дава допирателна дъга) |
| **Tangent snap** към окръжност/дъга (Line) | Inventor: започни линията върху окръжността и влачи — появява се знак за допирателна; SolidWorks: tangent snap; AutoCAD: обектна привръзка TAN. Наше: когато курсорът е върху окръжност/дъга до 12 px от точката, в която линия от предишната точка я допира, точката прихваща там → линията завършва върху кривата (Coincident) и е **Tangent** към нея. Линия, започната върху окръжност/дъга, която я напуска под по-малко от 8° от допирателната, също става Tangent | кръгче с допирателна, „tangent“ | ✅ визуално (DOF 5, redundant 0); тестове `line_tangent_snap_to_a_circle`, `line_tangent_with_its_end_on_the_circle` |
| **Intersection** | точка в пресечна точка на две криви (и във виртуална пресечна точка) | X | ⬜ |
| **Point Alignment** | Inventor (Application Options → Sketch → *Point alignment*): краят на новия елемент се подравнява по X или Y с точка на съществуваща геометрия; показва се пунктир от точката до курсора. Ако опцията е изключена, подравняването се „събужда“, като се мине с курсора през точката. В Inventor подравняването само **поставя** точката, без ограничение | пунктир | ✅ (6 px; всички инструменти за чертане; Ctrl изключва; опция *Point alignment* в Constraint Settings и бутон **Align** в лентата на състоянието). ⬜ „събуждане“ с минаване през точката, когато опцията е изключена |
| Подравняване → ограничение (наше разширение) | при включено *Persist* подравняването добавя **Horizontal** / **Vertical** между двете точки (същото като в Inventor с бутона Horizontal върху две точки). Пример: две линии, третата завършва на нивото на края на първата → Horizontal между двата края | пунктир + H/V | ✅ за Line (при конфликт линията се създава без него); другите инструменти само подравняват |
| Едновременно по X и по Y (две точки) | пресечната точка на двата пунктира | два пунктира | ✅ |
| Квадранти на окръжност | точките на 0°, 90°, 180°, 270° | — | ⬜ |
| Snap to Grid | към възлите на мрежата | — | ⬜ |

## 3. Управление

| Поведение | Inventor | Статус |
|---|---|---|
| **Ctrl** (задържан) | без разпознаване за текущия елемент | ✅ |
| Constraint Settings → Inference | *Infer constraints*, *Persist constraints* (само при Infer), избор кои видове се разпознават (Horizontal, Vertical, Parallel, Perpendicular, Midpoint, On Curve, Coincident), приоритет (∥/⊥ първо към геометрия или H/V първо към осите). При нас: бутон Constraint Settings в панела Constrain → Application Options | ✅; ⬜ приоритет, Tangent, Intersection |
| Радиус на прихващане | 12 px към точка, 8 px към крива; точката има предимство | ✅ |
| Прихващане при пускане | влачена точка, пусната върху точка или крива, се свързва | ✅ |
| Отказ при конфликт | ако разпознатото ограничение противоречи на съществуващите, елементът се създава **без** него | ✅ |
