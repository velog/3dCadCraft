# 2.16 Дърво на модела (Model Browser)

Статус: ✅ готово · 🟡 частично · ⬜ предстои.

## 1. Подреждане (като в Inventor)

```text
Part1
├─ Solid Bodies (N)          тела, резултат от операциите
├─ Origin                    YZ, XZ, XY, X/Y/Z Axis, Center Point
├─ Sketch1                   свободна скица — на мястото си в историята
├─ Extrusion1                операция; разгъва се:
│  └─ Sketch2                  консумираната ѝ скица
├─ Sketch2 (shared)          споделена скица — над първата операция, която я ползва
├─ Revolution1
│  └─ Sketch2
└─ End of Part
```

| Правило | Статус |
|---|---|
| Ред = ред на създаване (историята): скици и операции една след друга | ✅ |
| Консумирана скица е **под** операцията си; свободна — на мястото, където е създадена | ✅ |
| Споделена скица — и над операцията, и под всяка, която я ползва | ✅ |
| **Solid Bodies** горе, с броя на телата | ✅ (+ Surface Bodies) |
| Детайл без операции — без примерна форма (започва празен) | ✅ |
| Иконите отговарят на вида (скица, Extrude, Revolve, тяло, равнина, ос) | ✅ |
| Болни елементи — оранжеви, с причина в подсказката | ✅ |
| End of Part — влачене за „замразяване“ на историята | ⬜ |
| Преименуване (F2 / бавен двоен клик) | ⬜ |
