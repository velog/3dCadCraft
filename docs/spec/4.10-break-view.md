# 4.10 Break view (drawing stage D-S6)

> Shortens a long view: the part of the view between two break lines is left out and the rest is drawn
> closer together, with break lines in the gap. Dimensions across the break keep the true length.

## 1. Purpose

A long part (a shaft, a profile, a bar) drawn at a readable scale does not fit the sheet, and its middle often
holds no detail. **Break** removes a stretch of the view between two lines and draws the two remaining pieces
a small *gap* apart, with break lines showing where material was left out. A view can hold several breaks.
The view's model and its hidden-line computation do not change: a break is a 2D operation on the drawn view.

## 2. Inputs

1. Place Views › Modify › **Break** (alias BRK), or the right-click menu of a view.
2. The view (the selected view when the command starts).
3. The dialog's options (Style, Orientation, Display, Gap, Symbols, Propagate).
4. A click in the view: the first break line; a second click: the second break line. The stretch between them
   is removed. The preview shows the lines following the cursor.

One break per dialog; for another break the command runs again. ✅ the options float over the sheet; a preview line follows the cursor and the stretch to be removed is shaded; Esc cancels.

## 3. Options

| Option | Inventor behaviour | Restrictions | Status |
|---|---|---|---|
| View | the view to break: base, projected, isometric, section, detail, cropped views and slices of parts and assemblies | not a draft view | 🟡 any computed view (the selected view, else a click); its child views are made from the whole view; visually checked on a base view |
| Style › Rectangular | break edges drawn along the cut geometry as a wavy / zigzag line; meant for non-cylindrical parts and every sectioned broken view | | 🟡 a wave across the geometry at each piece's end (from where the visible lines cross the break line); the wave's exact shape is ours; visually checked |
| Style › Structural | stylised break lines: a straight line across the view with 1–3 break symbols (the "Z" mark) | | ✅ a straight line at each piece's end, half the gap past the geometry, with the symbols evenly spaced; visually checked (2 symbols) |
| Orientation › Horizontal / Vertical | the direction the view is shortened in (Horizontal: break lines are vertical) | cannot be changed after creation (delete and place again) | ✅ (Edit Break shows it disabled); Horizontal visually checked, Vertical by test |
| Orientation › Aligned | the break lines square to a picked line of the view | fixed after creation | ⬜ |
| Display (Min–Max slider) | a level 1–10 (default 5): Rectangular — the count / pitch of the waves of the break edges; Structural — the amplitude of the break line | | ✅ a slider 1–10, default 5; visually checked |
| Gap | the distance between the pieces on the sheet (drawing units); default 6 mm | > 0 | ✅ an expression field, sheet mm at any scale (a 200 mm bar with 60–140 removed: 126 mm wide at 1:1, 125 with a 5 mm gap, as in Inventor); visually checked (6 → 10 mm) |
| Symbols | 1–3 break symbols per break line (default 1) | Structural only | ✅ |
| Propagate to parent view | the break is applied to the parent view too | depends on the view type and Break Inheritance | ⬜ (shown disabled) |
| Break inheritance | orthographic child views whose projection is parallel to the break lines inherit the break by default; isometric children can, but do not by default | | ⬜ |

### Dimensions and annotations

| Behaviour | Inventor | Status |
|---|---|---|
| A dimension across the break, both ends kept | shows the true (unbroken) value; its dimension line gets a break symbol matching the break lines | 🟡 the true value, drawn across the shortened view (80,00 over a broken 80 mm plate; 200 over Inventor's bar by test); the break symbol on the dimension line ⬜ |
| A dimension with an end in the removed stretch | hidden | ✅ by test (`Orphan::Broken`: hidden, not shown as orphaned) |
| Annotations attached in the removed stretch | hidden; shown again when the break moves or gets smaller | 🟡 annotations on a point or circle there (dimensions, centre marks, hole notes) |

## 4. Browser and editing

| Behaviour | Inventor | Status |
|---|---|---|
| Browser | a Break node under the view | ✅ `Break<k>` under its view (before the child views); double-click = Edit Break; its menu: Edit Break, Suppress (the view drawn whole, the node struck through; `ViewBreak::suppressed`, no format revision), Delete; visually checked |
| Edit Break | right-click a break line › Edit Break: Style, Display, Gap, Symbols (not Orientation) | ✅ right-click a break line or its gap › Edit Break; one Undo step; visually checked |
| Drag | dragging the break moves it; dragging one break line changes how much is removed | ✅ a line (resize cursor) or the gap; one Undo step on release; overlapping positions refused; visually checked |
| Delete | right-click › Delete: the view is whole again | ✅ Delete Break; Undo brings it back; visually checked |
| Edit Sketch | the break has a sketch that can be edited | ⬜ |

## 5. Edge cases and errors

- Both clicks at the same place, or nothing of the view between them: `Break: the break removes nothing`. ✅
- Breaks overlapping each other in one view: refused (`Break: it overlaps another break`). ✅ (at most 8 breaks per view)
- A circle (hole, centre mark) whose centre lies in the removed stretch is left out with its annotations.

## 6. Implementation

- `drawing::brk::ViewBreak` in `DrawingView::breaks` (skipped when empty; old builds ignore the field and draw
  the view whole, so no format revision): style, orientation, the removed stretch `from..to` in the view plane
  (model mm, true coordinates), gap (sheet mm), display, symbols. `DrawingDocument::add_break / set_break /
  remove_break` check emptiness and overlap (`brk::check`).
- `brk::apply` clips a view's computed `ViewLines` (cached, whole) at the removed stretches — polylines exactly,
  cut-face loops by half planes (closed loops per piece), bends inside left out — and keeps the coordinates
  true. `ViewLines::breaks` (`BreakMap`, `Copy`) rides into `annot::Placement`: `to_sheet` shortens a true
  point (pulls the pieces together; the gap is sheet mm at the view's scale), `to_view` lengthens a sheet
  point (a point in the gap goes to the nearer end). Dimensions measure the true points, so their values are
  true without an unbreak step; `ViewLines::center / size` are of the shortened view, so the view keeps its
  centre (as Inventor's does). The GUI applies the breaks after the line jobs in `sheet_lines` (cached per
  view by the source lines, the breaks and the scale).
- Break lines are display primitives of the view (`render::view_extras`, `brk::break_lines`), on the view's
  visible-line layer (screen and PDF).
- GUI `gui/drawing_break.rs`: the command (`DrwCmd::Break`, options over the sheet, clicks, preview), Edit
  Break, drags (`break_grips`), Delete Break; the view's right-click menu has Break, Edit Break, Delete Break.
- Speed: 3 breaks over 100 000 points 4.4 ms (`tests/perf_drawing.rs`, budget 50 ms).
