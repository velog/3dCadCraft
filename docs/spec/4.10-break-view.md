# 4.10 Break view (drawing stage D-S6)

> Shortens a long view: the part of the view between two break lines is left out and the rest is drawn
> closer together, with break lines in the gap. Dimensions across the break keep the true length.

## 1. Purpose

A long part (a shaft, a profile, a bar) drawn at a readable scale does not fit the sheet, and its middle often
holds no detail. **Break** removes a stretch of the view between two lines and draws the two remaining pieces
a small *gap* apart, with break lines showing where material was left out. A view can hold several breaks.
The view's model and its hidden-line computation do not change: a break is a 2D operation on the drawn view.

## 2. Inputs

1. Place Views › Modify › **Break** (alias BRK), or the right-click menu of a view.
2. The view (the selected view when the command starts).
3. The dialog's options (Style, Orientation, Display, Gap, Symbols, Propagate).
4. A click in the view: the first break line; a second click: the second break line. The stretch between them
   is removed. The preview shows the lines following the cursor.

One break per dialog; for another break the command runs again.

## 3. Options

| Option | Inventor behaviour | Restrictions | Status |
|---|---|---|---|
| View | the view to break: base, projected, isometric, section, detail, cropped views and slices of parts and assemblies | not a draft view | ⬜ |
| Style › Rectangular | break edges drawn along the cut geometry as a wavy / zigzag line; meant for non-cylindrical parts and every sectioned broken view | | ⬜ |
| Style › Structural | stylised break lines: a straight line across the view with 1–3 break symbols (the "Z" mark) | | ⬜ |
| Orientation › Horizontal / Vertical | the direction the view is shortened in (Horizontal: break lines are vertical) | cannot be changed after creation (delete and place again) | ⬜ |
| Orientation › Aligned | the break lines square to a picked line of the view | fixed after creation | ⬜ |
| Display (Min–Max slider) | % of the gap: Rectangular — the count / pitch of the waves of the break edges; Structural — the amplitude of the break line | | ⬜ |
| Gap | the distance between the two pieces on the sheet (drawing units) | > 0 | ⬜ |
| Symbols | 1–3 break symbols per break line | Structural only | ⬜ |
| Propagate to parent view | the break is applied to the parent view too | depends on the view type and Break Inheritance | ⬜ |
| Break inheritance | orthographic child views whose projection is parallel to the break lines inherit the break by default; isometric children can, but do not by default | | ⬜ |

### Dimensions and annotations

| Behaviour | Inventor | Status |
|---|---|---|
| A dimension across the break, both ends kept | shows the true (unbroken) value; its dimension line gets a break symbol matching the break lines | ⬜ |
| A dimension with an end in the removed stretch | hidden | ⬜ |
| Annotations attached in the removed stretch | hidden; shown again when the break moves or gets smaller | ⬜ |

## 4. Browser and editing

| Behaviour | Inventor | Status |
|---|---|---|
| Browser | a Break node under the view | ⬜ |
| Edit Break | right-click a break line › Edit Break: Style, Display, Gap, Symbols (not Orientation) | ⬜ |
| Drag | dragging the break moves it; dragging one break line changes how much is removed | ⬜ |
| Delete | right-click › Delete: the view is whole again | ⬜ |
| Edit Sketch | the break has a sketch that can be edited | ⬜ |

## 5. Edge cases and errors

- Both clicks at the same place, or nothing of the view between them: `Break: the break removes nothing`.
- Breaks overlapping each other in one view: refused (`Break: it overlaps another break`).
- A circle (hole, centre mark) whose centre lies in the removed stretch is left out with its annotations.

## 6. Implementation

- `drawing::ViewBreak` in `DrawingView::breaks` (skipped when empty; old builds draw the view whole):
  style, orientation, the two lines in the view plane (model mm, unbroken), gap (sheet mm), display, symbols.
- `drawing::brk` maps a view's computed `ViewLines` (cached, unbroken) to broken ones: polylines and cut-face
  loops clipped at the break lines and moved together; edges and circles inside a removed stretch left out;
  `ViewLines::breaks` keeps the map so dimensions measure true values (`unbreak`).
- Break lines are display primitives of the view (`render`), on the view's visible-line layer.
- GUI `gui/drawing_break.rs`: the command (dialog from `drawing_planned` rows, clicks, preview), Edit Break,
  drags, Delete.
