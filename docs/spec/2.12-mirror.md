# 2.12 Mirror (огледално копие на операции и тела)

## 1. Предназначение

Прави огледално копие на операции или на цяло тяло спрямо равнина (лява и дясна ръка,
симетрични детайли).

## 2. Входни данни

- **Features** или **Solid** (режим).
- **Mirror Plane:** основна или работна равнина, или плоска стена.
- При Solid: **Join** / **New Solid**, **Remove Original**.

## 3. Настройки

| Опция | Поведение в Inventor | Ограничения | При нас |
|---|---|---|---|
| Команда | 3D Model → Pattern → Mirror; в 2027 още е диалог | | ⬜ |
| Mirror individual features | копира избраните операции; зависимите се добавят сами | | ⬜ Extrude и Revolve; Shell, Draft, Fillet, Chamfer → грешка |
| Mirror a solid | копира цялото тяло | | ⬜ |
| Mirror Plane | основна/работна равнина или плоска стена | | ⬜ |
| Join / New Solid | обединява огледалото с тялото или го прави отделно тяло | Solid | ⬜ |
| Remove Original | маха оригинала, остава само огледалото | Solid | ⬜ |
| Creation Optimized / Identical / Adjust to Model | | | ⬜ при нас винаги Identical |
| Preview | | | ⬜ |

## 4. Поведение в дървото и при редакция

- `Mirror1` в дървото. Стените на огледалото са `Mirror1#1:<името при оригинала>`.
- Edit Feature отваря диалога с избраното.

## 5. Крайни случаи и грешки

- Огледалната равнина пресича оригиналната операция: копието се застъпва с оригинала.
  При Join това е нормално обединение.
- Операция, която не може да се копира сама: както при масивите.
- Известни проблеми в SolidCraft: Mirror на cut + loft (#1669).

## 6. Реализация

Същият модул като масивите (`part::pattern`, `PatternKind::Mirror`): отражение
`p' = p − 2((p − o)·n)n` като матрица за `sk::transform_matrix` (определителят е −1, а
ядрото обръща ориентацията само).
