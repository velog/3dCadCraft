# 2.12 Mirror (огледално копие на операции и тела)

## 1. Предназначение

Прави огледално копие на операции или на цяло тяло спрямо равнина (лява и дясна ръка,
симетрични детайли).

## 2. Входни данни

- **Features** или **Solid** (режим).
- **Mirror Plane:** основна или работна равнина, или плоска стена.
- При Solid: **Join** / **New Solid**, **Remove Original**.

## 3. Настройки

„Чака визуална проверка“: направено и проверено с тестове, но не и в работещата програма.

| Опция | Поведение в Inventor | Ограничения | При нас |
|---|---|---|---|
| Команда | 3D Model → Pattern → Mirror; в 2027 още е диалог | | 🟡 бутон в панела Pattern; при нас панел в Properties като масивите (OK / Apply / Cancel), F1; чака визуална проверка |
| Mirror individual features | копира избраните операции; зависимите се добавят сами | | 🟡 Extrude и Revolve (Join / Cut / New Solid), масив или друго огледало; зависимите не се добавят сами; Shell, Draft, Fillet, Chamfer → грешка; чака визуална проверка |
| Mirror a solid | копира цялото тяло | | 🟡 избраните тела (без избор: всички); чака визуална проверка |
| Mirror Plane | основна/работна равнина или плоска стена | | 🟡 клик върху стена или равнина, бутони XY/XZ/YZ; чака визуална проверка |
| Join / New Solid | обединява огледалото с тялото или го прави отделно тяло | Solid | 🟡 чака визуална проверка |
| Remove Original | маха оригинала, остава само огледалото | Solid | 🟡 огледалото взима името на тялото на оригинала (по-късните операции го намират); чака визуална проверка |
| Creation Optimized / Identical / Adjust to Model | | | 🟡 винаги Identical |
| Preview | | | 🟡 ръбовете на огледалото, стената на равнината осветена |

## 4. Поведение в дървото и при редакция

- `Mirror1` в дървото (id `Mirror1`). Стените на огледалото са
  `Mirror1#2:<името при оригинала>` (оригиналът е копие 1, както при масивите).
- Edit Feature отваря панела с избраното; промяна на оригинала се отразява и в огледалото.

## 5. Крайни случаи и грешки

- Огледалната равнина пресича оригиналната операция: копието се застъпва с оригинала.
  При Join това е нормално обединение.
- Огледало на отвор, което не пада върху тялото: „Cut: none of the copies intersects the
  body“; детайлът не се променя.
- Без равнина: „select the mirror plane“.
- Операция, която не може да се копира сама: както при масивите.
- Известни проблеми в SolidCraft: Mirror на cut + loft (#1669) — при нас още няма Loft.

## 6. Реализация

Същият модул като масивите (`part::pattern`, `PatternKind::Mirror`): отражение
`p' = p − 2((p − o)·n)n` (`pattern::mirror_matrix`, по SolidCraft) като матрица за
`sk::transform_matrix` (определителят е −1, а ядрото обръща ориентацията само).
Тестове: `tests/matrix.rs` („mirror …“), `kernel::exact::tests`
(`rotated_and_mirrored_copies_are_valid`), `tests/perf.rs`.
