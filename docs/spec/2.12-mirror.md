# 2.12 Mirror (mirrored copy of features and bodies)

## 1. Purpose

Makes a mirrored copy of features or of a whole body about a plane (left and right hand,
symmetric parts).

## 2. Inputs

- **Features** or **Solid** (mode).
- **Mirror Plane:** an origin or work plane, or a planar face.
- With Solid: **Join** / **New Solid**, **Remove Original**.

## 3. Options

"Waiting for a visual check": done and proven by tests, but not in the running program.

| Option | Inventor behaviour | Restrictions | Ours |
|---|---|---|---|
| Command | 3D Model → Pattern → Mirror; in 2027 still a dialog | | 🟡 button in the Pattern panel; in ours a panel in Properties like the patterns (OK / Apply / Cancel), F1; waiting for a visual check |
| Mirror individual features | copies the selected features; dependent ones are added automatically | | 🟡 Extrude and Revolve (Join / Cut / New Solid), a pattern or another mirror; dependent ones are not added automatically; Shell, Draft, Fillet, Chamfer → error; waiting for a visual check |
| Mirror a solid | copies the whole body | | 🟡 the selected bodies (no selection: all); waiting for a visual check |
| Mirror Plane | origin/work plane or planar face | | 🟡 click on a face or a plane, XY/XZ/YZ buttons; waiting for a visual check |
| Join / New Solid | merges the mirror with the body or makes it a separate body | Solid | 🟡 waiting for a visual check |
| Remove Original | removes the original, only the mirror remains | Solid | 🟡 the mirror takes the name of the original's body (later features find it); waiting for a visual check |
| Creation Optimized / Identical / Adjust to Model | | | 🟡 always Identical |
| Preview | | | 🟡 the edges of the mirror, the plane's face highlighted |

## 4. Browser and editing behaviour

- `Mirror1` in the browser (id `Mirror1`). The faces of the mirror are
  `Mirror1#2:<name in the original>` (the original is copy 1, as with the patterns).
- Edit Feature opens the panel with the selection; a change to the original is reflected in the mirror too.

## 5. Edge cases and errors

- The mirror plane intersects the original feature: the copy overlaps the original.
  With Join this is a normal union.
- A mirror of a hole that does not land on the body: "Cut: none of the copies intersects the
  body"; the part does not change.
- No plane: "select the mirror plane".
- A feature that cannot be copied on its own: as with the patterns.
- Known problems in SolidCraft: Mirror of cut + loft (#1669) — we have no Loft yet.

## 6. Implementation

The same module as the patterns (`part::pattern`, `PatternKind::Mirror`): the reflection
`p' = p − 2((p − o)·n)n` (`pattern::mirror_matrix`, after SolidCraft) as a matrix for
`sk::transform_matrix` (the determinant is −1, and the kernel reverses the orientation itself).
Tests: `tests/matrix.rs` ("mirror …"), `kernel::exact::tests`
(`rotated_and_mirrored_copies_are_valid`), `tests/perf.rs`.
