# 1.7 Sketch patterns and mirror (Sketch → Pattern)

Status: ✅ done · 🟡 partial · ⬜ to do.

## 1. Purpose

Repeats selected geometry in rows and columns (Rectangular), around a point (Circular) or mirrored about a line (Mirror). The result is **associative**: changing the original or the spacing moves all the copies.

## 2. Rectangular

| Option | Behaviour in Inventor | Status |
|---|---|---|
| Geometry | the selected geometry (pre-selection or selection + Enter) | ✅ |
| Direction 1 / 2 | a line setting the direction; Flip button | ✅ |
| Count | count (including the original) for each direction | ✅ |
| Spacing | distance between adjacent copies | ✅ |
| **Suppress** | selected copies are turned off (they do not take part in profiles) | ✅ (after creation, from the copy's menu) |
| **Associative** | the copies follow the original; off → independent copies | ✅ (turning it off = Break Pattern) |
| **Fitted** | Spacing is the total length, not the step | ✅ the dimension in the sketch is on the total length |
| Preview | the copies are shown while the direction is being picked | ✅ |

## 3. Circular

| Option | Behaviour | Status |
|---|---|---|

| Axis | point (centre) | ✅ |

| Flip | clockwise | ✅ |
| Suppress / Associative / Fitted | as for Rectangular; Fitted on: the angle is the total, off: the angle is between neighbours | ⬜ / ✅ always / ✅ |

| Option | Behaviour | Status |

## 5. The pattern as an object in the sketch (editing after creation)

In Inventor a pattern is not just a pile of copies. It is an **object** in the sketch: it remembers the geometry, the direction or the centre, the count and the spacing, and it can be edited, suppressed or deleted as a whole. The same must hold for us.

### 5.1 What is stored

| Data | Status |
|---|---|
| The pattern in the sketch (`SketchPattern`): kind (Rectangular / Circular), the original curves, the directions (line, Flip, count, spacing, Fitted) or the centre (point, count, angle, Flip, Fitted) | ✅ |
| The copies per instance: `[instance] → curves, points`, so it is known which instance is which | ✅ |
| The constraints the pattern created (step, Translated/Rotated, Equal), so they can be removed and created again | ✅ |
| The suppressed instances | ✅ |
| Everything is saved in the file (adding-only) | ✅ |

### 5.2 Selection and menus

| Behaviour | In Inventor | Status |
|---|---|---|
| Hovering a curve of the pattern | highlights **the whole pattern** (original and copies) in a weaker colour, and the curve under the cursor more strongly | ✅ (the whole pattern in the selection colour) |
| Right click on a curve of the pattern | context menu with the commands below | ✅ |
| **Edit Pattern** | opens the pattern's settings (the same as at creation) in Properties, with a preview; changing the count, spacing, angle, direction, Flip and Fitted recreates the copies; OK confirms, Cancel restores | ✅ |
| **Suppress Element** | the instance under the cursor becomes **suppressed**: it is shown dashed, it does not take part in profiles, the relations of the others are kept | ✅ (construction style) |
| **Unsuppress Element** | restores the instance | ✅ |
| **Delete Pattern** | removes the copies and the pattern's constraints; **the original stays** | ✅ |
| **Break Pattern** (Associative off) | the copies become ordinary independent geometry: the internal relations and the step are removed; the pattern disappears as an object | ✅ |
| Delete on a copy | in Inventor a copy cannot be deleted on its own; Suppress is offered | ✅ |
| Delete on the original | deletes the original and the whole pattern | ✅ (Delete Pattern test) |

### 5.3b Useful capabilities from SolidWorks (Linear / Circular Sketch Pattern)

Inventor has only Rectangular, Circular and Mirror in a sketch. SolidWorks has more things that are worth having:

| Capability (SolidWorks) | Ours | Status |
|---|---|---|
| **Instances to Skip** — clicking a copy in the preview skips it already at creation | Suppress in the Edit Pattern preview (click on a copy) | ✅ "Skip elements by click" toggle in Edit Pattern (the pattern enters Edit Pattern right after creation); the skipped ones are dashed |
| Direction along the sketch's X/Y axis, without a line | Direction = the sketch's X or Y | ✅ X / Y / X + Y buttons in Rectangular Pattern (fixed construction axes through the selection) |
| The direction's angle as a value | ⛔ (the direction comes from a line) | ⬜ |
| *Dimension X spacing*, *Display instance count* — the step dimension and the count are shown in the sketch | the step is already a dimension ✅; ⬜ a label for the count | ✅ the step is a dimension; label "x N" / "x N x M" next to the last copy |
| Circular: **Radius** and **Arc angle** (the centre is given by a radius and an angle from the geometry) | | ✅ "Or centre at radius … angle … Create": a new centre at a given distance and angle from the first point of the selection, with a dimension for the radius |
| Circular: *Equal spacing* | = Fitted with 360° | ✅ |
| Pattern along a curve (Pattern along Path) — neither Inventor nor SolidWorks/Fusion has it in a sketch (only as a 3D feature) | our extension: copies at equal distances along a line/arc/spline | ✅ Pattern along Path button: line, arc or spline; the copies are moved to stations at equal chords (a dimension on the first, Equal for the others); Count/Spacing in Edit Pattern; no rotation along the tangent (⬜) |

### 5.4 Edge cases

- Edit Pattern with a count of 1 → refused (the pattern disappears only with Delete Pattern). ✅
- A deleted direction line or centre point → the pattern becomes **sick**: a warning in the menu and in Properties, Edit Pattern is disabled; Delete Pattern or Break Pattern fix it. ✅
- Undo restores the pattern with all its copies and suppressions. ✅
- A suppressed instance on which other geometry was later drawn does not get in the way of that geometry. ⬜

## 6. Associativity — how it works for us

- **The first step** is a construction line with a **dimension**: Distance for Rectangular, Angle and Equal for Circular. Changing the dimension moves the whole pattern. ✅
- Each copy repeats the step through the internal constraints `Translated` / `Rotated` (not shown). ✅
- The copies **add no degrees of freedom**: a test for every combination, including arcs and circles. ✅
- A copy of an arc already has the equation "the end is on the circle". So one of its ends is tied only tangentially, otherwise every copy would be over-constrained. The same holds for Mirror (`SymmetricOnArc`). ✅
- Edit Pattern (changing the count after creation). ⬜
