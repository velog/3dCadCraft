# 1.8 Проектиране на геометрия (Sketch → Create → Project Geometry)

Статус: ✅ готово · 🟡 частично · ⬜ предстои · ⛔ чака друга функция.

## 1. Предназначение

Пренася ръбове, върхове, стени, работни елементи или геометрия от други скици в текущата скица като **референтна** геометрия. Тя е фиксирана, оранжева, асоциативна и обновява се при промяна на източника. Към нея се оразмерява и ограничава.

## 2. Команди

| Команда | Поведение в Inventor | Статус |
|---|---|---|
| **Project Geometry** (лента Sketch → Create) | клик върху ръб, връх, стена (всичките ѝ контури), работна равнина/ос/точка, ос/равнина/точка от Origin или крива от друга видима скица → референтна геометрия в равнината на скицата. Командата остава активна до Esc | 🟡 прави ръбове на модела (асоциативно по имената на върховете, `PartDocument::project_edge`); бутонът е превключвател (втори клик спира); върхове, стени, работни елементи, криви ⬜; чака визуална проверка |
| Shift + клик | проектира като **construction** (при включен Construction — обратно) | ⬜ |
| Ctrl при проектиране | без асоциативна връзка (неасоциативно копие) | ⬜ |
| **Project Cut Edges** | сечението на тялото с равнината на скицата; **неасоциативна** снимка | ⬜ |
| Project Flat Pattern | разгъвка (ламарина) | ⛔ (5.6) |
| Project to 3D Sketch / Include Geometry | крива върху стени, ръбове в 3D скица | ⛔ (1.10) |
| Автоматична проекция при създаване (Application Options → Sketch) | началото на детайла; ръбовете на стената, върху която е скицата | ✅ прави ръбове |
| *Autoproject edges during curve creation* | ръб, „натрит“ с курсора при чертане, се проектира | ⬜ |
| **Break Link** (контекстно меню на проекция) | проектираната геометрия става обикновена, редактируема, без връзка | 🟡 от References ✅ (`PartSketch::break_link`); ⬜ от контекстното меню в изгледа |

## 3. Поведение

| Поведение | Статус |
|---|---|
| Линия → линия; окръжност/дъга в успоредна равнина → окръжност/дъга; наклонена → елипса; сплайн → неасоциативен референтен сплайн | 🟡 линии; ⬜ окръжности, дъги, елипси, сплайни |
| Проекция на **стена** = всичките ѝ контури (loops); контурите се подрязват, ако се застъпват | ⬜ |
| Асоциативност: при регенерация проекцията се преизчислява по устойчивото име на източника | ✅ (точки и ръбове на стената) |
| Разделени/слети линии в източника остават една референтна линия | ⬜ |
| Изчезнал източник → проекцията остава като **фиксирани** криви, ограниченията и размерите към нея се запазват; скицата е болна (жълто/оранжево в дървото) | ✅ замръзване + болна скица |
| Проектираната геометрия може да се **изтрие**; ръбовете на стената, върху която е скицата (автоматични), не могат | 🟡 автоматичните са защитени ✅; ⬜ изтриване на проекции от Project Geometry |
| Проектираната геометрия не се редактира (освен след Break Link) | ✅ / ⬜ Break Link |
| Проектирана геометрия участва в профили | ✅ (нормален стил) |
| Цвят: референтната геометрия е различна от обикновената (у нас — оранжева, като фиксирана) | ✅ |

## 3а. Управление на референциите (наша разширена функция)

Inventor показва връзките само косвено (болна скица, Break Link). Предлагаме панел, в който референциите се управляват явно:

| Поведение | Статус |
|---|---|
| Properties на скицата → секция **References**: всяка проекция с източника (`Extrusion1:Side:…`, `Origin: X Axis`, `Sketch2: Line 3`) и състояние ✔ / липсва | ✅ „References (N)“ (отваря се сама при липсващ източник): кратко име (`Extrusion1 · edge 1`, `Origin · Center Point`), пълните имена в подсказката, ✔ / ! за липсващ |
| Посочване на ред → източникът и проекцията светват в изгледа | 🟡 проекцията светва (оранжево) ✅; ⬜ източникът в модела |
| Действия на ред: **Break Link**, **Delete**, **Replace** (нов източник с клик; ограниченията остават върху същата геометрия) | 🟡 Break Link ✅, Delete ✅ (общите крайни точки остават); ⬜ Replace |
| В дървото: под скицата възел **References (N)**; при липсващ източник — предупредителен цвят | ⬜ |
| Обратна посока: в Properties на операция/стена — „Used by“: кои скици проектират от нея (за да се види какво ще се счупи при изтриване) | ⬜ |
| Изтриване на операция, от която проектират скици → предупреждение с техния списък | ⬜ |

## 3б. Нужда от проекция при Revolve и размери

| Поведение | Статус |
|---|---|
| Оста на Origin (X/Y/Z), проектирана в скицата, може да е ос на Revolve и линия за диаметрален размер | ⬜ (Revolve приема X/Y/Z директно ✅) |
