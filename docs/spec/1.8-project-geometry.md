# 1.8 Project Geometry (Sketch → Create → Project Geometry)

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ blocked by another feature.

## 1. Purpose

Brings into the current sketch geometry that already exists elsewhere: edges and vertices of the body, work features, the part origin and **points and curves from other sketches**. The result is **reference (projected) geometry**. It is fixed and **associative**: it updates when the source changes. It can be dimensioned and constrained to, and profiles and paths can be made from it.

Typical case (requested by the owner): two circles in two sketches on different planes and a spline in a third sketch that must start and end at their centres. Without projection the centres cannot be snapped to. With Project Geometry the centres are projected into the third sketch as fixed points, the spline snaps to them, and Sweep/Loft uses it as a path.

## 2. Inputs

| Input | Behaviour in Inventor 2027 | Status |
|---|---|---|
| A point from another sketch (point, centre, end of a line/arc, spline point) | projected as a fixed point | 🟡 done, waiting for a visual check (`SketchGeo::Point`) |
| A line from another sketch | a line in the sketch plane; if it is perpendicular to the plane — a point | 🟡 line ✅; a perpendicular line is refused with a message (it does not become a point) |
| A circle / arc from another sketch | in a parallel plane — a circle/arc with the same radius; in an inclined one — an ellipse | 🟡 parallel ✅ (also a flipped normal: the arc is reversed); inclined ⬜ (refused: "project its centre") |
| A spline from another sketch | projected spline | 🟡 CV spline — exact (affine projection of the control points); interpolation spline — the points and handles are projected, the chord-length parameterisation is recomputed (exact only in a parallel plane) |
| A straight model edge | a reference line between the projected vertices (by their names) | 🟡 done, waiting for a visual check (`project_edge`) |
| A circular model edge (circle, arc) | a circle/arc (in an inclined plane — an ellipse) | 🟡 parallel to the sketch ✅ (`project_model_edge`, by `EdgeRef`: the names of the two faces + a point *on the curve* — a chord's middle made both halves of a hole's rim one edge); the centre sits on the bisector of the two ends, so a kernel vertex a hair off the circle still closes the profile; in an inclined sketch the ellipse is an interpolation spline through 18 points of the circle (9 of an arc), associative (`link::edge_shape_on`; 2026-10-27, area within 1 %); a true ellipse ⬜ (no ellipse entity yet, 1.2) |
| Another curved edge (spline) | projected spline | 🟡 an interpolation spline through 9 points evenly spaced along the edge (18 on a closed one), associative (`link::curve_shape`): a Variable fillet's corners, a split through a blend; waiting for a visual check |
| A model vertex | fixed point | 🟡 a click on a vertex projects it (`project_point`, `PointRef::Vertex`, associative); waiting for a visual check |
| Chains of picked edges | the projected edges are connected | 🟡 every curved edge's ends are the projected vertices (`project_model_edge`), shared with straight edges picked before or after: edges picked one by one close into a profile (test: 8 edges of a rounded plate, one region); waiting for a visual check |
| A face (all its loops) | projects all loops; overlaps are trimmed | 🟡 a click on a face (where no edge or vertex is) projects every edge of every loop (`project_face`; the sketch's own face is skipped — its edges are there already); overlaps with existing geometry are not trimmed ⬜; waiting for a visual check |
| Work plane / axis / point, Origin | projection (the axis — a line, the point — a point); with constraints/dimensions to them Inventor projects them by itself | 🟡 work point → fixed point, work axis → a reference line along it (half a model diagonal each way, ≥ 50 mm), work plane → its line of intersection with the sketch plane (a parallel plane is refused); associative (`LinkSource::Work`, format revision 16), listed in References, a deleted source makes the link sick; picked in the view while Project Geometry is on (points and axes before edges); test with 3 positions; origin geometry ⬜ and the automatic projection on constraining ⬜; waiting for a visual check |
| Project Cut Edges | the section of the body with the sketch plane; a **non-associative** snapshot | 🟡 Project Geometry ▾ › **Project Cut Edges** (alias PCE): the section of every face by the sketch plane (`part/cut_edges.rs`: which faces are crossed and where from the display triangles, the geometry from each face's exact surface — plane → line, cylinder square to the sketch / sphere → circle or arc, else a spline; joints solved exactly) as fixed lines, arcs, circles and splines, loops sharing their points; a plane missing the part is refused without a change; a 36-hole plate in 1.2 ms (the kernel's split + conversion took 2.5 s, `tests/perf.rs`); waiting for a visual check |
| Project Flat Pattern | sheet metal flat pattern | 🟡 Project Geometry ▾ › **Project Flat Pattern** (alias PFP): the unfolded outline and cut-outs (LINE / ARC / CIRCLE as in the DXF) laid in the base panel's plane on the face the sketch is on, bend centre lines as construction; fixed geometry (Inventor's is associative ⬜); the sketch must be parallel to the base panel — a flange's face (the flat laid round another panel) ⬜; with several sheets the first parallel one; waiting for a visual check |
| Project to 3D Sketch / Include Geometry | curves in a 3D sketch | ⛔ (1.10, out of scope) |

## 5. Source changes and errors

| Case | Inventor | Status |
|---|---|---|
| The source changed (point, radius, plane) | the projection follows it | ✅ on every regeneration; in the GUI — on **Finish Sketch** of the source sketch (Inventor also updates on exit) |
| The source disappeared (deleted curve or sketch, missing edge) | the projection stays as fixed geometry, the constraints are kept, the sketch is "sick" | ✅ `PartSketch::health` = "projected source(s) missing, frozen: …"; the row in References is `!`; nothing is silently "fixed" |
| The source sketch is moved after the target | — | ✅ sick link "… comes after this sketch in the history" |
| A circle/arc in a non-parallel plane | ellipse | refused "not parallel … project its centre"; if the source is tilted later — sick link |
| The projection of the source arc changed direction | — | sick link "turned over; project it again" |
| The number of points of the source spline changed | it updates | 🟡 sick link "project it again" |

## 6. Implementation

- Ribbon: Sketch › Create › **Project Geometry** is a large split button (Project Geometry, Project Cut Edges, Project Flat Pattern), each with its own icon.
- `part/cut_edges.rs`: Project Cut Edges and Project Flat Pattern (`Piece`s drawn by one `Pen` that shares end points).
- `part/link.rs`: `GeometryLink { source: LinkSource, points, curve }`; `LinkSource::Sketch { sketch: <id>, geo: SketchGeo::Point|Curve }` (sketch id + point/curve id, never an index) and `LinkSource::Edge { edge: EdgeRef }`. `resolve` → `Shape3` (in 3D) → `project` (orthogonally into the sketch plane) → `create`/`place`. `apply` is called in `update_sketch` in history order.
- `PartSketch::links` (new field, `serde(default)`), `Sketch::fixed_radius` (a held radius, not a degree of freedom in the solver).
- `PartDocument::project_sketch_geometry`, `project_curved_edge`, `relink`, `link_dependents`, `can_project_from`.
- GUI: `gui/project.rs` (clicks, highlighting, Replace, context menu), References in `gui/panels.rs`.
- Tests: `part/link_tests.rs` (XY → YZ, work plane, line/arc/circle, following, missing source, Break Link, Delete, save/load, order, splines, Replace, circular edge, the Sweep scenario); `tests/perf.rs`.
- Format: new optional fields, no new revision (see `docs/FILE_FORMAT.md`).
