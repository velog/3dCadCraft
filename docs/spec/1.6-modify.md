# 1.6 Modifying a sketch (Sketch → Modify)

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ waiting for another feature.

## 1. General rules

- The commands that work on a **selection** (Move, Copy, Rotate, Scale, Stretch, Mirror, patterns) accept a pre-selection. If there is no selection, geometry is selected first and confirmed with Enter or right click → Done. ✅
- The commands that work by **pointing** (Trim, Extend, Split, Offset) act on the curve under the cursor and show a preview of what is affected. ✅
- Every command keeps the constraints: new ends get Coincident, and trimmed pieces stay on the same carrier curve. ✅
- Failure → the sketch does not change, and the reason is in the status bar. ✅

## 2. The commands

| Command | Behaviour (after Inventor) | Status |
|---|---|---|
| **Trim** (X) | removes the clicked piece up to the **nearest** intersecting curves. The ends get Coincident to the boundary; with no intersections it removes the whole curve. For a circle the arc without the clicked piece remains. **Shift** switches to Extend. Dragging across several curves trims them at once | ✅; ⬜ dragging across several |
| **Extend** | extends the end nearest the click up to the next curve (lines and arcs), with Coincident. Shift → Trim | ✅ |
| **Split** | splits the curve at the nearest intersection; the pieces stay Collinear (lines) or Equal with a shared centre (arcs) | ✅ |
| **Offset** (O) | a curve or, with **Loop Select**, the whole chain; pointing sets the side and the distance. Lines are Parallel, arcs concentric, smooth joins Tangent. **Constrain Offset**: all pieces at one distance, which is the only degree of freedom | ✅ lines, arcs, circles; ⬜ splines |
| **Move** | selection → base point → end point; the rest follows the constraints. Copy option; exact entry (Precise Input) | ✅ (with a Copy option in Properties); ⬜ Precise Input |
| **Copy** | the same, but copies, together with the internal constraints | ✅ |
| **Rotate** | selection → centre → reference point → angle | ✅; ⬜ entering the angle |
| **Scale** | selection → base point; the factor is in Properties. Radii and dimensions entirely within the selection are scaled | ✅ |
| **Stretch** | selection → base → end point. The selected points move, connected geometry stretches. Dimensions between moved and unmoved points take the new values, and those entirely within the selection are kept | ✅ |
| Dragging | a point or a whole curve; with Relax mode the dimensions give way ([1.3](1.3-constraints.md)) | ✅ |

## 3. Edge cases

- Trim of a curve without intersections → deletes the whole curve (so does Inventor). ✅
- Offset with a radius ≤ 0 (inside a small arc) → refused. ✅
- Offset of a spline → message "not yet", no change. ✅
- Stretch with a slightly slanted click against H/V constraints → the nearest valid position. ✅
- Scale with a factor ≤ 0 → refused. ✅

## 4. Implementation

`sketch/modify.rs` (Trim, Extend, Split, Offset, Move, Copy, Rotate, Scale, Stretch, Mirror, `chain`, `on_curve`), `gui/sketch_tools.rs` (clicks and previews).
