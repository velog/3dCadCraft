# 1.6 Модифициране на скица (Sketch → Modify)

Статус: ✅ готово · 🟡 частично · ⬜ предстои · ⛔ чака друга функция.

## 1. Общи правила

- Командите, които работят с **избор** (Move, Copy, Rotate, Scale, Stretch, Mirror, масиви), приемат предварителен избор. Ако няма избор, първо се избира геометрия и се потвърждава с Enter или десен клик → Done. ✅
- Командите, които работят с **посочване** (Trim, Extend, Split, Offset), действат върху кривата под курсора и показват преглед на засегнатото. ✅
- Всяка команда пази ограниченията: новите краища получават Coincident, а отрязаните части остават на същия носител. ✅
- Неуспех → скицата не се променя, а причината е в лентата на състоянието. ✅

## 2. Командите

| Команда | Поведение (по Inventor) | Статус |
|---|---|---|
| **Trim** (X) | маха кликнатата част до **най-близките** пресичащи криви. Краищата получават Coincident към границата; без пресичания маха цялата крива. При окръжност остава дъгата без кликнатата част. **Shift** превключва към Extend. Влачене през няколко криви ги реже наведнъж | ✅; ⬜ влачене през няколко |
| **Extend** | удължава края, най-близък до клика, до следващата крива (линии и дъги), с Coincident. Shift → Trim | ✅ |
| **Split** | разделя кривата в най-близката пресечна точка; частите остават Collinear (линии) или Equal с общ център (дъги) | ✅ |
| **Offset** (O) | крива или с **Loop Select** цялата верига; посочването задава страната и отстоянието. Линиите са Parallel, дъгите концентрични, гладките съединения Tangent. **Constrain Offset**: всички части на едно отстояние, което е единствената свободна степен | ✅ линии, дъги, окръжности; ⬜ сплайни |
| **Move** | избор → базова точка → крайна точка; останалото следва ограниченията. Опция Copy; точно въвеждане (Precise Input) | ✅ (с опция Copy в Properties); ⬜ Precise Input |
| **Copy** | същото, но копира, заедно с вътрешните ограничения | ✅ |
| **Rotate** | избор → център → отправна точка → ъгъл | ✅; ⬜ въвеждане на ъгъла |
| **Scale** | избор → базова точка; коефициентът е в Properties. Радиусите и размерите изцяло в избора се мащабират | ✅ |
| **Stretch** | избор → базова → крайна точка. Точките на избора се местят, свързаната геометрия се разтяга. Размерите между преместени и непреместени точки приемат новите стойности, а тези изцяло в избора се запазват | ✅ |
| Влачене | точка или цяла крива; с Relax mode размерите отстъпват ([1.3](1.3-constraints.md)) | ✅ |

## 3. Крайни случаи

- Trim на крива без пресичания → изтрива цялата крива (Inventor също). ✅
- Offset с радиус ≤ 0 (вътре в малка дъга) → отказ. ✅
- Offset на сплайн → съобщение „not yet“, без промяна. ✅
- Stretch с леко наклонен клик срещу H/V ограничения → най-близкото валидно положение. ✅
- Scale с коефициент ≤ 0 → отказ. ✅

## 4. Реализация

`sketch/modify.rs` (Trim, Extend, Split, Offset, Move, Copy, Rotate, Scale, Stretch, Mirror, `chain`, `on_curve`), `gui/sketch_tools.rs` (кликове и прегледи).
