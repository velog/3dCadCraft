# 4.13 Drawing resources: title blocks, borders, sketched symbols (drawing stage D-S5)

> The user's own title block, border and symbols, drawn as sketches and kept in the drawing's
> **Drawing Resources**: placed on sheets, filled in from Properties and from prompted entries, edited
> once and changed everywhere.

## 1. Purpose

A company's drawings carry its own title block (logo, fields in its own places), often its own border, and
recurring symbols (a weld note, a "do not scale" stamp, an inspection mark). Inventor keeps their
*definitions* in the drawing (or its template) under **Drawing Resources** › Borders / Title Blocks / Sketch
Symbols. A definition is a sketch: lines, arcs, texts and **fields** — a Property of the drawing, of the
sheet or of the model of the first view, or a **prompted entry** whose value the user types when the
definition is placed. A sheet then holds *instances*: one border, one title block, any number of symbols.
Editing a definition changes every instance. This spec builds on drawing sketches (spec 4.12) and the
fields of Format Text (spec 4.9 §3.4).

## 2. Inputs

Definitions:

1. Manage › Define › **Define Title Block** (alias DTB), **Define Border** (DBR; Inventor's Define New
   Border and Define New Zone Border are its Kind choice), **Define Sketched Symbol** (DSS); or right-click
   Drawing Resources › Title Blocks / Borders / Sketched Symbols › Define New ….
2. Zone border only: the Default Drawing Border Parameters (the panel's zone rows) first.
3. The sketch editor opens on an empty sheet-sized area (the sheet's own content dimmed): the Sketch tab's
   tools, plus Text with fields, Property Field, Prompted Entry, Connection Point and Insertion Point.
4. Finish (right-click › Save Title Block / Save Border / Save Sketch Symbol, or Enter): the name dialog;
   the definition appears in Drawing Resources.

Instances:

1. Double-click a definition in Drawing Resources (title block, border: replaces the sheet's after a
   question; symbol: placement starts), or right-click › Insert.
2. Annotate › Symbols › **Sketched Symbols** (alias SY): the Sketch Symbols dialog, then clicks on the
   sheet (with a leader: the leader's points first, then the symbol).
3. A definition with prompted entries opens **Edit Property Fields** before it is placed.

## 4. Browser and editing behaviour

- Drawing Resources lists the definitions; each sheet lists its Border, Title Block and Sketched Symbols
  (instances) after its views and sketches.
- An instance's menu: Edit Definition, Edit Field Text (prompted entries), Delete; a symbol's also Edit
  Symbol. ✅ 2026-11-07 for the built-in border and title block: Delete takes them off the sheet (Edit
  Sheet's Border / Title Block bring them back), one Undo step; the border's Edit Instance (§3.3).
- Saving a definition, inserting, replacing, deleting and editing field values are one Undo step each.
- Fields are evaluated whenever the sheet is drawn (screen and PDF); a field whose source is missing shows
  `#?`.

## 5. Edge cases and errors

- A definition name must be unique in its folder ("Define Title Block: a title block named X exists").
- Deleting a definition used by a sheet is refused, naming the sheet.
- A title block wider than the frame is still drawn (clipped by nothing), anchored at its corner.
- Old drawings: sheets keep `border` / `title_block` as today and show the built-in definitions; old builds
  ignore the new fields and show the built-in border and title block (no format revision unless a new enum
  variant is needed).
- A sheet's prompted values for an entry that left the definition are dropped at Save of the definition;
  values of new entries start empty.

## 6. Implementation (plan)

- Done: `drawing::fields` (`Field`, `SheetField`, `Piece`, `parse` / `tokens`, `expand`, `property`);
  `view_sketch::DrawingText` in `DrawingSketch::texts`, drawn by `render::sketch_prims_with` /
  `text_prim`; the GUI's `FieldProps` (`gui/drawing_resources.rs`) and the Text dialog
  (`gui/drawing_text.rs`).
- Done: `drawing::resources::ZoneParams` (zones, labels `ZoneLabel`, `LabelFrom`, `Delimit`, centre
  marks, margins) in `Sheet::border_params`; `sheet::border_params` / `margins` / `frame` read it,
  `sheet::border_prims` draws it; GUI `gui/drawing_resources.rs` (the sheet's rows, `BorderDialog`).
- `drawing::resources` (GUI-free): `Resources { title_blocks, borders, symbols }` in
  `DrawingDocument::resources` (serde default); `Definition { name, sketch: ViewSketch, texts: Vec<DefText>,
  points: Vec<MarkedPoint> }`; `DefText { at, height, anchor, angle, pieces: Vec<Piece> }`, `Piece = Text |
  Field(FieldRef) | Prompt(title)`; `BorderDef { zones: Option<ZoneParams>, def: Definition }`.
- Sheets: `title: Option<Placed>`, `border_def: Option<PlacedBorder>`, `symbols: Vec<PlacedSymbol>` (name,
  position, scale, angle, static, leader, prompted values); `None` = the built-in one, so old files read as
  before.
- `sheet::format_prims` draws the built-in ones; `resources::prims(def, placement, value)` draws a definition
  through the same `Prim`s; fields through one resolver shared with Format Text (`FieldRef`).
- GUI: `gui/drawing_resources.rs` (browser folders, menus, the name dialog, Edit Property Fields, the Sketch
  Symbols dialog replacing the planned panel); the editor is spec 4.12's `DrwSketch` with `SketchFor::Resource`.
