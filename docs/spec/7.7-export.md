# 7.7 Износ (Export): STL, STEP, GLB

Статус: ✅ готово · 🟡 частично · ⬜ предстои · ⛔ чака друга функция.

## 1. Предназначение

Детайлът се записва във формат за други програми: **STL** за 3D печат, **STEP** за други CAD системи (точна B-rep геометрия) и **GLB** (glTF 2.0) за визуализация и уеб. Родният `.3dcadcraft` остава параметричният модел; износът е само резултатът.

## 2. Входни данни

- активният детайл (всички тела);
- име на файла: полето за път в менюто File; разширението се сменя според формата.

## 3. Настройки

| Опция | Inventor | Статус |
|---|---|---|
| **STL** (File → Export → STL, в Inventor: Export → CAD Format / Print → 3D Print Preview): двоичен, мм | Inventor пише STL с избор на мерни единици, двоичен/текстов и резолюция | 🟡 двоичен, мм, затворена мрежа (тест: всеки ръб е общ за два триъгълника; обемът съвпада); ⬜ избор на резолюция, ASCII, единици |
| **STEP** (AP214/AP242): точни повърхнини | Inventor: Export → CAD Format → STEP, протокол AP203/214/242 | 🟡 AP242 от точното ядро (SolidCraft `step_export_bodies`), тест: прочетен обратно със същия обем; ⬜ избор на протокол, цветове по стени, асембли; детайл, построен от фасетираното ядро, не може да се изнесе в STEP (съобщение) |
| **GLB** (glTF 2.0 двоичен) | Inventor 2027: Export → glTF/GLB (визуализация) | 🟡 една мрежа, нормали, материал, метри, ос Y нагоре; ⬜ цвят на тялото, няколко тела като отделни възли |
| Команден ред | Inventor: Task Scheduler | ✅ `cargo run --example export -- проект.3dcadcraft изход.stl изход.step изход.glb` |
| Атомичен запис | — | ✅ временен файл и преименуване |

## 4. Грешки

- Празно поле за път → `Export: type a file name in the path field first`.
- Непознато разширение → `the file name must end in .stl, .step / .stp or .glb`.
- STEP без точно ядро → `STEP needs the exact kernel (this part was built with the faceted one)`.

## 5. Реализация

- `part/export.rs`: `ExportFormat`, `ExportMesh::of` (триъгълниците на телата), `stl_bytes`, `glb_bytes`, `step_text`, `export`.
- `kernel::exact::step_text` / `step_volumes` (обратно четене за тестове); `PartDocument::exact_bodies` пази точните тела от последната регенерация.
- GUI: File → Export → STL / STEP / GLB (`CadCraftApp::export_part`).
- Бързина: `tests/perf.rs` (износ на закръглената кутия, < 5 ms).

## 6. Източници

- glTF 2.0 спецификация (Khronos), GLB контейнер.
- STL (двоичен формат: 80 байта заглавие, брой, 50 байта на триъгълник).
- ISO 10303-21 (STEP) — пише се чрез SolidCraft (MIT/Apache).
