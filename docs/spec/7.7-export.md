# 7.7 Export: STL, STEP, GLB

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ waiting for another feature.

## 1. Purpose

The part is written in a format for other programs: **STL** for 3D printing, **STEP** for other CAD systems (exact B-rep geometry) and **GLB** (glTF 2.0) for visualisation and the web. The native `.3dcadcraft` stays the parametric model; an export is only the result.

## 2. Inputs

- the active part (all bodies);
- file name: the path field in the File menu; the extension changes with the format.

## 3. Options

| Option | Inventor | Status |
|---|---|---|
| **STL** (File → Export → STL; in Inventor: Export → CAD Format / Print → 3D Print Preview): binary, mm | Inventor writes STL with a choice of units, binary/text and resolution | 🟡 binary, mm, closed mesh (test: every edge is shared by two triangles; the volume matches); ⬜ choice of resolution, ASCII, units |
| **STEP** (AP214/AP242): exact surfaces | Inventor: Export → CAD Format → STEP, protocol AP203/214/242 | 🟡 AP242 from the exact kernel (SolidCraft `step_export_bodies`), test: read back with the same volume; ⬜ choice of protocol, per-face colours, assemblies; a part built by the faceted kernel cannot be exported to STEP (message) |
| **GLB** (binary glTF 2.0) | Inventor 2027: Export → glTF/GLB (visualisation) | 🟡 one mesh, normals, material, metres, Y axis up; ⬜ body colour, several bodies as separate nodes |
| Command line | Inventor: Task Scheduler | ✅ `cargo run --example export -- project.3dcadcraft out.stl out.step out.glb` |
| Atomic write | — | ✅ temporary file and rename |

## 3a. Export Face As (DXF / SVG)

Inventor offers **Export Face As** on the right-click menu of a planar face (parts, sheet metal folded or flat, assemblies): the face's loops go to a 2D file for cutting machines; the outer profile becomes one polyline and the drawing is moved so all coordinates are positive. We do the same for one face or several (Shift / Ctrl + click), in DXF or SVG.

| Option | Inventor | Status |
|---|---|---|
| Right-click menu of a planar face: **Export Face As...** | one planar face | 🟡 one or more planar faces (rule 17); also File → Export Face As (`FXF`) |
| Several faces | — (one face) | 🟡 must be parallel; projected into the first face's plane; an edge two selected faces share is left out, so touching faces give one outline; otherwise refused (`<face> is not parallel to <face>`) |
| View direction | the face seen from outside | 🟡 the first face's outward normal towards the viewer; x = world X in that plane (world Y when the face is square to X) |
| Positive coordinates | moved so every coordinate is positive | 🟡 the lower left corner of the outline's box at 0, 0 (arcs' extremes counted) |
| **DXF** | DXF / DWG, layers and versions set in a configuration file | 🟡 DXF R12 ASCII, mm (`$INSUNITS` 4); each loop a closed POLYLINE, arcs as bulges (exact), whole circles as CIRCLE; outline on layer `OUTER`, holes on `INNER`; ⬜ DWG, versions, layer names of the user's choice, splines as SPLINE |
| **SVG** | — | 🟡 SVG 1.1, 1 unit = 1 mm (width / height in mm), y up as in the model; one `<path>` per loop (lines `L`, arcs `A`), whole circles `<circle>`, groups `OUTER` / `INNER`, stroke only |
| Curves other than lines and circles | exported as they are | 🟡 points within 0.01 mm (the display chord tolerance) |
| Lines split by Booleans, circles in halves | — | ✅ joined back (one line, one arc, one circle) |
| Format choice | Save dialog's file type | 🟡 by the extension typed (`.dxf` / `.svg`, DXF when none) |

Errors (`Export Face As: …`): nothing selected (`select one or more planar faces first`), a curved or free-form face (`<face> is not a planar face`), faces not parallel, a mesh body's face (`has no edges`), a loop that does not close.

Implementation: `part/face_export.rs` (`outline` → `FaceOutline` of `Loop2`s of `Seg`s, `dxf`, `svg`; holes found by nesting, not by loop sense — open surfaces' senses are not reliable); GUI `gui/sel_menu.rs` (`Entry::ExportFace`, `export_face_start`, `export_face_to`, atomic write), dialog purpose `ExportFace` in `gui/files.rs`. Tests: `tests/face_export.rs` (plate with a hole and a slot: areas, circle, bulges, SVG arcs, bottom face, parallel / refused cases).

## 4. Errors

- Empty path field → `Export: type a file name in the path field first`.
- Unknown extension → `the file name must end in .stl, .step / .stp or .glb`.
- STEP without the exact kernel → `STEP needs the exact kernel (this part was built with the faceted one)`.

## 5. Implementation

- `part/export.rs`: `ExportFormat`, `ExportMesh::of` (the bodies' triangles), `stl_bytes`, `glb_bytes`, `step_text`, `export`.
- `kernel::exact::step_text` / `step_volumes` (read back for tests); `PartDocument::exact_bodies` keeps the exact bodies of the last regeneration.
- GUI: File → Export → STL / STEP / GLB (`CadCraftApp::export_part`).
- Speed: `tests/perf.rs` (export of the filleted box, < 5 ms).
