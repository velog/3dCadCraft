# 7.7 Export: STL, STEP, GLB

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ waiting for another feature.

## 1. Purpose

The part is written in a format for other programs: **STL** for 3D printing, **STEP** for other CAD systems (exact B-rep geometry) and **GLB** (glTF 2.0) for visualisation and the web. The native `.3dcadcraft` stays the parametric model; an export is only the result.

## 2. Inputs

- the active part (all bodies);
- file name: the path field in the File menu; the extension changes with the format.

## 3. Options

| Option | Inventor | Status |
|---|---|---|
| **STL** (File → Export → STL; in Inventor: Export → CAD Format / Print → 3D Print Preview): binary, mm | Inventor writes STL with a choice of units, binary/text and resolution | 🟡 binary, mm, closed mesh (test: every edge is shared by two triangles; the volume matches); ⬜ choice of resolution, ASCII, units |
| **STEP** (AP214/AP242): exact surfaces | Inventor: Export → CAD Format → STEP, protocol AP203/214/242 | 🟡 AP242 from the exact kernel (SolidCraft `step_export_bodies`), test: read back with the same volume; ⬜ choice of protocol, per-face colours, assemblies; a part built by the faceted kernel cannot be exported to STEP (message) |
| **GLB** (binary glTF 2.0) | Inventor 2027: Export → glTF/GLB (visualisation) | 🟡 one mesh, normals, material, metres, Y axis up; ⬜ body colour, several bodies as separate nodes |
| Command line | Inventor: Task Scheduler | ✅ `cargo run --example export -- project.3dcadcraft out.stl out.step out.glb` |
| Atomic write | — | ✅ temporary file and rename |

## 4. Errors

- Empty path field → `Export: type a file name in the path field first`.
- Unknown extension → `the file name must end in .stl, .step / .stp or .glb`.
- STEP without the exact kernel → `STEP needs the exact kernel (this part was built with the faceted one)`.

## 5. Implementation

- `part/export.rs`: `ExportFormat`, `ExportMesh::of` (the bodies' triangles), `stl_bytes`, `glb_bytes`, `step_text`, `export`.
- `kernel::exact::step_text` / `step_volumes` (read back for tests); `PartDocument::exact_bodies` keeps the exact bodies of the last regeneration.
- GUI: File → Export → STL / STEP / GLB (`CadCraftApp::export_part`).
- Speed: `tests/perf.rs` (export of the filleted box, < 5 ms).

## 6. Sources

- glTF 2.0 specification (Khronos), GLB container.
- STL (binary format: 80-byte header, count, 50 bytes per triangle).
- ISO 10303-21 (STEP) — written through SolidCraft (MIT/Apache).
