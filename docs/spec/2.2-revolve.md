# 2.2 Revolve

Статус: ✅ готово · 🟡 частично · ⬜ предстои · ⛔ чака друга функция.

Сравнено ред по ред с Inventor Help 2027 (*To Create Revolved Features*) на 2026-10-19. Редовете „(2027)“ чакат визуална проверка (машина без снимки) и са 🟡.

## 1. Предназначение

Завърта профил от скица около ос и така създава или променя тяло: валове, втулки, шайби, фланци, канали.

## 2. Входни данни

| Вход | Inventor | Статус |
|---|---|---|

| **Axis: десен клик → Continue** (2027) | след профилите десен клик в изгледа → Continue минава към избора на оста | 🟡 контекстно меню (Continue / OK / Cancel); чака визуална проверка |
| Профил, пресичащ оста | отказ | ✅ |

## 3. Настройки

| Опция | Поведение | Статус |
|---|---|---|
| **Full** | 360° | ✅ |
| **Angle** | ъгъл в една посока; Flip обръща | ✅ |
| **Symmetric** | по половин ъгъл в двете посоки | ✅ (2026-10-19: поправка — точното ядро завърташе началото в грешната посока и покриваше 45°…135° вместо ±45°; регресионен тест) |
| **Angle-Angle** (Asymmetric) | два ъгъла | ✅ (същата поправка) |
| **To** (2027) | до стена или равнина (удължава се, ако не пресича профила) | 🟡 `RevolveExtent::To` + `to`: планарна стена или начална/работна равнина **през оста**, или точка/връх (полуравнината през нея); посока Default/Flipped; ⬜ равнини, които не съдържат оста, криволинейни стени; тест `revolve_to_with_minimum_solution` |
| **Minimum Solution** (2027) | при двусмислие спира на най-близкото решение | 🟡 равнина през оста има две полуравнини: включено — по-близката, изключено — по-далечната; стена — само полуравнината, в която лежи |
| **To Next** | до следващото тяло, с Terminator | ⬜ |
| **Output** Solid / Surface | Surface: само завъртяните криви, без капаци | ✅ (фасетирано); 🟡 точно (`exact::revolve_sheet`, 2026-10-20): линиите на профила по оста не дават стена (профил до оста = отворена верига от оста до оста), повърхнинно тяло извън булевите операции; чака визуална проверка |
| **Operation** New Solid / Join / Cut / Intersect | виж [2.13](2.13-booleans.md); не се показва за базовата операция | ✅ / 🟡 (2027) скриване при базова |
| **Predict Boolean Operation** (2027) | предлага операцията | 🟡 `RevolveFeature::predict_operation`: без тяло → New Solid; профилът е в материала → Cut, иначе → Join; тест с 4 профила |
| Ъгълът е параметър (`d<N>`), приема израз | | ✅ |
| **Presets** | | 🟡 вж. [0.11-presets.md](0.11-presets.md) |

## 4. Повърхнини

| Сегмент от профила | Повърхнина |
|---|---|
| линия, успоредна на оста | цилиндър |
| линия, перпендикулярна на оста | равнина (пръстен) |
| наклонена линия | конус |
| дъга | тор (сфера, ако центърът е на оста) |
| сплайн | повърхнина на въртене |
| сегмент върху оста | няма стена |

Не-пълен ъгъл добавя две планарни стени: **Start** и **End**.

## 5. Скица и размери за въртене

| Поведение | Статус |
|---|---|
| Format → **Centerline**: щрих-точка линия, ос за Revolve | ✅ |
| **Диаметрален размер** през центровата линия | ✅ |

## 6. Дърво, редакция, имена

Като при Extrude. Имена: `<id>:Side:<крива>:<k>`, `<id>:Start`, `<id>:End`. ✅

Посока на въртене (за To): точното ядро завърта положителен ъгъл **по часовниковата стрелка**, гледано от върха на оста; `sweep_in` мери ъглите на целите в същия смисъл.

## 7. Реализация

`part/revolve.rs`: `RevolveFeature` (+ `to`, `minimum`), `sweep_in` (To спрямо модела), `predict_operation`, `build_in`. `part/exact.rs::revolve` получава тялото и работната геометрия. `kernel/exact.rs::revolve` — поправената посока на началния ъгъл.

## 8. Примитиви Sphere и Torus (2027)

| Стъпка / опция | Inventor | Статус |
|---|---|---|
| Равнина на скицата | начална/работна равнина или планарна стена | 🟡 |
| **Sphere** | клик за центъра, после за диаметъра | 🟡 половин окръжност, затворена от центрова линия (оста), с размер Ø |
| **Torus** | клик за центъра, за центъра на сечението, после за диаметъра на сечението | 🟡 окръжност (Ø) на разстояние R от центрова линия през центъра; сечение, което стига оста → отказ |
| Само пълно завъртане, само Solid | | 🟡 Extents и Output са заключени в панела |
| Join / Cut / Intersect / New Solid, Solids | | 🟡 тест `primitives_with_operations` (сфера Cut/Join/Intersect, тор New Solid) |

Обеми (тестове `sphere_and_torus_volumes`, по 5 размера): сфера 4/3·π·r³, тор 2·π²·R·r².
