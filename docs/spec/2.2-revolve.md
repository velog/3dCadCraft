# 2.2 Revolve

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ waiting for another feature.

Compared row by row with Inventor Help 2027 (*To Create Revolved Features*) on 2026-10-19. The "(2027)" rows are waiting for a visual check (machine without screenshots) and are 🟡.

## 1. Purpose

Revolves a sketch profile about an axis, creating or modifying a body: shafts, bushings, washers, flanges, grooves.

## 4. Surfaces

| Profile segment | Surface |
|---|---|
| line parallel to the axis | cylinder |
| line perpendicular to the axis | plane (ring) |
| inclined line | cone |
| arc | torus (sphere if the centre is on the axis) |
| spline | surface of revolution |
| segment on the axis | no face |

A non-full angle adds two planar faces: **Start** and **End**.

## 6. Browser, editing, names

As for Extrude. Names: `<id>:Side:<curve>:<k>`, `<id>:Start`, `<id>:End`. ✅

Direction of rotation (for To): the exact kernel rotates a positive angle **clockwise**, seen from the tip of the axis; `sweep_in` measures the targets' angles in the same sense.

## 7. Implementation

`part/revolve.rs`: `RevolveFeature` (+ `to`, `minimum`), `sweep_in` (To relative to the model), `predict_operation`, `build_in`. `part/exact.rs::revolve` receives the body and the work geometry. `kernel/exact.rs::revolve` — the fixed direction of the start angle.
