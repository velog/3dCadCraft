# 0.13 Подредба на интерфейса: панели, прозорци, User Interface

## 1. Предназначение

Потребителят сам решава колко място заемат панелите около графичния прозорец: влачи
ръба на дървото и на Properties, свива лентата с команди до табовете, скрива панели,
които не му трябват, и временно вижда само модела (Clean Screen, Full Screen).
Плаващите прозорци (Parameters, Physical Properties, браузърите за материали…) се
отварят там, където са били затворени, и със същия размер. Всичко това, заедно с
Application Options, се помни между стартиранията.

В Inventor тези неща са на таба **View → панел Windows**: падащият списък
**User Interface** с отметки за всеки елемент, **Clean Screen** (Ctrl+0),
**Full Screen**, **Reset UI Layout** (и в Tools → Options), плюс Switch / Arrange /
Tile / Cascade за документите. Лентата се свива с бутона Minimize (или двоен клик
върху активния таб).

## 2. Входни данни

- влачене на ръбовете на панелите и на плаващите прозорци;
- отметките в менюто User Interface (лентата: View → Windows; и бутонът **View** в
  Quick Access реда, който остава видим винаги);
- клавиши Ctrl+0 и F11;
- `settings.json` в папката с настройки (`%APPDATA%\3dcadcraft`, под Linux
  `~/.config/3dcadcraft`), ключове `ui` и `options`.

## 4. Поведение в дървото / редакция

Няма данни в документа: всичко е настройка на потребителя и не влиза в Undo.

## 5. Гранични случаи и грешки

- Липсващ `settings.json` → стойности по подразбиране (днешната подредба), без съобщение.
- Повреден файл → `Settings: <файл> is damaged (…); defaults are used` в лентата на
  състоянието; при следващия запис старият файл се пази като `settings.json.bak`.
  Програмата не пада.
- Непознати ключове се пропускат; липсващи — по подразбиране (поле по поле, така че
  стар файл без нови полета не губи останалите).
- Други ключове в `settings.json` (`recent_files`, `hints_bulgarian`) се запазват при
  записа.
- Записът е атомарен (временен файл и преименуване) и отложен: 0,5 s след последната
  промяна, така че влаченето на ръб пише веднъж; при затваряне — веднага.
- Запомнен прозорец извън текущия екран (по-малък монитор) се вкарва вътре и се смалява
  до размера на екрана.

## 6. Реализация

- `src/gui/layout.rs`: `UiSettings` (serde, `#[serde(default)]`), `AppOptions`,
  `Element` (Browser, Properties, Ribbon, StatusBar, ViewCube, Triad), `LayoutUi`
  (живо състояние: Clean Screen, временно показана лента, отложен запис `Saver`),
  `clamp_rect`, `ui_menu` (менюто User Interface), `place` (плаващ прозорец),
  `escape_target`; `load_from` / `write_to` за файла.
- `ribbon::Action::Ui(UiCmd)`; панел **Windows** в таба View.
- `CadCraftApp::ui` чете видимостта и ширините от `layout`; `options_snapshot` /
  `apply_options` пренасят Application Options.
