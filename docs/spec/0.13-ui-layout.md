# 0.13 Interface layout: panels, windows, User Interface

## 1. Purpose

The user decides how much room the panels around the graphics window take: drag the
edge of the browser and of Properties, collapse the command ribbon to its tabs, hide
panels they do not need, and temporarily see only the model (Clean Screen, Full Screen).
Floating windows (Parameters, Physical Properties, the material browsers…) open where
they were closed, at the same size. All of this, together with Application Options, is
remembered between runs.

In Inventor these are on the **View → Windows panel** tab: the **User Interface**
drop-down with a check box for each element, **Clean Screen** (Ctrl+0),
**Full Screen**, **Reset UI Layout** (also in Tools → Options), plus Switch / Arrange /
Tile / Cascade for documents. The ribbon is collapsed with the Minimize button (or a
double click on the active tab).

## 2. Inputs

- dragging the edges of panels and of floating windows;
- the check boxes in the User Interface menu (ribbon: View → Windows; and the **View**
  button in the Quick Access row, which always stays visible);
- the keys Ctrl+0 and F11;
- `settings.json` in the settings folder (`%APPDATA%\3dcadcraft`, on Linux
  `~/.config/3dcadcraft`), keys `ui` and `options`.

## 4. Browser / editing behaviour

No data in the document: everything is a user setting and does not go into Undo.

## 5. Edge cases and errors

- Missing `settings.json` → default values (the current layout), no message.
- Damaged file → `Settings: <file> is damaged (…); defaults are used` in the status bar;
  on the next save the old file is kept as `settings.json.bak`. The program does not
  crash.
- Unknown keys are skipped; missing ones get defaults (field by field, so an old file
  without the new fields does not lose the others).
- Other keys in `settings.json` (`recent_files`, `hints_bulgarian`) are kept when
  saving.
- The save is atomic (temporary file and rename) and deferred: 0.5 s after the last
  change, so dragging an edge writes once; on close — immediately.
- A remembered window outside the current screen (a smaller monitor) is moved inside and
  shrunk to the size of the screen.

## 6. Implementation

- `src/gui/layout.rs`: `UiSettings` (serde, `#[serde(default)]`), `AppOptions`,
  `Element` (Browser, Properties, Ribbon, StatusBar, ViewCube, Triad), `LayoutUi`
  (live state: Clean Screen, temporarily shown ribbon, deferred save `Saver`),
  `clamp_rect`, `ui_menu` (the User Interface menu), `place` (floating window),
  `escape_target`; `load_from` / `write_to` for the file.
- `ribbon::Action::Ui(UiCmd)`; the **Windows** panel in the View tab.
- `CadCraftApp::ui` reads visibility and widths from `layout`; `options_snapshot` /
  `apply_options` carry Application Options.
