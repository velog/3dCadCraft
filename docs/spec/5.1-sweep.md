# 5.1 Sweep

## 1. Purpose

Sweep moves a closed profile along a curve (path) and makes a body from its trace: pipes, spring
arms, handles, grooves, frame profiles. The path can be open or closed, with lines and
arcs, with smooth or sharp turns. Instead of a profile a whole body can be moved (Solid Sweep):
this models the path of a milling cutter. A second curve (Guide Rail) or a surface (Guide
Surface) can be added to the path; they control the size and the rotation of the profile along
the path.

## 2. Inputs

- **Profiles:** one or more closed regions of a sketch. If there is only one visible
  sketch with one region, it is selected automatically.
- **Path:** a chain of curves of a 2D sketch (in another plane), of a 3D sketch, or model
  edges. Inventor copies the edges into a new 3D sketch on OK.
- **Guide Rail** (for Path & Guide Rail): a second curve that pierces the profile plane.
- **Guide Surface** (for Path & Guide Surface): a surface the path lies on.
- **Toolbody** (for Solid Sweep): a body that moves along the path.
- **Solids:** which bodies the feature works on, if there are several.

Inventor's condition: the path must pierce the profile plane, and its start must be
close to the profile. The profile keeps its relation to the path; it does not need to lie
exactly on it. For us the path starts from its end that is closer to the profile.

## 4. Browser and editing behaviour

- In the browser it is `Sweep1`, with the consumed sketches of the profile and of the path (and the rail) under it.
- The sketches are consumed and hidden (`PartDocument::add_sweep`). If one is already used by
  another feature, it becomes shared.
- Editing the path sketch (another length, another radius) rebuilds the sweep.
  The regeneration cache key includes the geometry of **all** the feature's sketches
  (`Feature::sketch_ids`).
- Edit Feature rolls the model back to before the feature (rollback).

## 5. Edge cases and errors

- A path in the profile plane: "Sweep: the path lies in the profile plane".
- The path curves do not join end to end: "Sweep: the path curves are not connected end
  to end".
- A path with sharp corners and taper/twist/rail/Parallel: a clear refusal (the corner is mitred
  only for the plain sweep).
- A taper that closes the profile before the end: "the taper closes the profile …".
- A profile larger than the bend of the path: before the kernel, every point of the path is checked —
  the radius of curvature against how far the profile reaches towards the centre of the bend (the profile
  is carried with the kernel's frames). Refusal: "the profile is larger than the path's bend:
  <s> mm along the path it bends with radius <R> mm, but the profile reaches <d> mm towards
  the bend …" (Inventor also refuses self-intersecting sweeps). 🟡 only Orientation Path
  without a rail.
- Self-intersection or an invalid result: regeneration checks the body and never
  accepts it. The feature becomes sick, and the part stays as it was. The sweep never
  falls back to the faceted kernel.
- Shell after a sweep along a curve: the faces are B-spline surfaces, and the kernel offsets only
  analytic ones — "Shell: free-form faces (a sweep or loft along a curve) cannot be offset yet".
- A Cut that does not intersect the body: "Cut: the feature does not intersect the body".

## 6. How we implement it

- Data: `part::sweep::SweepFeature` (`Feature::Sweep`, format revision 12), path
  `PathRef` (also used by Loft), `SweepType`, `ProfileScaling`, `SweepOrientation`.
- Kernel: `kernel::exact::sweep` (exact, `sk::sweep` / `sk::sweep_path`) and
  `kernel::exact::loft_frames` (copies of the profile in "frames": origin + images of the sketch
  axes; arcs under a non-uniform scale become rational quadratic segments; a full
  circle is split into quarters — one edge with one vertex breaks the kernel's loft). The profile's
  holes are lofted separately and cut out.
- Face names: `Sweep1:Side:<curve>`, `Sweep1:Start`, `Sweep1:End` from the kernel's
  history; the second profile is `Sweep1#2:…`.
- GUI: `gui/sweep.rs` (selectors Profiles → Path → Guide Rail, auto-advance, preview,
  OK/Apply/Cancel, Properties, F1 → this file).
