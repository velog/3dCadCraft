# 2.9 Thread (резба)

## 1. Предназначение

Thread слага резба на цилиндрична стена: външна на вал или вътрешна в отвор. В Inventor
резбата е винаги *козметична*: пази се като данни (стандарт, размер, клас, дължина), а в
изгледа се показва като текстура. Геометрията не се променя. При нас има и **моделирана**
резба (като във FreeCAD): истинска винтова канавка, полезна за 3D печат. Има и **хлабина
за печат**: разширява вътрешна резба и стеснява външна с дадена стойност.

## 2. Входни данни

- **Face:** цилиндрична стена. Кликът близо до единия край определя началото на
  резбата.
- **Specification:** вид (таблица), размер, обозначение (стъпка), клас, Right/Left Hand.
- **Depth:** по цялата дължина или Offset + Length.
- **Modeled thread** и **Thread clearance** (наши).

### 3.1 Изображение на козметичната резба

В Inventor козметичната резба се рисува като *текстура* (картина на резба) върху самата
цилиндрична стена, а не като отделна геометрия: така моделът остава лек. Текстурата
покрива само дължината на резбата, следва стената при въртене и осветяване в оцветените и
реалистичните стилове, вътре в отвор и отвън на вал. Командата Textures On/Off в View →
Appearance не засяга резбите (те остават видими); скриват се с *Display thread in model* на
самата операция. При нас: процедурна текстура в шейдъра, без картинка.

| Опция | Поведение в Inventor | Ограничения | При нас |
|---|---|---|---|
| Текстура на стената | картина на резба върху стената, не геометрия | | 🟡 „ръкав“ на 0.016 mm от стената към въздуха (`ThreadBands`), шейдърът `fs_thread` рисува светли/тъмни винтови ивици; чака визуална проверка |
| Стъпка на ивиците | изображението подсказва резба | | 🟡 една ивица на стъпка (фаза h/P ∓ θ/2π от `ThreadSpec::pitch`); ивици под ~2 px избледняват към средния тон (без моаре); чака визуална проверка |
| Посока (Right / Left Hand) | | | 🟡 ивиците се накланят според посоката; огледален масив обръща посоката; чака визуална проверка |
| Само по дължината на резбата | при непълна дълбочина или Offset + Length текстурата е само там | | 🟡 ръкавът е от началото до края на резбата; чака визуална проверка |
| Вътрешна и външна | отвор с резба (Hole Tapped) и Thread на вал или в отвор | | 🟡 вътрешна: на стената на свредлото, нормали към оста; външна: на вала; чака визуална проверка |
| Следва оцветяването | цветът и светлината на стената остават | | 🟡 смесване „умножение по 2·стойност“ върху вече оцветената стена: външният вид (appearance) и светлината се запазват; чака визуална проверка |
| Скрито зад други стени | | | 🟡 тест за дълбочина без запис; изрязването (Slice Graphics) го реже като стената; чака визуална проверка |
| Масиви (Pattern / Mirror) | всяко копие има резба | | 🟡 копията на козметичните резби се пазят (`CosmeticThread::transformed`); 1000+ отвора = една мрежа, по 2 пръстена на резба; чака визуална проверка |
| Textures On/Off (View) | не засяга резбите | | ⬜ няма такава команда още |
| Настройка на приложението (наша) | в Inventor няма | | 🟡 Tools → Application Options → Display → **Thread texture** (вкл. по подразбиране, `settings.json` → `options.thread_texture`); чака визуална проверка |
| Старото изображение (линии) | | | 🟡 винтовата линия и двете окръжности останаха само в предварителния преглед на командата Thread |

## 4. Поведение в дървото и при редакция

- В дървото е `Thread1` (подсказка: обозначението, козметична или моделирана). Edit Feature
  отваря същия панел; Properties показва стената, резбата, дължината и полетата с изрази.
- Моделираната канавка е стена `Thread1:Thread`. Козметичната резба не променя тялото.

## 5. Крайни случаи и грешки

- „Резбата не генерира геометрия“ (собственикът, 2026-10-19): моделираният канал се пропускаше без съобщение, когато средата на зоната му беше извън тялото. Поправено, виж 2.3 §5; тестове по пътя на GUI (`gui::hole::tests::modeled_thread_*`) проверяват, че `part.body` и сцената на изгледа имат стените на канала.

- Стената не е цилиндрична: „Thread: select a cylindrical face“.
- Диаметърът не отговаря на размера (вал: голям диаметър, отвор: малък или свредлото) с
  повече от 15 % от размера: „an M12 thread does not fit a Ø8 shaft“ (SolidCraft
  #2705/#2969: допуск на диаметъра).
- Offset + Length по-дълги от стената: „the thread is longer than the face“.
- Моделирана резба над 200 оборота: съобщение.
- Резбата започва от свободен край (каналът излиза в празното с една стъпка); при
  непълна дължина свършва рязко в края.

## 6. Реализация

- `part::hole::ThreadFeature` (`Feature::Thread`, формат ревизия 6), `ThreadSpec`
  (`internal_groove`, `external_groove`, `note`), `CosmeticThread`; `PartDocument::add_thread`,
  `PartDocument::cosmetic_threads`.
- `part::exact::thread`; моделираната канавка — `kernel::exact::cut_threads` след всички
  операции. Гладката `kernel::exact::helix_tool` (`sk::sweep_helix`) е налична, но точната
  булева операция с нея е твърде бавна (виж 2.3 §5).
- GUI: `gui/hole.rs` (`ThreadDraft`, `thread_lines` — само за прегледа), `gui/hole_panel.rs`.
- Текстура: `part::hole::ThreadBands::of(&part.cosmetic_threads)` (ръкав по `BAND_SAG`, отместен
  с `BAND_LIFT`, фаза на всеки връх), `gui::renderer::SceneGeometry::add_thread_bands`, конвейер
  `threads` (смесване Dst·Src + Src·Dst, без запис в дълбочината, след непрозрачните стени и
  преди ръбовете), шейдър `vs_thread` / `fs_thread` в `gui/viewport.wgsl`. Мрежата се строи в
  `build_scene` (при промяна на модела), никога на кадър. Тестове: `thread_bands_*` (`part::hole`),
  `thread_texture_on_hole_and_shaft`, `pattern_copies_carry_the_thread_texture` (`tests/holes.rs`),
  `viewport_shader_validates`; perf: „thread texture: mesh of 100 tapped M8 holes“.
- Тестове: `thread_on_a_shaft_cosmetic_and_modeled` (козметична, грешен размер, моделирана
  10 mm), `cut_threads_facets_only_the_zone` (дясна и лява), фикстура `r6/hole_r6`.
