# 0.5 Parameters and expressions (Manage → Parameters, fx)

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ waiting for another feature.

## 1. Purpose

Every size is a named **parameter**. Its value can be a number or an **expression** that uses other parameters: `d1 = d0 / 2`, `wall = 3 mm`, `L = 2 * wall + 40`. Changing one parameter updates everything that depends on it. This way the part becomes a "family" driven by a few numbers.

## 2. Kinds of parameters

| Kind | Inventor | Status |
|---|---|---|
| **Model parameters** | created automatically from every dimension in a sketch and every value of a feature (Extrude distance, Revolve angle…): `d0`, `d1`, … They can be renamed | ✅ sketch dimensions; 🟡 Extrude values (in the table; ⬜ expression in the Extrude dialog) |
| **User parameters** | created by the user (Add Numeric) with a name, expression, unit, comment | ✅ |
| Text / True-False parameters | text and logical parameters (for rules) | ⬜ (7.5) |
| Linked / Derived | parameters from an external file | ⬜ |

## 3. The Parameters table (columns)

| Column | Behaviour | Status |
|---|---|---|
| **Parameter Name** | unique in the part; a letter first, then letters, digits, `_`; renaming updates the expressions that use it | ✅ |
| **Consumed by** | which dimension or feature uses the parameter | ✅ |
| **Unit/Type** | mm (length), deg (angle), ul (unitless) | ✅; 🟡 also cm, m, in, ft (lengths) and rad (format revision 17, `Unit::ALL`): a bare number takes the unit, values stay mm / rad inside; changing the unit converts a plain value (25.4 mm → 1 in) and keeps an equation as typed (evaluated again) — waiting for a visual check |
| **Equation** | a number or an expression; on an error the cell is red and the value does not change | ✅ |
| **Nominal Value** | the computed value, at full precision | ✅ |
| **Tolerance** | Upper / Nominal / Lower / Median: which limit of the tolerance the model is built at | ✅ (dimensions) |
| **Model Value** | the value the model is built with (nominal ± tolerance, as chosen) | ✅ |
| **Key**, **Export Parameter** | key parameter, export to iProperties | ⬜ |
| **Comment** | free text | ✅ |
| Add Numeric / Delete | add a user parameter; delete only an unused one | ✅ |
| Purge Unused | deletes the unused user parameters | 🟡 button under the table (`PartDocument::purge_unused_parameters`: user parameters no equation or feature field uses); test; waiting for a visual check |
| Filter (All / Renamed / Used / Unused / Key) | filter of the list | 🟡 All / User / Model / Used / Unused (Used = some equation names it); Renamed and Key ⬜ |
| **Pick whip** (our addition, After Effects style) | — | 🟡 each row has an `@` handle: dragged onto another row's name or equation, that parameter follows it (`link_parameter`: the equation becomes the name, then it can be edited, e.g. `Width * 2`); dropped onto any value field (Properties, feature dialogs) the field takes the name; a line follows the pointer while dragging; a circular link or a link to itself is refused and changes nothing (test) — waiting for a visual check |

## 4. Expressions

| Behaviour | Status |
|---|---|
| Numbers, `+ - * / ^`, parentheses, unary minus | ✅ |
| Parameter names | ✅ |
| Functions: `sin cos tan asin acos atan sqrt abs floor ceil round min max`, constant `PI` | ✅; 🟡 also `sinh cosh tanh asinh acosh atanh exp ln log sign pow(x, y)` and `E` (test) |
| Units in the expression: `10 mm`, `1 in`, `0.5 cm`, `45 deg`, `1 rad`; no unit → the parameter's unit | ✅ (bare numbers in a sum with a quantity get the parameter's unit; in an argument of sin/cos — degrees); 🟡 the Dynamic Input fields next to the cursor take equations and parameter names too (`10+5`, `d0*2`, `1 in`: letters after a first digit belong to the field) — waiting for a visual check |
| Angles are entered in degrees and stored in radians internally | ✅ |
| Circular dependencies are refused with a clear message | ✅ |
| The expression is kept; the value is recomputed on every change | ✅ |

## 6. Implementation

`part/params.rs`: `Parameters` (table), `Expr` (parsing and evaluation), `ParamValue`. The part keeps the table. On regeneration the parameters are evaluated first, then their values are written into the sketch dimensions and the features.
