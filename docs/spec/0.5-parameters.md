# 0.5 Параметри и изрази (Manage → Parameters, fx)

Статус: ✅ готово · 🟡 частично · ⬜ предстои · ⛔ чака друга функция.

## 1. Предназначение

Всеки размер е **параметър** с име. Стойността му може да е число или **израз**, който ползва други параметри: `d1 = d0 / 2`, `wall = 3 mm`, `L = 2 * wall + 40`. Промяна на един параметър обновява всичко, което зависи от него. Така детайлът става „фамилия“ с няколко управляващи числа.

## 2. Видове параметри

| Вид | Inventor | Статус |
|---|---|---|
| **Model parameters** | създават се автоматично от всеки размер в скица и всяка стойност на операция (Extrude distance, Revolve angle…): `d0`, `d1`, … Могат да се преименуват | ✅ размери в скиците; 🟡 стойностите на Extrude (в таблицата; ⬜ израз в диалога на Extrude) |
| **User parameters** | създадени от потребителя (Add Numeric) с име, израз, единица, коментар | ✅ |
| Text / True-False параметри | текстови и логически параметри (за правила) | ⬜ (7.5) |
| Linked / Derived | параметри от външен файл | ⬜ |

## 3. Таблицата Parameters (колони)

| Колона | Поведение | Статус |
|---|---|---|
| **Parameter Name** | уникално в детайла; буква в началото, после букви, цифри, `_`; преименуването обновява изразите, които го ползват | ✅ |
| **Consumed by** | кой размер или операция ползва параметъра | ✅ |
| **Unit/Type** | mm (дължина), deg (ъгъл), ul (безразмерно) | ✅ |
| **Equation** | число или израз; при грешка клетката е червена и стойността не се сменя | ✅ |
| **Nominal Value** | изчислената стойност, с пълна точност | ✅ |
| **Tolerance** | Upper / Nominal / Lower / Median: по коя граница на допуска се строи моделът | ✅ (размери) |
| **Model Value** | стойността, с която се строи (номинал ± допуск според избора) | ✅ |
| **Key**, **Export Parameter** | ключов параметър, износ в iProperties | ⬜ |
| **Comment** | свободен текст | ✅ |
| Add Numeric / Delete | добавяне на потребителски параметър; изтриване само на неизползван | ✅ |
| Purge Unused | изтрива неизползваните потребителски параметри | ⬜ |
| Filter (All / Renamed / Used / Unused / Key) | филтър на списъка | ⬜ |

## 4. Изрази

| Поведение | Статус |
|---|---|
| Числа, `+ - * / ^`, скоби, унарен минус | ✅ |
| Имена на параметри | ✅ |
| Функции: `sin cos tan asin acos atan sqrt abs floor ceil round min max`, константа `PI` | ✅ |
| Единици в израза: `10 mm`, `1 in`, `0.5 cm`, `45 deg`, `1 rad`; без единица → единицата на параметъра | ✅ (голите числа в сума с величина получават единицата на параметъра; в аргумент на sin/cos — градуси) |
| Ъглите се въвеждат в градуси, вътре се пазят в радиани | ✅ |
| Цикличните зависимости се отказват с ясно съобщение | ✅ |
| Изразът се пази; стойността се преизчислява при всяка промяна | ✅ |

## 5. Връзка с размерите

| Поведение | Статус |
|---|---|
| Всеки driving размер получава име `d<N>` при създаване (N расте в детайла) | ✅ |
| В Edit Dimension (и в редакцията върху размера) може да се въведе израз | ✅ |
| Размер, управляван от израз, се показва с префикс `fx:` | ✅ |
| Показване на размерите: Value / Name / Expression / Tolerance (лентата на състоянието, като в Inventor) | ✅ |
| Driven размерите също имат параметър (само за четене) и могат да се ползват в изрази | ⬜ |

### 5.1 Параметри в полетата на операциите

| Поведение | Статус |
|---|---|
| Distance A/B, Taper, Angle A/B в Properties приемат израз и имена на параметри (виж [0-ui §2.7](0-ui.md)) | ✅ |
| Уравнението се пази в параметъра на операцията (`FeatureParams`) и се вижда в таблицата Parameters | ✅ |
| Менюто `>` → List Parameters / Show Dimensions / Measure / Recently Used | 🟡 List Parameters, Recently Used ✅; ⬜ Show Dimensions, Measure |

## 6. Реализация

`part/params.rs`: `Parameters` (таблица), `Expr` (разбор и изчисляване), `ParamValue`. Детайлът пази таблицата. При регенерация първо се изчисляват параметрите, после стойностите им се записват в размерите на скиците и в операциите.
