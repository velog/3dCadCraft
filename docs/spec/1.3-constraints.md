# 1.3 Geometric constraints (Sketch → Constrain)

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ waiting for another feature.

## 1. Purpose

Constraints define the **relations** between geometry: parallelism, tangency, coincidence and so on. Together with the dimensions ([1.4](1.4-dimensions.md)) they make the sketch **fully constrained**: every point has an exactly determined place and there are no redundant or conflicting conditions.

## 2. General behaviour

| Behaviour | Inventor | Status |
|---|---|---|
| Selection order | the tool is chosen first, then the geometry in the order it requires; stays active until Esc | ✅ |
| Over-constraining | a constraint that would over-constrain the sketch is **not applied** and the sketch does not change (with Relax mode off) | ✅ |
| Glyphs | every constraint has a label next to the geometry (F8 shows, F9 hides) | ✅ |
| Hovering a glyph | highlights the constrained geometry | ✅ |
| Selection and deletion | a click on a glyph selects (Shift adds), Delete deletes; right click → Delete Constraint | ✅ |
| Delete Constraints of a curve | removes all constraints of the curve and of its points | ✅ |
| List in Properties | all constraints of the sketch; hovering highlights, a click selects, `x` deletes | ✅ |
| Show Constraints (selected curves) | shows the glyphs only of the selected curves | ⬜ (for now all or none) |
| Automatic Dimensions and Constraints | adds constraints and dimensions until the sketch is fully constrained | ⬜ |

## 3. The constraints

| Constraint | Selection | Meaning | Status |
|---|---|---|---|
| **Coincident** | point + point | they coincide | ✅ |
|  | point + curve (line, circle, arc, spline) | the point is on the curve and can slide along it | ✅ |
| **Collinear** | two lines | on one straight line | ✅ |
| **Concentric** | two circles or arcs (or ellipses) | shared centre | ✅ (no ellipses) |
| **Fix** | point or curve | fixes the place (for a curve — its defining points) | ✅ |
| **Parallel** | two lines (or an ellipse axis) | parallel | ✅ |
| **Perpendicular** | two lines | perpendicular | ✅ |
| **Horizontal** | a line or two points | horizontal / at the same height | ✅ |
| **Vertical** | a line or two points | vertical / one above the other | ✅ |
| Horizontal / Vertical to a **line's midpoint** | a point (or midpoint) and the midpoint of a line (the midpoint glyph under the cursor) | aligned with the middle of the line (a point in the centre of a rectangle) | 🟡 the midpoint snap is on for these tools; a point held at the middle (`Midpoint`) is added and aligned (test `horizontal_and_vertical_to_line_midpoints`); waiting for a visual check |
| **Tangent** | line–circle/arc, circle–circle, curve–spline | tangent; internally or externally according to the geometry | ✅ without splines |
| **Smooth (G2)** | spline + curve | continuous curvature at the shared point | ⬜ |
| **Symmetric** | two points, two lines or two circles + a line of symmetry | mirrored | ✅ |
| **Equal** | two lines (lengths) or two circles/arcs (radii) | equal | ✅ |
| Midpoint | point + line | at the middle (in Inventor it is Coincident to the midpoint) | ✅ (on a snap and in the composite shapes); the Coincident tool takes a line's midpoint (point → midpoint or midpoint → point, 2026-10-27, waiting for a visual check) |

**Internal constraints** (not shown as glyphs; Inventor also hides its internal relations):
- `Translated` / `Rotated` (patterns);
- `SymmetricOnArc` (Mirror of arcs);
- `EqualOffset` (Offset).

## 5. Relax Mode

| Behaviour | Inventor | Status |
|---|---|---|
| Turning it on | Constrain → Relax Mode, button in the status bar, **F11**; the state is remembered | ✅; ⬜ remembered between sessions |
| Dragging | the dimensions the drag has to change become **driven** (in parentheses, with the new value); the others stay driving; the constraints are respected | ✅ |
| New constraint on a conflict | the conflicting constraints are removed, the conflicting dimensions become driven; the user confirms or reverts | ⬜ (refused for now) |
| Protected kinds | Coincident, Tangent, Symmetric, Smooth, Pattern, Project and dimensions with equations are not removed | ⬜ |

## 6. Solver

- Levenberg with damping λ·I. As λ → 0 the step has **minimum norm**, i.e. the geometry moves as little as possible. ✅
- Failure → the sketch does not change and is red. ✅
- A tangent at a shared endpoint is solved with a first-order condition (otherwise there is a double root). ✅
- Point on a spline: signed distance to the closest point, with no extra unknown. ✅
- Two identical circles from arcs (mirrored halves) do not duplicate their equation. ✅
- Splitting into independent clusters and an analytic Jacobian for large sketches. ⬜

## 7. Edge cases

- Coincident between a point and its own curve (for example a centre with its circle) → refused with a reason. ✅
- Tangent between two lines, Parallel between a line and a circle → unsuitable selection, refused. ✅
- A constraint on projected geometry → allowed (it is fixed). ✅
