# 1.3 Геометрични ограничения (Sketch → Constrain)

Статус: ✅ готово · 🟡 частично · ⬜ предстои · ⛔ чака друга функция.

## 1. Предназначение

Ограниченията задават **връзките** между геометрията: успоредност, допирателност, съвпадение и т.н. Заедно с размерите ([1.4](1.4-dimensions.md)) те правят скицата **напълно дефинирана**: всяка точка има точно определено място и няма излишни или противоречиви условия.

## 2. Общо поведение

| Поведение | Inventor | Статус |
|---|---|---|
| Ред на избора | инструментът се избира, после геометрията в реда, който изисква; остава активен до Esc | ✅ |
| Свръхограничаване | ограничение, което би направило скицата свръхограничена, **не се прилага** и скицата не се променя (при изключен Relax mode) | ✅ |
| Знаци | всяко ограничение има етикет до геометрията (F8 показва, F9 скрива) | ✅ |
| Посочване на знак | осветява ограничената геометрия | ✅ |
| Избор и изтриване | клик върху знак избира (Shift добавя), Delete изтрива; десен клик → Delete Constraint | ✅ |
| Delete Constraints на крива | маха всички ограничения на кривата и на точките ѝ | ✅ |
| Списък в Properties | всички ограничения на скицата; посочване осветява, клик избира, `x` изтрива | ✅ |
| Show Constraints (избрани криви) | показва знаците само на избраните криви | ⬜ (засега всички или нито един) |
| Automatic Dimensions and Constraints | добавя ограничения и размери, докато скицата стане напълно дефинирана | ⬜ |

## 3. Ограниченията

| Ограничение | Избор | Значение | Статус |
|---|---|---|---|
| **Coincident** | точка + точка | съвпадат | ✅ |
|  | точка + крива (линия, окръжност, дъга, сплайн) | точката е върху кривата и може да се плъзга по нея | ✅ |
| **Collinear** | две линии | на една права | ✅ |
| **Concentric** | две окръжности или дъги (или елипси) | общ център | ✅ (без елипси) |
| **Fix** | точка или крива | фиксира мястото (на кривата — определящите ѝ точки) | ✅ |
| **Parallel** | две линии (или ос на елипса) | успоредни | ✅ |
| **Perpendicular** | две линии | перпендикулярни | ✅ |
| **Horizontal** | линия или две точки | хоризонтална / на една височина | ✅ |
| **Vertical** | линия или две точки | вертикална / една над друга | ✅ |
| **Tangent** | линия–окръжност/дъга, окръжност–окръжност, крива–сплайн | допирателни; вътрешно или външно според геометрията | ✅ без сплайни |
| **Smooth (G2)** | сплайн + крива | непрекъсната кривина в общата точка | ⬜ |
| **Symmetric** | две точки, две линии или две окръжности + линия на симетрия | огледални | ✅ |
| **Equal** | две линии (дължини) или две окръжности/дъги (радиуси) | равни | ✅ |
| Midpoint | точка + линия | в средата (в Inventor е Coincident към средата) | ✅ (при прихващане и във фигурите) |

**Вътрешни ограничения** (не се показват като знаци; Inventor също крие своите вътрешни връзки):
- `Translated` / `Rotated` (масиви);
- `SymmetricOnArc` (Mirror на дъги);
- `EqualOffset` (Offset).

## 4. Степени на свобода и цветове

| Поведение | Inventor | Статус |
|---|---|---|
| Брой нужни размери/ограничения | в лентата на състоянието: „Needs N dimension(s)/constraint(s)“ или „Fully constrained“ | ✅ |
| Цвят на скицата | синьо недодефинирана, зелено напълно дефинирана, оранжево излишни, червено противоречие ([0-ui.md](0-ui.md), раздел 2.2) | ✅ |
| Цвят на отделна крива | зелена, щом самата тя е напълно дефинирана | ✅ |
| **Show All Degrees of Freedom** | знаци за свободните посоки на всяка точка и крива; бутон DOF в лентата на състоянието; десен клик → Display Degrees of Freedom | ✅ |
| Как се изчислява | ранг на якобиана в решението; нулевото пространство дава посоките | ✅ |

## 5. Relax Mode

| Поведение | Inventor | Статус |
|---|---|---|
| Включване | Constrain → Relax Mode, бутон в лентата на състоянието, **F11**; състоянието се помни | ✅; ⬜ помнене между сесиите |
| Влачене | размерите, които влаченето трябва да промени, стават **driven** (в скоби, с новата стойност); останалите остават driving; ограниченията се спазват | ✅ |
| Ново ограничение при конфликт | конфликтните ограничения се махат, конфликтните размери стават driven; потребителят потвърждава или връща | ⬜ (засега отказ) |
| Защитени видове | Coincident, Tangent, Symmetric, Smooth, Pattern, Project и размери с уравнения не се махат | ⬜ |
| Настройки (Relax Mode tab) | кои видове могат да се махат | ⬜ |

## 6. Solver

- Levenberg с амортизация λ·I. При λ → 0 стъпката е с **минимална норма**, т.е. геометрията се мести възможно най-малко. ✅
- Неуспех → скицата не се променя и е червена. ✅
- Тангента в обща крайна точка се решава с условие от първи ред (иначе има двоен корен). ✅
- Точка върху сплайн: знаково разстояние до най-близката точка, без допълнителна неизвестна. ✅
- Два еднакви кръга от дъги (огледални половини) не дублират уравнението си. ✅
- Разделяне на независими клъстери и аналитичен якобиан за големи скици. ⬜

## 7. Крайни случаи

- Coincident между точка и собствената ѝ крива (например център с окръжността си) → отказ с причина. ✅
- Tangent между две линии, Parallel между линия и окръжност → неподходящ избор, отказ. ✅
- Ограничение върху проектирана геометрия → позволено (тя е фиксирана). ✅

## 8. Реализация

`sketch/constraint.rs` (видовете, остатъци, валидиране), `sketch/solver.rs` (решаване, DOF, излишни), `gui/sketch_tools.rs` (`constraint_click`), `gui/overlay.rs` (знаци).
