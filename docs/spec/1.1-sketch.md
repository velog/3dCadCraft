# 1.1 2D sketch: creation, editing, coordinate system

Status: ✅ done · 🟡 partial · ⬜ to do · ⛔ waiting for another feature.

## 1. Purpose

The 2D sketch is the basis of almost every feature. Geometry is drawn in it, constrained with geometric relations and dimensions, and profiles are taken from it. The sketch lies in a plane: an origin plane, a planar face or a work plane. It **remembers** the plane by persistent name and **follows** it when the model changes.

## 6. Default coordinate system

In ours Z is up; Inventor is Y-up by default, so some initial directions differ.
- **XY:** x = X.
- **XZ:** viewed from −Y; x = X, y = Z.
- **YZ:** viewed from +X; x = Y, y = Z.
- **Face:** the normal points outwards; on a vertical face y = +Z, on a horizontal one x = +X.
- **Origin:** the projection of the part origin.

## 7. Browser and consumption

- A new sketch appears in the browser after the last feature. 🟡 (for now sketches are after the features)
- A sketch used by a feature goes under it and is hidden. Share Sketch shows it above the feature. Details: [2.1-extrude.md](2.1-extrude.md), section 4. ✅

## 8. Edge cases

- A face that disappears on a change (for example a deleted feature) makes the sketch sick. The sketch keeps the last good plane. ✅
- Redefine to a non-planar face → refused. ✅
- Edit Coordinate System to an invalid edge (not straight, not lying in the plane) → refused, no change. ✅
