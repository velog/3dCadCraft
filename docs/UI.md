# Потребителски интерфейс и миграция от Inventor

Цел: конструктор, който работи с Autodesk Inventor, да седне пред 3DCadCraft и **да знае къде е всичко**. Ще намери същото разположение на екрана, същите понятия, същата мишка и клавиши, и същия ред на работа (скица → ограничения → операция).

Копира се **организацията и работният поток**, не графиката: иконите, името и външният вид са собствени на 3DCadCraft. Подреждането „лента с табове + дърво на модела + панел със свойства + ViewCube“ е обща практика в съвременните CAD системи.

## 1. Разположение на екрана

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ [File]    New Open Save │ Undo Redo │  Project: Bracket.3dcadcraft       │ ← Quick Access
├──────────────────────────────────────────────────────────────────────────┤
│  3D Model │ Sketch │ Assemble │ Annotate │ Inspect │ Tools │ View        │ ← табове на лентата
│ ┌────────┐┌──────────────────────────┐┌─────────────────┐┌──────────┐    │
│ │ Start  ││ Extrude Revolve Hole ... ││ Fillet Chamfer  ││ Plane    │    │ ← панели с команди
│ │ Sketch ││         Create           ││     Modify      ││  Work    │    │
│ └────────┘└──────────────────────────┘└─────────────────┘└──────────┘    │
├──────────────┬──────────────────────────────────────────┬────────────────┤
│ Model        │                                    ┌───┐ │ Properties     │
│ ▾ Bracket    │                                    │TOP│ │ ─────────────  │
│   ▾ Plate    │            3D изглед               └───┘ │ Sketch1        │
│     ▸ Origin │                                 ViewCube │ DOF: 0         │
│     ▾ Sketch1│                                          │ Distance 30 mm │
│       H, V … │                                          │ …              │
│     Body1    │                                          │                │
│   Stack      │                                          │                │
├──────────────┴──────────────────────────────────────────┴────────────────┤
│ Fully constrained · 0 DOF        Select a point to drag          mm │ ISO │ ← лента на състоянието
└──────────────────────────────────────────────────────────────────────────┘
```

| Зона | В Inventor | В 3DCadCraft | Статус |
|---|---|---|---|
| Бутон за файлове + Quick Access | File menu, Quick Access Toolbar | **File** меню и New/Open/Save/Undo/Redo, Select, списъци **Material** и **Appearance** (с `*`, когато стени/операции/тела имат свой вид) | 🟡 |
| Лента с табове | Ribbon (3D Model, Sketch, Assemble, Annotate, Inspect, Tools, Manage, View, Environments) | същите табове, **зависят от вида на документа** (детайл/сглобка/чертеж) | 🟡 обвивка; неготовите команди са сиви с подсказка „предстои (ниво X.Y)“ |
| Дърво на модела | Model Browser | **Model**: проект → документи → Origin, скици, ограничения, тела | 🟡 |
| Панел със свойства | Property Panel (в новите версии вместо модални диалози) | **Properties**: параметрите на избрания елемент, редактируеми на място | 🟡 |
| ViewCube | ViewCube | ViewCube в горния десен ъгъл: клик върху стена = стандартен изглед, Home | 🟡 |
| Лента на състоянието | Status Bar | статус на скицата, подсказка за следващата стъпка, бутони **DOF** (Show All Degrees of Freedom) и **Relax**, единици, стандарт | ✅ |
| Navigation Bar | Navigation Bar | (по-късно) Pan / Zoom / Orbit / Look At бутони | ⬜ |
| Marking menu | радиално меню с десен бутон | засега обикновено контекстно меню: New Sketch върху стена, Finish 2D Sketch; в дървото: Edit/Redefine/Look At/Hide/Delete | 🟡 |
| Mini-toolbar | плаваща лента при операция | стойности на място в изгледа (например разстояние при Extrude) | ⬜ |

**Лентата зависи от средата:**
- **Детайл:** 3D Model, Sketch, Inspect, Tools, Manage, View. Tools има панел **Material and Appearance** (Material, Appearance, Adjust, Clear); Manage — **Styles and Standards** (Styles Editor, Update, Purge); Inspect → **Physical Properties**.
- **В скица:** таб Sketch, с панели Create, Modify, Pattern, Constrain, Insert, Format.
- **Сглобка:** Assemble, Design (калкулатори), Inspect, Tools, View.
- **Чертеж:** Place Views, Annotate, Sketch, Tools, View.

Както в Inventor, влизането в скица отваря таба Sketch, а „Finish Sketch“ връща в 3D Model.

## 2. Мишка

Има избираеми **профили на мишката** (View → Navigation), за да не се преучава ръката:

| Действие | Профил **Inventor** (по подразбиране) | Профил **3DCadCraft** (досегашният) |
|---|---|---|
| Завъртане (orbit) | **Shift + среден бутон**, или задържан **F4** + ляв | ляв бутон в празно място |
| Местене (pan) | **среден бутон**, или задържан **F2** + ляв | десен или среден бутон |
| Мащаб (zoom) | колелце, или задържан **F3** + ляв (нагоре/надолу) | колелце |
| Избор / влачене на точка | ляв бутон | ляв бутон върху точка |
| Покажи всичко | **Home** (F6) / двоен клик със средния бутон | двоен клик |

Посоката на колелцето може да се обърне (в Inventor също е настройка).

**Прихващане в скица:** курсорът се закача за точка в радиус 12 px и за крива в радиус 8 px. Точката има предимство. Нова линия, започната или завършена до съществуваща точка, споделя тази точка. Влачена точка, пусната върху друга точка, получава **Coincident**. Пусната върху крива, получава **Coincident (on line/circle)**. Връзката може да се изтрие от списъка Constraints.

Предвиждат се и профили **SolidWorks** и **Fusion**: различават се главно по това кой бутон върти.

## 3. Клавишни комбинации

По подразбиране са **като в Inventor** и всички могат да се преназначат. Това е списъкът, който ще се поддържа. Срещу всеки клавиш е статусът в 3DCadCraft:

| Клавиш | Действие | Статус |
|---|---|---|
| **F2** (задържан) | Pan | ✅ |
| **F3** (задържан) | Zoom | ✅ |
| **F4** (задържан) | Orbit | ✅ |
| **F5** | предишен изглед | ⬜ |
| **F6** | Home view | ✅ |
| **F7** | Slice graphics (разрез на изгледа през равнината на скицата) | ✅ |
| бутон **Align** (лента на състоянието, в скица) | включва/изключва подравняването към точки (пунктирни линии) | ✅ |
| **F8 / F9** | покажи / скрий всички ограничения на скицата | ✅ |
| **F1** | спецификацията на текущата команда (`docs/spec/`) | ✅ |
| **F11** | Relax Mode (в скица) | ✅ |
| **Enter** (без активна команда) | повтаря последната команда; десен клик → Repeat | ✅ |
| **S** | нова 2D скица (Start 2D Sketch) | ✅ |
| **L / C / R** | Line / Center Point Circle / Two Point Rectangle (в скица) | ✅ |
| **Enter** | завършва сплайн / прилага Edit Dimension | ✅ |
| **Delete** | изтрива избраната геометрия и избраните ограничения | ✅ |
| **двоен клик** върху размер | Edit Dimension | ✅ |
| **D** | размер (General Dimension) | ✅ |
| **X / O** | Trim / Offset | ✅ |
| **Shift** (при Trim/Extend) | превключва Trim ↔ Extend | ✅ |
| **E** | Extrude | ✅ |
| **R / H** | Revolve / Hole (в 3D Model) | 🟡 R ✅; H ⬜ |
| **P / C** | Place / Constrain (в сглобка) | ⬜ |
| **Ctrl+Z / Ctrl+Y** (и Ctrl+Shift+Z) | Undo / Redo | ✅ |
| **Ctrl+S / Ctrl+O / Ctrl+N** | запис / отваряне / нов | ✅ запис и отваряне |
| **Esc** | прекратява текущия вход; второ Esc връща Select | ✅ |
| **Ctrl** (задържан) | без автоматични ограничения при чертане | ✅ |

> Буквените комбинации на Inventor могат да се различават според езика и версията. Таблицата ще се сверява с реална инсталация, а файлът с клавиши ще е лесен за редакция (`keymap.toml`).

### Динамично въвеждане (докато се чертае Line / Circle / Rectangle)

| Клавиш | Действие |
|---|---|
| цифри, `.`, `-`, Backspace | пише в активното поле до курсора |
| Tab / Shift+Tab | следващо / предишно поле (заключва въведеното) |
| Enter | поставя точката; заключените стойности стават размери |
| Esc | изчиства въведеното (второ Esc прекратява) |
| ↑ | последната стойност, въведена в това поле |

### Избор в 3D

| Клавиш / действие | Действие |
|---|---|
| курсор над ръб/стена | светва (зелено), до курсора: име, операция, тяло / дължина |
| клик | избира (синьо) и показва лентата с предложения |
| Shift+клик / Ctrl+клик | добавя към избора / превключва (без лента) |
| влачене от празно място | правоъгълник: отляво надясно — изцяло вътре, отдясно наляво — и пресечените (Shift добавя, Ctrl превключва) |
| двоен клик върху стена/ръб | **Select Tangencies** — всички допирателни стени/ръбове |
| Ctrl+A | всичко от режима на избор |
| **Select: …** (лентата горе, до Undo/Redo) | режим: Faces and Edges / Features / Bodies / Sketch Features; Enable Prehighlight; Select All, Invert Selection, Previous Selection, Select Tangencies |
| Esc | изчиства избора (Previous Selection го връща) |
| Extrude/Revolve: влачене от празно място | избор на профили с правоъгълник |
| **Rebuild** (лентата горе) / Tools → Update → Rebuild All | всички операции наново, без кеша |
| File → **Export** → STL / STEP / GLB | износ под името от полето за път (разширението се сменя) |
| Fillet/Chamfer: **Select** Edge / Loop / Feature / Solid | Loop и Feature: клик върху стена; Solid: All Edges / All Fillets / All Rounds |
| Fillet: Type Constant / Variable / Chord / Full Round; **Add set** | набори ръбове с различен радиус; Full Round: клик върху средната стена |
| Line: курсор върху окръжност/дъга до точката на допиране | тангентен снап (знак „tangent“): край върху кривата + Tangent |
| покой ~0,7 s върху няколко обекта | **Select Other**: `<` `>`, ←/→ или Shift+колелце сменят, щракване върху името избира |
| Enter или интервал (без активна команда) | повтаря последната команда |
| БГ (долу вдясно) | подсказки на български (пази се в `~/.config/3dcadcraft/settings.json`, под Windows в `%APPDATA%\3dcadcraft\settings.json`) |

## 5. Преминаване на съществуващи данни

1. **Модели:** от Inventor се изнася **STEP AP242** (File → Export → CAD Format) и се отваря в 3DCadCraft (ниво 7.7, предстои). Геометрията идва точна, но *без история*. Промените се правят с директно редактиране (5.5) или чрез ремоделиране по скиците.
2. **Чертежи:** DXF за справка. Новите чертежи се създават асоциативно от модела.
3. **Стандартни елементи:** вместо Content Center се изгражда фирмена библиотека `company-standard.3dcadcraft` (виж FEATURES 6.3).
4. **Шаблони:** основни надписи и стилове се пресъздават в Styles & Standards (4.1).
5. **Навици:** профил на мишката „Inventor“ и клавишите по-горе са включени по подразбиране.

## 6. Език на интерфейса

Командите в лентата са на **английски, с имената от Inventor** (Extrude, Revolve, Fillet), защото конструкторите ги познават така и така ги търсят в документацията. Превод на интерфейса (български и други) е предвиден чрез файлове с преводи. Изборът на езика е в Application Options.


## Edit Feature

Двоен клик върху операция в дървото (или контекстното меню **Edit Feature**, също от стена/ръб в изгледа) отваря диалога ѝ с входовете; моделът се връща назад до нея. **OK** заменя операцията на място, **Cancel** / **Esc** връща модела напред. Предварителният изглед се смята във фонова нишка („Computing the preview...“).
