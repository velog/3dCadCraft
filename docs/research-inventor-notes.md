# Inventor research notes (for 3DCadCraft specs)

All text below is our own paraphrase of Autodesk Inventor Help (2027 pages where they
exist, older years where the 2027 page is thin). Option names stay in English.
Markers:
- **[Help]** = stated on a fetched Help page.
- **[Mem]** = general Inventor knowledge, NOT confirmed on a fetched 2027 page — verify
  before marking a spec row as "matches Inventor".

Common facts about the modern **property panel** (GUID-3E5505B9-9F60-43A0-BF32-97D183B91A70,
2027) apply to Shell, Patterns, Hole (and Extrude/Revolve/Fillet/Sweep):

- Floating panel, opens at the upper-left of the graphics area; can be moved, resized,
  docked into a graphics window or the browser space, or put on a 2nd monitor; the next
  command opens where the last one was docked. [Help]
- **Breadcrumb** at the top: `Sketch > Feature`; the active part is blue; click to jump
  between sketch and feature editing (switching commits pending edits); click the text
  twice to rename (browser node updates on OK). [Help]
- **Preview toggle** right of the breadcrumb (not in every panel). [Help]
- **Preset row** under the header (see §7). [Help]
- **Accordion sections**, top to bottom, progressive: a section affects only those below
  it. Rarely used options sit in a collapsible **Advanced Properties** group. Warnings of
  a collapsed group show on its header. [Help]
- **Selectors**: each shows a coloured dot (same colour as the selection highlight in the
  view), the count of picked items, and an `X` to clear. The **active selector is
  underlined**. Some commands allow several selection sets ("Add … set" button). [Help]
- Icon groups can be shown as dropdown lists (arrow at the right of the field; type the
  first letter to choose). [Help]
- Value fields take numbers, equations and parameter names; flyout arrow offers Measure,
  Show Dimensions / Select Feature Dimension, Tolerance…, recent values. [Help]
- Manipulators in the view edit the same value; the active manipulator highlights and the
  matching field gets focus. Reference (non-editable) values are shown in parentheses. [Help]
- Keys: Enter / Tab commit a value and go to the next field (Shift+Tab back); **Ctrl+Enter**
  = OK (create + close); if a required selector is still empty, Enter acts as **Continue**
  and moves focus to it; Esc / Cancel exits; Undo while the panel is open cancels the
  command; Ctrl+Down opens the value flyout; Ctrl+Delete deletes a table row. [Help]
- Buttons at the bottom: **OK**, **Apply and create new (+)** (creates the feature and
  restarts the command with the same settings), **Cancel**. The marking menu shows OK at
  3 o'clock, disabled, or Continue when inputs are missing. [Help]
- Status: a required-but-empty value is red with an alert icon; a blocking problem shows a
  red diamond with "!"; profile problems show a Sketch Doctor icon; warning badges appear
  in the panel *and* the in-canvas HUD, tooltip on hover. Orange dots mark new/rare
  options after install. [Help]
- **Advanced settings menu** (gear/hamburger in the header, contextual per command,
  remembered between sessions): e.g. Pre-select sketch center points, Keep sketch visible
  on (+), Window select center points only, Hide Presets, Single ENTER to finish
  command, Open Library Location, Help. [Help]
- Patterns have a **tool palette** docked to the panel side (detachable) to switch the
  pattern type and the selection priority (feature vs solid body). [Help]

Old-style **dialogs** (Mirror, Face Draft, Styles editor) are modal-less dialogs with
selector buttons (white arrow icon), tabs/"More >>" expander and OK / Cancel / Apply. [Mem]

## 1. Shell (part feature)

**Sources:** To Create a Shell — GUID-D9BDDBFF-CCC3-46B9-921E-E30F3849D7DE (fetched 2027);
legacy Shell dialog box — GUID-899C322D-651C-47D5-801D-D5E737BAC08D (2014);
What's New 2026 "Shell Enhancements" — Inventor-WhatsNew INV2026-SHELL-ENHANCEMENTS
(https://help.autodesk.com/cloudhelp/2026/ENU/Inventor-WhatsNew/files/INV2026-SHELL-ENHANCEMENTS.htm);
Shell presets topic GUID-0FDF0162-5374-4FC8-B6E3-59FDBC9AAA40; parent About Placed
Features GUID-1FE5C77C-167B-4F89-BC39-FBFD7B27C197.

### Purpose
Hollows a solid so that only walls of a given thickness remain. Faces picked for removal
become openings; with no removed face the result is a closed internal cavity. Shell acts
on the whole body, so features added *after* it are not shelled (LT help). [Help]

### Inputs
- Body/bodies (Solids selector, only when the part has more than one body). [Help]
- Faces to remove (optional). [Help]
- Thickness (uniform). [Help]
- Optional per-face thickness overrides. [Help, legacy]

### Options
| Option | Behaviour | Restrictions |
|---|---|---|
| Shell type: **Sharp Corners** (2026+) | offset walls meet in sharp corners | — [Help] |
| Shell type: **Rounded Corners** (2026+) | corners generated by the offset get rounds (the outer corner offsets become round); meant also for a partial result to finish with surface tools | — [Help] |
| Direction **Inside** | wall offset into the material; original outside stays the outside | default [Mem] |
| Direction **Outside** | wall offset outward; original skin becomes the inner wall | [Help] |
| Direction **Center / Both Sides** | half thickness each side; part grows by t/2 per side | named "Both Sides" in older help, "Center" in 2027 page [Help] |
| **Thickness** | one value for all non-removed walls; expression/parameter | must be > 0 [Mem] |
| **Remove Faces** | picks faces to delete; Ctrl+click removes from the set | Part must be active (assembly in-place) [Help] |
| **Automatic Face Chain** | picking a face also picks its tangent-connected faces; on by default; off = single faces | [Help legacy] |
| **Solids** | which bodies are shelled | hidden/disabled with one body [Help legacy] |
| **Unique Face Thickness** table | rows = (face set, thickness); click a row, pick faces (count shown), type thickness; deleting a row returns those faces to the default thickness | legacy "More" tab; the 2027 page mentions "uniform or unique" but its steps describe only uniform, so the panel location is unconfirmed [Help] |
| **Allow Approximation** | when no exact offset exists (exact = every point of the original has its offset at exactly t), allow deviation | applies only when exact fails [Help] |
| — **Mean** | deviation split above and below t | needs Allow Approximation [Help] |
| — **Never Too Thin** | deviation only above t (keeps minimum) | [Help] |
| — **Never Too Thick** | deviation only below t (keeps maximum) | [Help] |
| — **Tolerance as Optimized** | system picks a sensible tolerance, fast | [Help] |
| — **Tolerance as Specified** | user tolerance (0..100 per 2027 page); may be slow | [Help] |

### Browser / edit
- Feature node `Shell1` in the browser after the features it hollows. [Mem]
- Edit Feature (double-click / right-click) reopens the property panel with all values;
  values also editable with in-canvas manipulator. [Help]
- If an approximation was used, after OK a message box asks to accept (OK) or go back
  (Edit) to the panel. [Help]

### Edge cases / errors
- Thickness larger than a local radius of curvature (inward) → offset self-intersects;
  kernel fails or needs approximation. [Mem]
- Big offsets can leave artefact faces (forum: fixed with Delete Face → Heal). [forum]
- Mirror/pattern cannot copy a Shell individually (whole-body feature) — see §3. [Help]

### UI and workflow
- (a) Ribbon: **3D Model tab > Modify panel > Shell**. [Help]
- (b) Panel top→bottom (2026/2027): header with breadcrumb `Shell1`, preview toggle,
  advanced menu; **Preset** row; **Input Geometry** section: *Remove Faces* selector
  (active first, underlined, coloured dot, count + X), *Solids* selector (multi-body only),
  Automatic Face Chain toggle [Mem: icon toggle next to selector]; **Behavior** section:
  shell type icons (Sharp / Rounded Corners), direction icons (Inside / Outside / Center),
  **Thickness** field; **Advanced Properties**: Allow Approximation + Mean / Never Too
  Thin / Never Too Thick + Optimized / Specified tolerance (+ Unique face thickness table
  if present). Section names are [Mem]; the option list is [Help].
- (c) Prompt flow: on start Inventor immediately shows a **preview of the closed shell**
  (no face removed) — [Mem]; hovering a face highlights it (with its tangent chain), click
  adds it to Remove Faces and the preview reopens there; Ctrl+click removes. A distance
  **arrow manipulator** on a wall drags the thickness, with an in-canvas edit box. [Help:
  manipulator exists; arrow shape Mem]
- (d) Defaults: Inside, Sharp Corners, Automatic Face Chain on, approximation off,
  thickness = last used / preset (default 2 mm-ish [Mem]); Preset field = "Last Used" if a
  shell exists, otherwise "No Preset". [Help for preset; others Mem]
- (e) OK / Ctrl+Enter creates and closes; (+) creates and restarts; Cancel/Esc discards.
  Browser shows `Shell1`; Edit Feature reopens the same panel populated. [Help]
- (f) Messages (paraphrased): "shell could not be created / offset failed — try a
  different thickness or allow approximation" [Mem]; approximation accept/edit dialog
  [Help]; red required-field marker if thickness empty [Help general].

## 2. Face Draft (Draft)

**Sources:** To Create a Draft — GUID-38133835-2EDB-414E-ACB1-2487A96900F7 (fetched 2027);
Face draft dialog box — GUID-0824679A-7B9F-4261-B96B-4F073020E757 (2014);
Face draft feature — GUID-8E2A3152-8F73-4516-AD5E-F0225EA8DA11 (2014);
Create fixed plane draft — GUID-4C4D41BF-F5DC-4853-B1F3-12EB2AA28A32 (2014);
API FaceDraftDefinition (Inventor-API/files/FaceDraftDefinition.htm).

### Purpose
Tilts selected faces by an angle relative to a pull direction so the part can leave a
mould (or simply to cant a face). Defined by faces, pull direction, angle and a fixed
reference (edge, plane or parting tool). [Help]

### Draft types
| Type | Behaviour | Symmetry allowed |
|---|---|---|
| **Fixed Edge** | each face pivots about one or more tangent-contiguous fixed edges of that face; can create extra faces | One Way only [Help] |
| **Fixed Plane** | a planar face / work plane is the pivot; pull direction = its normal; faces pivot about their intersection with the plane; can add material on one side and remove on the other | One Way, Symmetric, Asymmetric [Help] |
| **Parting Line** | pivot is a parting tool (2D/3D sketch, plane or surface); draft above and below it; lets the user choose which part of the thickness is kept | Symmetric, Asymmetric [Help] |

### Options
| Option | Behaviour | Restrictions |
|---|---|---|
| **Pull Direction** | pick planar face, work plane, edge or axis; arrow previews normal to a face / along an edge before click | Fixed Edge & Parting Line; Fixed Plane derives it [Help] |
| **Flip** (pull) | reverses the arrow | [Help] |
| **Fixed Plane** selector | planar face or work plane | Fixed Plane type [Help] |
| **Parting Tool** selector | sketch, plane or surface | Parting Line [Help] |
| **Faces** | faces to draft; in Fixed Edge the pick point near the top/bottom edge chooses which edge stays fixed (cursor glyph shows it); Ctrl+click removes | [Help] |
| **Draft Angle**, **Draft Angle 2** | value (±) or a calculation method from list; Angle 2 for Asymmetric | [Help] |
| **One Way / Symmetric / Asymmetric** | see table above | [Help] |
| **Automatic Face Chain** | tangent faces picked together; off to pick single faces | [Help] |
| **Automatic Blending** | keep adjacent blends (fillets) blended in the drafted result; off excludes them | [Help] |
| **Move Parting Line** (Parting Line) | then: Static Edges selector (single edges or **Select Boundary** for all, **Clear All**), and **Angle for Top / Angle for Both / Angle for Bottom** | [Help] |
| Absolute / Relative angle (expanded Parting Line) | how the angle is interpreted | [Help] |

### Browser / edit
- Node `Face Draft1` (FaceDraft) [Mem]; Edit Feature reopens the dialog. [Mem]

### Edge cases / errors
- Faces parallel to the pull direction get the full angle; faces already inclined are
  measured from the pull direction [Mem].
- Fixed Plane that does not cross a face → that face cannot be drafted about it (error)
  [Mem].
- Draft of faces whose neighbours cannot be extended/trimmed → feature fails [Mem].

### UI and workflow
- (a) **3D Model tab > Modify panel > Draft**. [Help] (Draft is still a **dialog**, not a
  property panel, in 2027 — no 2027 What's New item moved it [inferred].)
- (b) Dialog: left column of 3 large type buttons (Fixed Edge / Fixed Plane / Parting
  Line); right: selector buttons with arrow icons — **Pull Direction** (+ Flip button),
  [**Fixed Plane** or **Parting Tool**], **Faces**; Draft Angle field (and Angle 2);
  One Way / Symmetric / Asymmetric icon buttons; Automatic Face Chain / Automatic Blending
  checkboxes; bottom: help (?), OK, Cancel, Apply; ">>" expands Parting Line extras. [Mem
  layout, Help options]
- (c) Flow: active selector first = **Pull Direction** (Fixed Edge) / **Fixed Plane**;
  hovering shows a direction vector glyph; after the click the selector auto-advances to
  **Faces**. Hovering a face highlights it in one colour and the edge that will stay fixed
  in another; a glyph shows the tilt direction. Clicking adds it; preview of the tilted
  face appears. [Help for highlighting, Mem for auto-advance]
- (d) Defaults: Fixed Edge, angle = last value (often 0 / 1°), One Way, Automatic Face Chain
  and Automatic Blending on. [Mem]
- (e) OK creates; Apply creates and keeps the dialog for the next draft; Cancel. Browser:
  `Face Draft1`; Edit Feature reopens the dialog with the selections highlighted. [Mem]
- (f) Messages: "one or more faces could not be drafted" / "invalid fixed edge" style
  errors; angle out of range. [Mem]

## 3. Mirror (part feature)

**Sources:** To Arrange Part Features in Patterns (includes Mirror) —
GUID-9B3D1B72-340A-4F3E-9AD1-80E6DDD91ED2 (fetched 2027); Mirrored features dialog box —
GUID-8A7CFDA4-D362-4A52-BE34-40FCEA538D74 (2015; 404 on 2027 path); Mirror part —
GUID-69D50554-5688-43AA-B7CB-8E91082689B9 (2014); API MirrorFeatures.CreateDefinition.

### Purpose
Makes a mirror copy of features or of a whole body across a plane. [Help]

### Options
| Option | Behaviour | Restrictions |
|---|---|---|
| **Mirror individual features** | copies chosen solid / work / surface features; dependants of a picked feature are auto-picked | in assemblies only sketched features [Help] |
| **Mirror a solid** | copies the whole body, including features that cannot be mirrored one by one; can add work/surface features | not in assemblies (use Mirror Component) [Help] |
| **Features** selector | features from view or browser | [Help] |
| **Include Work/Surface Features** | extra work/surface features (solid mode) | [Help] |
| **Mirror Plane** | work plane or planar face (origin planes too) | [Help] |
| **Solid** | target body in a multi-body part | hidden in single-body parts [Help] |
| **Join** | result merged with the chosen body | solid mode [Help] |
| **New Solid** | result is a new body | solid mode, multi-body [Help] |
| **Remove Original** | deletes the source body, only the mirror stays (left/right hand) | solid mode [Help] |
| Creation **Optimized** | mirrors feature faces; fastest; cannot overlap or hit other faces than the originals | under More [Help] |
| Creation **Identical** | replays the original features' results | [Help] |
| Creation **Adjust to Model** ("Adjust") | recomputes each copy's extents/terminations (e.g. To face) | slow; not for open/surface bodies [Help] |

Cannot be mirrored individually: assembly work features; single sheet-metal flange /
contour flange defined on several edges; whole-body features (fillet/round "all",
**Shell**); features built from an Intersect result. [Help]

### Browser / edit
- Node `Mirror1`; expanding shows the participating features; right-click a participant →
  **Remove Participant**. Edit Feature reopens the dialog. [Help]

### UI and workflow
- (a) **3D Model tab > Pattern panel > Mirror**. [Help] Still a **dialog** in 2027. [Help:
  "Mirror uses a dialog box, not the property panel"]
- (b) Dialog: two big mode icons at the left (individual features / solid); right:
  **Features** (or Include Work/Surface Features) selector with arrow, **Mirror Plane**
  selector with arrow, **Solid** selector (multi-body), Join / New Solid / Remove Original
  (solid mode); "More >>" reveals Creation Method radio buttons; bottom ?, OK, Cancel. [Mem
  layout, Help options]
- (c) Features selector active first; picks highlight the features; then click **Mirror
  Plane** (in many versions it auto-advances after the first feature is picked? — [Mem,
  unclear]; Help step 3 says *click* Mirror Plane), pick plane → preview of mirrored copy
  appears (shaded/ghost). [Help/Mem]
- (d) Defaults: individual features, Optimized, Join. [Mem]
- (e) OK creates `Mirror1`; Cancel discards. Edit Feature reopens with selections.
- (f) "feature cannot be mirrored" for unsupported participants; Optimized failing on
  overlapping copies → suggestion to use Identical/Adjust. [Mem]

## 4. Rectangular Pattern and Circular Pattern (part features)

**Sources:** To Arrange Part Features in Patterns — GUID-9B3D1B72-340A-4F3E-9AD1-80E6DDD91ED2
(fetched 2027, describes the 2026+ property panel); Rectangular pattern dialog box
(legacy) — GUID-C1A1FF2B-082E-4D50-911E-10343611F276 (2015); Circular pattern dialog box
(legacy) — GUID-B9D71D5C-C3D8-4089-A326-9DCC2B5331B1 (2015); Arrange features in
rectangular pattern — GUID-07DF91E8-B342-477B-BE98-0C5A6F804A8E (2014); circular —
GUID-78ABC572-C94C-47ED-9755-F83865F51AB8; parent About Part Feature Patterns —
GUID-F2BDABCB-0946-4921-A196-6BC68C7C2342; What's New 2026 Patterns
(Inventor-WhatsNew/files/INV2026-PATTERNS.htm); What's New 2023.2 GUID-50A3711E-66F4-4E32-B30A-9B8956D4A574,
2025 GUID-8FC14BE7-71A7-41C4-8B24-04D8F0ABE883.

**History:** until 2025 both were dialogs (Features/Solids tabs, Direction 1/2, More >>).
In **2026** Rectangular, Circular and Sketch Driven moved to the property panel with a
shaded preview, manipulators and **irregular members** (pick occurrences in the view and
give them their own distance/angle). [Help]

### Common to both
| Option | Behaviour | Restrictions |
|---|---|---|
| Tool palette: **Select Feature** | pattern individual features (solid, work, surface) | assembly work features not allowed; finish features (fillet, chamfer, delete face) only with their parent [Help] |
| Tool palette: **Select Solid** | pattern a whole body incl. features that cannot be patterned singly; optional work/surface features | not in assemblies [Help] |
| Geometry selector | active right away; features/bodies | many features → slow [Help] |
| **Solid** (target) | which body receives the copies | multi-body only [Help] |
| **Operation Join / New Solid** | solid mode only | [Help] |
| **Boundary** (part only, 2025+) | face or profile limiting the pattern; **Offset** keep-out; inclusion: Include Geometry (whole oriented bounding box inside), Include Centroids, Base Points (picked point on an occurrence) | boundary plane must intersect the geometry or an error is shown [Help] |
| Compute **Optimized** | copies faces; fastest; no overlapping copies, no copies meeting other faces | [Help] |
| Compute **Identical** | replays original results | [Help] |
| Compute **Adjust** | each occurrence computed separately (terminations like To face) — copies can differ; slow; meeting a planar face can terminate/reshape | not for open/surface bodies [Help] |
| Suppress occurrences | browser: expand pattern → occurrence → Suppress/Unsuppress (individual must be restored individually); whole pattern → Suppress Features | first occurrence (the original) cannot be suppressed [Mem] |
| Work/surface visibility | Hide/Show All Work Features, Hide/Show All Surfaces; per-occurrence Visibility; All Surfaces Opaque/Transparent | [Help] |
| Hole with **Through All** | patterned copies cut only through what the original penetrated; switch to Distance to change | [Help] |

### Rectangular specific
| Option | Behaviour | Restrictions |
|---|---|---|
| **Direction 1 / Direction 2** | edge, axis, 2D/3D line, arc, spline, trimmed ellipse, cylindrical face (axis), origin axis; a planar face / work plane gives its normal; arrow starts at pick point; path can be open/closed; changing the path updates spacing | Direction 2 optional (rows) [Help] |
| **Flip** | reverse; with Midplane + even count chooses the side of the extra copy | [Help] |
| **Midplane** | copies on both sides of the original; separate per direction | [Help] |
| **Count / Number** | occurrences incl. original | > 0 [Help] |
| **Distribution Incremental (Spacing)** | count + spacing, span computed | [Help] |
| **Distribution Fitted (Distance)** | count + total span, spacing computed | [Help] |
| **Curve Length** (legacy third choice; 2026 = Fitted on a curve) | spreads copies evenly over the length of the chosen curve | [Help] |
| **Distance value** | negative reverses direction | [Help] |
| **Irregular member** | pick occurrence(s), give own distance ("Irregular Distance" section) | 2026+ [Help] |
| **Start** (legacy More) | per direction, a point where the first occurrence starts (any selectable point) | [Help legacy; 2026 panel location unconfirmed] |
| **Orientation Identical** | all copies keep the orientation of the first feature | [Help legacy] |
| **Orientation Adjust to Direction 1 / 2** | copies rotate to follow the 2D tangent of the path; best when the first occurrence sits at the path start | [Help legacy] |

### Circular specific
| Option | Behaviour | Restrictions |
|---|---|---|
| **Rotation Axis** (Direction) | edge, work axis, cylindrical face, origin axis; may lie in another plane than the feature | [Help] |
| **Flip** | reverse direction | [Help] |
| **Count** | including original | [Help] |
| **Angle** | Incremental: angle between copies; Fitted: total angle (360° = full circle, spacing = 360/N); negative reverses | [Help] |
| **Distribution Incremental / Fitted** | (legacy "Positioning Method"); Fitted recommended when design changes | [Help] |
| **Midplane** | copies on both sides; even count → Flip picks side of extra copy | [Help] |
| **Orientation Rotational** | copies rotate about the axis | default [Help/Mem] |
| **Orientation Fixed** (+ **Base Point**) | copies keep parent's orientation; optional vertex/point as base | [Help] |
| **Irregular member** | own angle for picked occurrences | 2026+ [Help] |
| "Associative" | for part circular patterns there is no Associative toggle; the 2D *sketch* Circular Pattern has an **Associative** checkbox (copies follow edits of source); assembly component patterns are associative by default | [Mem] |

### Browser / edit
- Node `Rectangular Pattern1` / `Circular Pattern1`; children `Occurrence1..N`, each
  containing the copied features; Edit Feature (right-click in view or browser) reopens
  the panel to change type, count, direction or spacing. [Help]

### UI and workflow
- (a) **3D Model tab > Pattern panel > Rectangular Pattern / Circular Pattern** (also
  Sketch Driven, Mirror). [Help]
- (b) Panel (2026+): breadcrumb + preview toggle; tool palette at the side (pattern type:
  rectangular/circular/sketch; selection priority feature/solid); Preset row; **Input
  Geometry** (Features/Solids selector — active, underlined); **Direction 1** section
  (Direction selector, Flip, Midplane, Number, Distribution Incremental/Fitted icons,
  Distance); **Direction 2** section (same; collapsed until used [Mem]); **Irregular
  Distance/Angle** section (add member icon); **Boundary** section; **Output**
  (Operation Join/New Solid, solids only); **Advanced/Compute** (Optimized/Identical/Adjust,
  Orientation). [Help items, Mem ordering]
- (c) Flow: pick features (highlighted) → selector auto-advances to **Direction**
  [Mem]; hover an edge shows a direction arrow from the cursor point; click → shaded
  preview of N copies appears with manipulators: an **arrow** for spacing/distance and a
  count control at the end [Mem: count glyph]; for circular an **arc/angle** manipulator.
  Clicking an occurrence in the preview lets you make it an irregular member or
  suppress it [Help for irregular, Mem for suppress]. [Help: "shaded preview and
  graphic manipulation"]
- (d) Defaults: Count 2, spacing ≈ feature size/last used, Incremental (rectangular),
  circular Count 6 / Angle 360 Fitted, Optimized, Rotational, Preset "Last Used"/"No
  Preset". [Mem]
- (e) OK / Ctrl+Enter create; (+) creates and restarts; Cancel. Browser node with
  occurrences; Edit Feature reopens the panel. [Help]
- (f) Warnings badges for conflicting values; boundary plane not intersecting →
  error + message; Optimized failure ("copies overlap") → use Identical/Adjust; "some
  occurrences failed" shows those occurrences sick in the browser. [Help for boundary,
  Mem for others]

## 5. Hole (2027 property panel)

**Sources:** To Create Holes — GUID-94EB6947-0347-4888-870D-4BA22DB144D8 (fetched 2027);
Hole features — GUID-009A70C0-B7CF-428A-B7CF-DE506F8A306E (2015); Create a Tapped Hole —
GUID-8A669999-FA2D-48E4-9B34-118B5D73B81F (2014); What's New 2025 GUID-E8AD7C92-E6AA-433B-B3A4-17D918F5B032;
What's New 2027 slot INV2027-SLOT-CMD-ENHANCEMENTS; iMate GUID-99710449-7D65-45A9-98A4-059F69B8B454;
Tolerance dialog GUID-7C7C1ED2-2CB9-41A9-B0AA-68C96C37C368; API HoleFeature.

### Purpose
Places drilled/clearance/tapped holes with optional seats; quickly via presets or by
setting dimensions, drill point, termination and thread data. [Help]

### Placement (Positions / Input Geometry)
- No sketch needed. Valid picks: a face, a sketch point (end/mid/centre), a work point. [Help]
- **Allow Center Point Creation** (on by default; remembered): click on a planar face →
  body chosen, a sketch is created on that face and a centre placed; drag free centres.
  Off → only existing sketch centre points / sketch points / work points. Disabled when
  the position is a work point. [Help]
- Point picked first → then a face/work plane (axis ⟂) or a linear edge (axis ∥) for
  direction. [Help]
- Click a model edge after a centre → a **linear dimension** to that edge is added (edit
  in place, Delete removes); "Select Feature Dimension" reuses an existing value. [Help]
- **Concentric**: after placing the centre, click a circular edge or curved face — centre
  becomes concentric. [Help]
- Visible sketch with several unused centres → all pre-selected (advanced option);
  Ctrl+click deselects (keeps the point); deleting the point removes that hole. Window
  select picks only centre points unless the option is off. **Clear Selections** button. [Help]
- Legacy placement types (From Sketch / Linear / Concentric / On Point) are gone; old
  Linear holes get a sketch with points + constraints on migration. [Help]
- **Solids** selector when 2+ bodies. [Help]

### Type
| Hole Type | Behaviour |
|---|---|
| **Simple** | plain hole, diameter only |
| **Clearance** | sized from fastener data (Clearance.xls): Standard, Fastener Type, Size, Fit (Normal / Close / Loose) |
| **Tapped** | threaded; diameter from thread size (Thread.xls) |
| **Taper Tapped** | taper thread (NPT, ISO taper…); diameter, taper and depth from data; type, size, hand |

| Seat Type | Parameters |
|---|---|
| **None** | — |
| **Counterbore** | hole Ø, cbore Ø, cbore depth |
| **Spotface** | hole Ø, spotface Ø, spotface depth (thread depth measured from spotface bottom; bore depth 0 allowed in parts) |
| **Countersink** | hole Ø, csink Ø, csink angle (depth derived) |
Restriction: Taper Tapped cannot have Counterbore. [Help]

### Termination & direction
| Option | Behaviour |
|---|---|
| **Distance** | positive depth from the face/work plane (sheet metal default = Thickness) |
| **Through All** | through every face |
| **To** | to a picked face/surface; **Extend To** (default on) extends the hole to a face that it does not reach |
| **Direction 1** (default) / **Direction 2** (flip) | Distance and Through All |
| **Symmetric** | both directions; only Simple, no seat, Through All |
[Help]

### Drill point
Flat; Angle (value, measure, or show dims; positive = CCW from the axis, default 118° [Mem]);
Flat W / Angle V (ISO annotation styles); Angle Y (point included in the depth). [Help]

### Threads (Tapped / Taper Tapped)
Type (ANSI Unified, ANSI Metric M Profile, ISO Taper, NPT…), Size, Designation (pitch),
Class (2B, 3B, 6H…), Diameter (display: Minor/Major/Pitch/Tap drill per document setting),
**Full Depth** (Tapped only; else thread depth field), Direction **Right Hand / Left
Hand**. [Help]

### Advanced
**iMate** (auto iMate on the hole); **Extend Start** (extend the start face back until it
leaves the body — removes leftover slivers; in multi-body does not cut a second body
except where it crosses the hole volume). [Help]

### Browser / edit
- Node `Hole1` with its sketch underneath (created automatically for face placement);
  Edit Feature / double-click reopens the panel; click the Sketch breadcrumb to add more
  centres, then the Hole breadcrumb to return. Right-click → **Convert to Slot** (one way).
  Delete dialog can also delete the sketch. [Help]

### UI and workflow
- (a) **3D Model tab > Modify panel > Hole**. [Help]
- (b) Panel top→bottom: breadcrumb `Sketch > Hole1` + preview; advanced menu; **Preset**;
  **Input Geometry**: Positions selector (active, underlined; Allow Center Point Creation
  toggle next to it), Solids; **Type**: Hole Type icons (Simple / Clearance / Tapped /
  Taper Tapped) and Seat icons (None / Counterbore / Spotface / Countersink); **Behavior**:
  Termination dropdown (Distance / Through All / To), Direction icons, Drill Point icons;
  a **dimension picture** of the hole with editable fields in it (Ø, depth, cbore Ø/depth,
  angle) [Mem: the image-with-fields is Inventor's hallmark]; **Threads** (when tapped);
  **Fastener** (clearance); **Advanced Properties** (iMate, Extend Start). [Help sections]
- (c) Prompt: "select a face, sketch point or work point". Click a face → centre placed
  under the cursor with live hole preview; click edges to dimension the centre (dimension
  glyphs with in-canvas edit); arrow manipulator for depth, diameter manipulator [Mem];
  red values if invalid (e.g. thread longer than hole). [Help]
- (d) Defaults: Simple, None, Distance, Direction 1, Flat? (Mem: Angle 118°), Allow Center
  Point Creation on, Extend To on, preset Last Used. [Help/Mem]
- (e) OK / Ctrl+Enter; (+) "Create new hole" keeps settings (Keep sketch visible on (+)
  shares the sketch); Esc cancels (and unshares). [Help]
- (f) Invalid value → red; no position → OK disabled / Continue; termination face not hit
  with Extend To off → error. [Help/Mem]

### Styles and Standards Editor
- Access: **Manage tab > Styles and Standards panel > Styles Editor**; same panel has
  **Update**, **Save** (to library), **Purge**. [Help]
- Layout: left = **browser tree** of style types → styles (library + document); right =
  editor pane of the selected style; top buttons **Back** (previous style, asks to save),
  **New** (copy of selected; "Add to Standard" checkbox), **Save**, **Reset** (revert to
  saved); **Filter**: Local Styles / Styles in the Active Standard (drawings) / All Styles;
  **Import** (.styxml); bottom **Done** [Mem], Help. Each style shows Name, **Location**
  (Library / Document / Both), **In Use**, **Changes** (Local / Library / Both). [Help]
- Style types **in parts**: **Lighting** and **Material** (material styles are legacy —
  since 2013 materials/appearances live in the Material/Appearance browsers; the editor
  in parts is mainly for Lighting [Help: "in part and assembly documents it sets lighting
  styles"]). Sheet metal styles are edited in a separate Sheet Metal Styles dialog.
  Assemblies/presentations: Lighting. Drawings: **Standard** plus Balloon, Center Mark,

  Weld Bead, Weld Symbol, Sketch? [Mem list]. Weldments: separate weld standard. [Help

- **Local vs library**: a document caches copies of the styles it uses; the library
  (XML per style type, location from the project file) cannot be edited directly — edit
  in a document, then **Save to Style Library** (replaces the library version; substyles
  saved only if missing unless saved explicitly). **Update** (manual) pulls library
  changes into the document (substyles separately; locally edited styles ask). **Purge**
  removes unused styles (all at once from the panel, or Purge Style / Purge Style &
  Substyle from the context menu); purge fails if referenced (sketch geometry in drawing
  resources, cached standard, object default, parent style). **Rename Cached Style**
  (document only; breaks the library link unless the name matches). **Cache in Document**
  keeps styles even if unused. **Export/Import** `.styxml` (self-contained, no live link,
  import overwrites same-named). Moving a document to a project with another library keeps
  its cached styles. Templates supply defaults (Document Settings > Standard tab). [Help]

## 7. Presets in property panels

**Sources:** To Work with Presets — GUID-0FDF0162-5374-4FC8-B6E3-59FDBC9AAA40 (fetched 2027);
Property Panel GUID-3E5505B9-9F60-43A0-BF32-97D183B91A70; Application Options File tab
GUID-53853AEB-F2BD-4ACF-BD90-6EBCE8034CAB; Migrate settings GUID-16061BA7-A2CD-4D71-905C-D8C417058239;
Hole page (HoleCmd.preset).

### What
A named saved set of a feature command's properties (incl. tolerances and the Boolean
output for Extrude/Revolve/Sweep/Coil). Choosing one fills the panel; the user can tweak
and save as new or overwrite. [Help]

### Which commands
Property-panel feature commands: Extrude, Revolve, Sweep, Coil, Hole, Fillet, Chamfer,
Shell (2026), Patterns (2026), Thread, Slot (2027), sheet-metal Face/Flange/Cut… [Help for
Extrude/Revolve/Sweep/Coil/Hole/Shell; others Mem]; plus legacy drawing commands End
Fill, Weld Symbol, Surface Texture Symbol. [Help]

### How it works
- Preset row: dropdown, **Create new preset** icon (+), **settings** dropdown. [Help]
- On start the dropdown shows **Last Used** (if a feature of that kind exists) or
  **No Preset**. [Help]
- Create: change values → Create new preset → type name (default offered). [Help]
- Settings menu: **Save Current** (overwrite), **Rename Current** (Esc reverts name),
  **Delete Current**, **New <feature> Default** = Last Used / Use Current Preset / No
  Preset (factory values), sort list by Recently Used / Date created / Alpha-Numeric /
  Last modified. [Help]
- Built-in presets: read-only, metric and imperial sets chosen by document units; can be
  hidden; can seed a custom preset. [Help]
- Modified preset shows an **asterisk**; editing an existing feature loads the preset it
  was made with (legacy / Last Used features show No Preset; changed legacy values → a
  "Custom" entry). [Help]
- Tolerances: value flyout → Tolerance… → saved with the preset; coloured indicator. [Help]
- Conflicts: Predict Boolean Operation overrides the preset's Boolean; a preset that
  conflicts with a style is greyed out. [Help]
- Storage: per user `%APPDATA%\Autodesk\Inventor <ver>\Presets` (e.g. `HoleCmd.preset`;
  read-only file disables saving); Last Used in `PresetSettings.xml…`; can be redirected to
  one shared file in Application Options > File; migrated between releases; persists across
  sessions. **Hide Presets** in the panel's advanced menu hides the row. [Help]

### For our clone
Presets are user settings, not document data — store them in the settings folder, never
in the `.3dcadcraft` file (only the preset *name* used could be recorded per feature). [our note]
